# RunningHub RHSTORY UI 系统分析

> 色值、尺寸与间距是从 1280×720 和更大视口截图估算的设计语义，不是官方 Design Token。应学习层级和工作流支撑方式，而非像素复刻。

## 1. 总体视觉策略

RHSTORY 使用高密度暗色专业工具界面：接近纯黑的应用背景、深灰表面、少量白色主按钮和荧光黄绿色状态强调。视觉重点不是装饰，而是让图像/视频素材、当前选择和生成成本在长时间工作中保持清晰。

```text
背景层：近黑，降低媒体预览周围干扰
表面层：深灰，用层级而非阴影组织区域
主文本：高对比白
次文本：中灰
状态强调：荧光黄绿，仅用于当前/选中/完成/价格
推进动作：高对比浅色填充
风险：红色，仅用于失败或删除
```

## 2. App Shell

### 2.1 组成

- 全站页面：全局导航 + 内容区 + 账户/消息区；
- 单集页面：Studio Header + 阶段工具栏 + 工作区 + 局部轨道/浮层；
- 专业工具：独立画布壳，但携带项目/集/镜上下文。

### 2.2 为什么有效

Stable Shell 让用户在剧本、设定、分镜、短片四种完全不同的工作区中仍保持空间记忆。项目、集和阶段稳定，主区可以大胆变化而不造成“换了一个产品”的感觉。

## 3. Header

单集 Header 约 64–72px，高度紧凑，结构从左到右为：

1. 返回项目；
2. 项目名；
3. 单集选择器；
4. 居中的四阶段步骤条；
5. 余额、充值、账户/空间入口。

设计理由：左侧表示层级和身份，中间表示流程，右侧表示资源和账户。阶段条居中提升持续可见性，但未解锁阶段需要可访问的禁用原因，不能只降低透明度。

## 4. Sidebar 与 Inspector

### 4.1 Sidebar

剧本左栏用于分场导航，自由模式左栏用于资产目录。它们都是稳定索引，不承担复杂编辑。

### 4.2 Inspector

分镜左栏是对象检查器，字段纵向堆叠并支持滚动/调宽。它围绕当前镜头显示输入依赖，适合高密度表单和缺失检查。

### 4.3 设计理由

Sidebar 回答“有哪些对象”，Inspector 回答“当前对象是什么状态”。如果混合两者，列表会被参数挤压，用户也无法快速切换对象。

## 5. Workspace

| 阶段 | Workspace 主形态 | 主要认知任务 |
|---|---|---|
| 剧本 | 左纲要 + 大正文编辑器 | 阅读、定位、改稿、确认 |
| 设定标准 | 卡片网格 | 比较资产完整性与当前主图 |
| 设定自由 | 资产目录 + 节点画布 | 理解关系、编辑结构字段 |
| 分镜 | Inspector + 编辑器 + 结果 + 镜头轨 | 组装输入、编排时间、生成与比较 |
| 短片 | 大播放器 + 时间线 | 审片、定位缺失、判断整集完成 |

同一个 Shell 下根据任务改变主形态，比用一套通用三栏硬套所有阶段更合理。

## 6. Cards

### 6.1 资产卡

资产卡突出横向三视图/主图，底部只保留类型、名称、音色或常用操作。空卡使用棋盘/占位区域和明显的“+”。

为什么有效：用户在设定页的高频任务是扫描“是否有图、形象是否一致、谁缺失”，而不是同时编辑全部字段。

### 6.2 风格卡

风格卡以图像为主，名称叠在底部渐变上，四列网格提升浏览效率。分类标签和搜索置于 Modal 顶部。

为什么有效：画风是视觉选择，缩略图比抽象名称更能降低匹配成本。但选中态、描述、推荐模型和应用影响必须明确。

### 6.3 镜头卡

镜头轨卡片包含镜号、时长、缩略图和状态；当前卡使用高对比边框和文字。未生成用统一占位而非空白。

为什么有效：时间线需要同时表达顺序、长度、完成度和当前选择。

## 7. Lists 与 Tables

### 7.1 Lists

- 分场大纲：短文本列表，选中后定位正文；
- 自由模式资产目录：头像缩写/名称，选中后聚焦节点；
- 历史候选：按时间或任务顺序，支持预览与选用；
- 项目/剧集列表：摘要优先，低频动作进入更多菜单。

### 7.2 Tables

消耗看板任务明细适合表格，因为项目/剧集、类型、模型、任务 ID、计费量、费用、状态是重复字段，用户需要横向比较和筛选。

表格不适合资产和镜头主体，因为媒体缩略图、视觉质量和连续性比字段对齐更重要。

## 8. Toolbar

### 8.1 阶段工具栏

顺序通常遵循：

```text
范围筛选 → 对象分类/统计 → 模式 → 重建/导入/批量 → 全局设置
```

工具栏只放阶段级动作。对象删除、候选选用等留在卡片/Inspector；账户和充值留在 Header。

### 8.2 生成参数条

分镜中栏底部把模型、规格、价格和生成按钮放在同一条带上。它把“能力、成本、执行”组合为一个决策单元，避免用户选完参数后到页面另一处寻找生成按钮。

## 9. Forms

### 9.1 表单层级

- 摘要字段直接展示；
- 高频字段内联编辑；
- 结构化资产字段进入 Drawer/Inspector；
- 复杂模型参数按能力动态出现；
- 高级提示词和参考映射按需展开。

### 9.2 表单规则

- 统一使用清楚的标签、单位和当前值；
- 数字时长显示秒，整集显示 `mm:ss`；
- 模型变化只重置不兼容字段，并解释原因；
- 禁用字段显示能力限制，不隐藏用户已填但暂不可用的数据；
- 费用靠近提交动作；
- 保存、确认、生成、选用、导出使用不同动词。

## 10. Dialog 与 Drawer 层级

| 表面 | 建议宽度 | 职责 | 背景状态 |
|---|---:|---|---|
| Confirm Dialog | 360–480px | 单一高影响决策 | 完全阻塞 |
| Selector Modal | 800–1200px / 视口自适应 | 画风、音色、素材选择 | 阻塞但保留背景可见 |
| Batch Modal | 720–960px | 范围、参数、价格预检 | 阻塞 |
| Detail Drawer | 38%–48%，最小约 520px | 长表单、历史、任务 | 非导航，保留背景上下文 |
| History Panel | 320–440px | 候选/任务浏览 | 可折叠 |

## 11. Typography hierarchy

建议语义层级：

| 级别 | 估算字号 | 用途 |
|---|---:|---|
| Page/Project title | 18–20px，600–700 | 项目名、页面主标题 |
| Section title | 16px，600 | 剧本正文、镜头号、分区标题 |
| Body/control | 14px，400–500 | 正文、表单、按钮 |
| Metadata | 12–13px | 数量、状态、时间、辅助说明 |
| Price/status emphasis | 14–16px，600 | 价格、完成度、当前选择 |

正文编辑器行高约 1.5–1.7；分时码提示词需要更宽松的段间距，以区分动作 beat。价格和计数建议使用等宽数字。

## 12. Spacing hierarchy

估算的间距阶梯：`4 / 8 / 12 / 16 / 24 / 32px`。

- 4px：图标与短标签；
- 8px：紧凑工具和同组控件；
- 12px：卡片内部字段；
- 16px：卡片/表单组之间；
- 24px：页面边距和主要区域间；
- 32px：大章节或空态。

圆角约分为：按钮/输入 8–10px，卡片 10–12px，主播放器/大面板 16–20px。主要分组依赖表面色和留白，不为每个容器叠加边框与阴影。

## 13. Information density

RHSTORY 是高密度桌面生产工具，但采用“默认摘要、选择后深入”的密度策略：

- 设定页同屏 3–4 张大卡，便于比较；
- 复杂资产参数藏入详情层；
- 分镜页密度最高，因为镜头输入、意图、结果和序列必须同屏；
- 短片页密度下降，主播放器占据视觉中心；
- 经营数据使用表格和图表，不侵入制作页面。

建议断点行为：≥1280px 完整多栏；1024–1279px 收起次要侧栏；<1024px 只提供轻编辑/审阅，避免把桌面三栏硬压成不可用窄列。

## 14. 状态视觉

状态不能只靠颜色：

| 状态 | 表现建议 |
|---|---|
| Selected | 边框 + 背景 + 图标/文字 |
| Loading | 保持布局的骨架屏 |
| Processing | 进度/阶段文本 + 可查看任务 |
| Success | 完成标记 + 结果落点 |
| Error | 错误图标 + 原因 + 重试 |
| Disabled | 降低强调 + 明确禁用原因 |
| Stale | 警示图标 + 来源版本 + 影响范围 |
| Partial Success | 成功/失败/跳过分项计数 |

## 15. 可访问性观察与缺口

实机页面的阶段和资产类型使用 tab 语义、正文使用可编辑区域、部分按钮有可访问名称，这是良好基础。仍观察到若干无名称图标按钮，且禁用原因未必能从键盘获得。

LocalMiniDrama 应补齐：可见焦点、图标按钮名称、非颜色状态、Modal 焦点圈定、Drawer 关闭后焦点恢复、镜头轨键盘移动、媒体替代文本和 WCAG AA 对比度。

## 16. 值得学习与不应复制

值得学习：Stable Shell、阶段视觉层级、暗色媒体工作区、卡片扫描/抽屉深改、分镜四区、价格靠近生成、短片大播放器与时间线、统一状态语言。

不应复制：荧光绿具体色值、纯暗色唯一主题、无名称图标、静默禁用、超宽屏依赖、账户抽屉覆盖工作区、以视觉“下一步”代替严谨业务批准。

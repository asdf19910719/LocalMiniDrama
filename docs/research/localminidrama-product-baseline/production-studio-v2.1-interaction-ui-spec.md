## 1. 规格定位

本文把 V2.1 架构母稿落实为页面、组件、状态、操作和视觉规则。它不是另一套架构，也不改变母稿中的 Stage、Approval、Revision、Invalidation、Shot Package、Reference Manifest、Candidate、Timeline Revision 和 Delivery Package。六类来源、外部协作、AI 配置、网页生成、归档、个人库、声音所有权、重拍、任务和危险操作的完整状态转换以[关键交互流程合同](../../superpowers/specs/2026-09-08-production-studio-v2.1-interaction-flow-contracts.md)为准。

本文用于产品评审、交互原型、前端拆分、API 契约检查和验收用例编写。若页面实现需要绕过上述领域对象，必须先修正设计，不能通过组件本地状态或 `metadata` 旁路写入。

## 2. 体验目标

### 2.1 用户每时每刻都能回答五个问题

1. 我在哪个项目、哪一集、哪个阶段、哪个对象？
2. 当前阶段完成到什么程度？
3. 哪些内容已批准，哪些只是草稿或候选？
4. 下一步是什么，为什么某个动作不可用？
5. 这次操作会影响哪些对象、触发多少任务、是否可能产生远端费用？

### 2.2 设计原则

- **阶段清晰**：主流程只有剧本、设定、分镜、短片四个阶段。
- **批准可见**：草稿、已选、已批准、过期和已锁定不能只靠颜色区分。
- **影响先于执行**：上游修改和批量生成先展示影响范围，再确认执行。
- **普通优先、高级不丢**：默认界面展示业务语义；H3、槽位、工作流参数在高级模式中完整可用。
- **本地优先**：本地编辑、预览和零远端费用工具直接执行；远端生成明确确认。
- **渐进展开**：列表/轨道负责扫描，详情抽屉负责编辑，历史/日志按需展开。
- **不中断长任务**：离开页面后任务继续，状态在全局任务抽屉中可追踪。
- **证据可追溯**：任何当前产物都能打开来源、输入快照和历史版本。

## 3. 路由与上下文恢复

### 3.1 目标路由

```text
/projects
/projects/:projectId
/projects/:projectId/episodes/:episodeId/script
/projects/:projectId/episodes/:episodeId/assets
/projects/:projectId/episodes/:episodeId/storyboard
/projects/:projectId/episodes/:episodeId/cut
/library
/quick-create
/settings/ai
/settings/tools
```

`:stage` 只允许 `script | assets | storyboard | cut`，未知值回退到该集最近有效阶段；没有历史时进入 `script`。

高级画布不是第五个阶段。唯一入口是当前阶段路由加 `?mode=advanced`。旧 `/projects/:projectId/episodes/:episodeId/canvas`、`/film/:id/canvas`、`/drama/:id/canvas` 不注册、不跳转，也不保留旧页面。

### 3.2 缺少上下文时的行为

| 情况 | 行为 |
|---|---|
| 项目不存在 | 显示 404 内容卡，提供返回项目列表；不自动创建 |
| 项目存在但剧集不存在 | 回到项目详情的剧集区，显示“剧集不存在或已移除” |
| 项目没有剧集 | 项目详情显示创建/导入剧集空状态 |
| 阶段依赖未批准 | 页面允许只读浏览；生成主动作禁用并列出 blocker |
| 未注册或旧 URL | 使用统一 404；提供进入 `/projects` 的动作，不加载旧实现 |

### 3.3 URL 可恢复状态

阶段必须体现在 URL。当前镜头/资产和模式使用查询参数，便于刷新和分享本地链接：

```text
?shot=42
?asset=character:18
?mode=advanced
?panel=history
```

纯视觉状态（抽屉宽度、轨道滚动位置）保存在本地偏好，不写入服务端领域数据。

## 4. 桌面端应用骨架

### 4.1 完整布局

```text
┌────────┬──────────────────────────────────────────────────────────┐
│ 全局栏 │ 项目 / 剧集切换       保存态 任务 预算 主题 用户/设置   │ 56
│  64    ├──────────────────────────────────────────────────────────┤
│        │ 剧本        设定        分镜        短片    阶段进度/阻塞 │ 48
│        ├──────────────────────────────────────────────────────────┤
│        │                                                          │
│        │                    当前阶段工作区                         │
│        │                                                          │
│        ├──────────────────────────────────────────────────────────┤
│        │ 可选：镜头轨 / 时间线 / 批量操作栏                       │
└────────┴──────────────────────────────────────────────────────────┘
```

### 4.2 全局栏

宽度 64px，图标加 tooltip，依次为：

1. 项目；
2. 资产库；
3. 快速创作；
4. 高级画布；
5. 任务；
6. 设置。

当前入口使用 3px 左侧指示条和强调背景；不能只改变图标颜色。64px 模式不显示文字，1280 以下不再缩窄。

### 4.3 制作头

高度 56px，固定于顶部：

- 左侧：返回项目、项目名、剧集下拉；
- 中部：最近保存状态，格式为“已保存 · 14:32”或“保存失败 · 重试”；
- 右侧：撤销/重做（当前阶段）、任务按钮及数量、远端预算摘要、主题、更多。

项目名和剧集名过长时分别截断，悬浮显示完整值。切集前如有未保存草稿，先尝试自动保存；失败时弹出“重试/放弃本地草稿/留在此页”，不得静默丢失。

### 4.4 阶段导航

四个阶段固定显示：剧本、设定、分镜、短片。每项包含：

- 序号或图标；
- 阶段名；
- 内容状态文字：未开始、进行中、可确认、已确认、已过期；
- 完成度，如 `8/10 镜已确认`；
- 需要处理时另列 blocker、warning 和失败任务数量徽标；“被阻塞”不得替代内容状态。

点击后允许浏览任何阶段。只有高资源生成、批量执行、Picture Lock 和最终导出受 Gate 限制。

### 4.5 阶段头

每个页面内容区顶部固定 56px 阶段头：

- 左：标题、简短状态、最近批准版本；
- 中：筛选、搜索或当前选择摘要；
- 右：一个实心主 CTA，最多两个次级按钮和“更多”；
- 存在 blocker 时，在阶段头下方显示可折叠阻塞条。

禁止把超过三个同级按钮平铺到阶段头。

## 5. 状态语言

### 5.1 对象 revision 状态

| 状态 | 标签文案 | 图标/形状 | 允许操作 |
|---|---|---|---|
| draft | 草稿 | 空心圆 | 编辑、删除、提交确认 |
| ready_for_review | 待确认 | 时钟 | 对比、确认、退回 |
| approved | 已确认 | 勾选圆 | 用于下游、创建新修订 |
| stale | 已过期 | 警告三角 | 查看原因、查看旧批准版本、重新编译 |
| superseded | 已被新版本取代 | 历史标 | 查看、比较、从此派生 |

`locked` 仅用于 Timeline/Picture/Post/Delivery 不可变 revision。`blocked` 是 Gate 评估，`generating/failed` 是任务状态，`waived` 是独立豁免记录；它们以 badge 与对象/阶段主状态并列显示，不进入对象 revision 枚举。

所有状态同时显示文字与图标；颜色只是辅助。

### 5.2 阶段状态

```text
not_started → in_progress → ready_for_review → approved
approved --上游变化--> stale --复核/重编--> ready_for_review
```

Gate 有 blocker 时保持当前阶段内容状态并返回 `block`；不把阶段持久化为 `blocked`。阶段批准不自动批准其内部所有草稿；批准 API 必须验证必需对象，明确跳过项写独立 waiver，记录原因、创建者和输入变化过期规则。

### 5.3 自动使用与确认默认值

V2.1 关闭资产候选自动使用。批量生成成功只产生候选；技术检测通过只标记 `technically_eligible`，不会自动成为 current。用户点击候选卡即执行“使用此图/使用此音色”并保存 current pointer，不再经过“临时选中→采用为当前→对象批准”三层动作。剧本、Look、Shot、Picture Lock 和交付仍保留各自必要的阶段确认。

单机阶段确认者为 `local-user`；一次性迁移生成的记录可标记 `system`，并说明迁移来源。字段预留未来多人身份，不在 V2.1 引入 RBAC。

## 6. Script Stage｜剧本

### 6.1 页面布局

```text
┌ 场次/结构 240 ┬──────────── 剧本编辑器 fluid ────────────┬ 检查 320 ┐
│ 集/场次列表    │ 标题、场景头、动作、角色对白、旁白       │ 结构摘要 │
│ 搜索/过滤      │ 当前修订、行级问题标记                   │ 角色场景 │
│ 变更点         │                                          │ 问题列表 │
└────────────────┴──────────────────────────────────────────┴──────────┘
```

最小工作区宽度 1024。1280 以上三栏；1024–1279 时右栏变为抽屉；小于 1024 进入有限编辑模式并提示使用桌面宽屏进行完整制作。

### 6.2 核心操作

- 新建/粘贴/导入剧本；
- 从梗概生成草稿；
- 解析角色、场景、道具和镜头建议；
- 查看修订历史与 diff；
- 保存草稿；
- “提交确认”进入检查；
- “确认剧本”创建 Approval Revision；
- 已确认剧本的编辑自动派生新草稿，不覆盖批准版。

### 6.3 保存规则

- 停止输入 800ms 后自动保存当前草稿；
- 保存中显示非阻塞状态，不弹 toast；
- 失败后保留浏览器内草稿，顶部显示持久错误条；
- `Ctrl/Cmd+S` 立即保存；
- 冲突时显示服务端版本和本地版本 diff，不采用最后写入覆盖。

### 6.4 检查器

分为“阻塞”和“建议”：

- 阻塞：无法解析的场次、缺失正文、未知角色归属、重复 id、非法导入；
- 建议：场次过长、镜头过密、角色名近似、场景缺视觉信息、对白过长。

点击问题跳转到对应场次和文本位置。确认时只阻止“阻塞”项，建议可带说明忽略。

### 6.5 上游变更影响确认

修改已批准剧本并再次确认前，弹出影响摘要：

```text
本次修订影响
  3 个场次已修改
  2 个角色设定可能过期
  6 个镜头 Shot Package 将过期
  4 张已确认镜头图可继续保留，但需复核

[查看明细] [取消] [确认新修订]
```

确认只写入新 revision 和失效标记，不自动触发任何远端生成。

### 6.6 主 CTA

- 草稿未检查：`检查并提交`；
- 已检查可确认：`确认剧本`；
- 已确认无新改动：`进入设定`；
- 有阻塞：禁用 CTA，按钮下或阻塞条说明具体原因。

## 7. Assets Stage｜设定

### 7.1 页面信息架构

顶部标签：`总览`、`画风`、`角色`、`场景`、`道具`。人物音色在角色卡和人物详情中管理，不再建立平级“音色”标签；标签右侧显示待处理数量。

页面提供模式切换：

- **标准模式**：卡片、列表、详情抽屉和批量操作；默认。
- **高级画布**：自由组织和查看依赖；写操作仍调用统一 V2 API。

### 7.2 总览

总览首屏依次为：

1. readiness：Look、角色（含本集音频策略实际要求的音色）、场景、道具已确认数；
2. blocker：缺失、失败、过期；
3. 最近变更及下游影响；
4. 各资产类型缩略列表；
5. 批量预检入口。

用户点击“进入分镜”时，系统自动检查 Look 已确认，且本集实际使用的必需人物状态、场景和道具有可用 current。人物音色采用条件 Gate：只有本集所选音频策略明确需要该人物音色且 current 缺失时才阻断；人物无对白、使用无需参考音色的 H3 原声或允许 Provider 默认音色时只提示。检查通过即保存本集实际引用的精确资产版本/hash 快照并跳转，不增加独立的阶段确认或批准动作；项目资产之后改选不会静默改写该快照。

### 7.3 Look/画风

Look 卡片显示：

- 名称、代表图、来源（预设/自定义/导入）；
- 业务描述和可读标签；
- 适用的图片/视频 Provider 能力摘要；
- 当前修订号和批准状态；
- 使用该 Look 的镜头数量。

打开详情抽屉后分为：

1. 视觉意图：媒介、线条、色彩、光线、质感、时代/类型；
2. 样例图：上传/生成/选择；
3. 编译预览：标准模式只读摘要，高级模式显示 prompt 片段和 Provider 输出；
4. 版本与影响：历史、diff、受影响资产/镜头；
5. 操作：保存草稿、生成样例、提交确认、确认版本。

选择卡片不等于批准；批准后卡片显示“项目当前 Look”。场次或分镜覆盖分别显示“本场覆盖”“本镜覆盖”，不得出现不存在的 Episode Look 或“当前用于本集”。

### 7.4 角色/场景/道具卡

卡片只保留扫描所需信息：

- 缩略图或音色波形；
- 名称、类型和一行描述；
- 当前使用版本；
- 草稿/过期/失败/缺失标签；
- 被多少镜头使用；
- 快捷“打开详情”和“生成候选”。

编辑字段、Provider 参数、负向 prompt、身份锚点、造型阶段、历史候选全部进入详情抽屉，避免恢复当前横向宽卡片。

### 7.5 详情抽屉

桌面宽 440px，可拖至 640px；打开后保持列表上下文。固定结构：

1. Header：名称、状态、关闭；
2. Preview：当前批准版 + 候选数量；
3. 基础设定；
4. 版本/变体；
5. 生成 Recipe 与引用；
6. 使用位置；
7. 历史与 provenance；
8. Footer：保存、生成候选、提交/确认。

角色额外包含身份锚点、造型状态和人物声音身份。人物卡直接显示音色已设置/未设置、来源和快捷试听；人物详情的“版本与候选”提供“人物形象/人物音色”切换。音色记录稳定的语言、口音、年龄感、音质描述、来源许可和 Provider 能力；愤怒、耳语、哭腔、语速、停顿等表演要求属于对白/时段，不固化为人物音色属性。场景包含时段/天气变体；道具包含比例/持有关系。

### 7.6 批量生成预检

任何远端批量生成先显示：

- 选择范围：全部/缺失/已过期/手选；
- 将跳过：已确认、生成中、无必需输入；
- Provider 和模型；
- 预计任务数；
- 费用：已知估算或“Provider 未返回价格”；
- 并发数；
- 失败策略：继续其余任务；
- 完成行为：进入待确认，不自动批准。

主按钮文案必须具体，如 `创建 8 个远端任务`，不能只写“确定”。

## 8. Storyboard Stage｜分镜

### 8.0 方案 B 的界面语义

分镜阶段采用“场次—分镜—时段”：

- 场次是剧本叙事分组；设定阶段的 `scenes` 在 UI 中统一称为“场景资产”；
- 分镜是一次视频生成单元，不增加用户可见的“视频段”层；
- 每个分镜含 1～N 个时段，单时段是常规合法形态；
- 时段以连续时间码表达动作、运镜、对白、声音以及场景资产/角色/道具的生效范围；
- 15 秒只作为特定 Provider 的上限或规格，不作为自动拆分长度和必须填满的目标。

### 8.1 桌面布局

```text
┌ 结构 280 ┬────────── 分镜图与关键帧 fluid ──────┬ 编译 360 ┐
│ 分镜字段 │ 当前图/图片候选/连续性覆盖层          │ Recipe   │
│ 时段/台词│ 关键帧与可选 motion previs            │ Prompt   │
│ 资产引用 │                                        │ 引用/预检│
├──────────┴────────────────────────────────────────┴──────────┤
│ 镜头轨 112：缩略图、编号、时长、状态、失败/过期标记          │
└──────────────────────────────────────────────────────────────┘
```

主页面本身不允许横向滚动。镜头轨可横向滚动，并支持 `Shift+滚轮`；栏宽可拖动但有最小值。

页面工具栏提供两个不同来源的结构更新入口：

- `从当前剧本重新生成分镜`：只读取当前剧集已确认的 Script revision，显示结构模型、预计费用/耗时以及新增、变化、拟删除和不变镜头差异；人工锁定内容进入冲突处理，确认后创建新 Shot revision，不删除原版本及图片/视频候选历史；
- `导入分镜文件`：V2.1 支持 Excel `.xls/.xlsx`、CSV `.csv` 与 `shot-package@2.1` JSON，经选择文件、解析/字段映射、结构预览、资产匹配、版本差异、确认写入后创建新 Shot revision。DOCX/普通文本的 AI 辅助解析留待后续；完整 Episode Package、外部 AI 回流 JSON 和整集制作包固定转到剧集页导入。

两个入口均不得直接覆盖当前 Shot revision，也不能因为结构重建而删除媒体历史。

### 8.2 左栏：分镜与时段检查器

基础模式显示：

- 分镜号、关联场次、剧情计划时长；
- 目标 Video Recipe 的预计请求时长；若与计划时长不同则并列显示原因；
- 时段列表；默认允许一个覆盖全时长的时段；
- 景别、机位、镜头运动；
- 画面描述；
- 对白、旁白；
- 角色/造型、场景/变体、道具引用；
- 连续性备注。

时段行显示 `开始—结束`、摘要、场景资产、角色和道具芯片；提供新增、拆分、合并、重排操作。只有一个时段时不显示结构不足警告。高级模式增加结构化角度、universal mode、AV contract 等现有字段。字段更改先保存 Shot 草稿，是否让当前分镜图、已编译 prompt 或正式视频候选过期由 fingerprint 计算，不由前端猜测。

### 8.3 中栏：分镜图、关键帧与预演

视图模式：

- 当前：当前分镜图或关键帧；
- 比较：2–4 个图片候选并排或 A/B 滑动；
- 历史：按 revision 分组；
- 连续性：上一镜/当前/下一镜三联视图。

图片候选卡显示 Provider、模型、生成时间、尺寸、输入 revision 和任务状态。选择候选只是“临时选中”；点击 `采用为当前` 后成为当前分镜图，但 Shot Gate 并不普遍要求必须有图。

可选 motion previs 仅用于检查节奏和动作密度，显示 `预演，不进入成片` 标签并保存为 `artifact_role=previs`。它不能成为正式 VideoCandidate、不能采用到 Timeline，也不能通过 Video Gate。

采用时可选理由：构图、角色一致性、动作、光线、其他。拒绝理由可用于后续 Recipe 调整，但不自动训练模型。

### 8.4 右栏：图片与视频生成面板

按顺序分组：

1. Recipe：图片生成 Recipe 或目标 Video Recipe；
2. 业务意图：正向、负向、镜头运动；
3. Reference Manifest：角色、场景、道具、首尾帧、上一镜稳定帧；
4. 能力检查：请求时长、时段数、多场景和引用上限的支持/降级/阻塞；
5. 基础编译预览：标准摘要/高级完整 prompt、槽位映射和 PromptStyleGate 结果；
6. H3 提示词草稿：独立生成动作、可编辑文本、来源 Shot/Recipe revision、fingerprint、生成时间/编译器，以及结构、引用槽位、音频语义覆盖和 PromptStyleGate 结果；
7. 图片生成数量、尺寸、质量参数；
8. 视频任务参数：Provider、模型、计划/请求输出时长、分辨率、任务数、并发、预计费用/资源和降级项；
9. 视频任务时间：预计排队、预计生成处理、预计总耗时、统计样本和“非承诺值”说明；
10. 图片模式显示“生成图片候选”；视频模式显示“预检并生成视频候选”。

H3 草稿不是藏在“重新编译 Prompt”中的不可见副作用。来源 revision、引用或声音事件变化时，旧草稿保留并标记 `stale`；结构、引用槽位或音频语义校验失败时标记 `invalid`。两种状态均阻断新的正式视频任务，并提供保留人工文本后重新生成或直接编辑修复；不得静默覆盖人工 H3 文本。

提交视频前必须展示本次不可变输入快照并二次确认费用或资源。`计划 7s / 请求 8s` 表示输出视频长度，不得与任务等待时间混写。运行中显示已运行时间与预计剩余区间；完成候选显示提交、开始、完成时间以及实际排队、处理和总耗时。任务成功只追加 VideoCandidate，不自动采用、不替换旧候选，也不自动进入短片。候选点击只预览；点击 `使用这个候选` 后才写 adopted pointer 和事件。生成失败保留输入快照，并提供原参数重试、换模型和返回修改三种恢复动作。

Provider 不支持某引用时：

- 必需引用：阻止执行；
- 可选引用：默认阻止并提供用户明确勾选的降级选项；
- 降级选择写入本次任务快照，不能静默省略。

目标 Video Recipe 不支持当前多时段或多场景结构时，编译面板显示具体边界和两种可执行动作：`按建议拆分分镜`、`更换目标模型`。不得静默删除时段或场景引用。模型只接受离散时长时显示“计划 7s / 本次请求 8s”；正式费用确认和任务提交在分镜阶段发生。

### 8.5 镜头轨

每个镜头缩略块包含：编号、当前图、计划时长、确认状态、图片任务状态、视频任务状态、候选数和 adopted 状态。交互：

- 单击切换当前镜头；
- `Shift` 多选连续范围；
- `Ctrl/Cmd` 多选离散镜头；
- 拖拽重排需要确认并生成新顺序 revision；
- 过滤缺失、过期、失败、待确认；
- `[` / `]` 或左右键切换上一/下一镜，输入框聚焦时不拦截。

### 8.6 连续性

连续性面板显示：

- 上一镜稳定帧及来源时间点；
- 角色身份、服装/受伤/持有物状态；
- 场景、时间、天气、主光方向；
- 相机轴线和动作方向提醒；
- 作为引用时的 Provider 支持结果。

稳定帧只是引用候选。用户确认后才加入下一镜 Reference Manifest；系统不得自动形成不可见的级联依赖。

### 8.7 批量操作

批量栏只在选择多个镜头时出现：

- 重新编译 prompt；
- 生成缺失图片；
- 生成过期图片；
- 生成缺失视频；
- 重新生成过期视频；
- 提交确认；
- 设置共享 Recipe；
- 导出所选 Shot Package。

所有批量动作先展示命中/跳过/阻塞数量、预计任务数/并发和费用或资源；正式视频批量生成仍需明确确认。单个失败不回滚已成功镜头，完成后保留成功项并按失败原因分组提供重试。

### 8.8 阶段完成条件

每个必需镜头必须满足：

- 引用的剧本、Look 和资产版本仍有效；
- Shot Package 编译成功；
- 镜头状态为已确认；分镜图是可选产物，不作为通用 Shot Gate 条件；
- 没有会改变当前 Shot fingerprint 的运行中或未知结构/编译任务；
- 若目标 Video Recipe 需要首帧/参考图，缺图只显示为“视频生成前置未满足”，不阻止确认 Shot Package，但会阻止在分镜页提交对应正式任务；
- 被豁免的镜头有原因。

`进入短片审核` 是阶段导航，不等于所有镜头已完成。短片可先打开查看整集状态；Picture Lock 仍由 Video Gate 硬性要求每个必需镜头具有 adopted 候选或有效豁免。

## 9. Cut Stage｜短片

### 9.1 页面模式

短片阶段提供三个主标签：

1. `镜头审核`：连续播放、逐镜复核、候选比较、质量和修复；
2. `时间线`：组合、裁剪、音频、字幕；
3. `交付`：后期、检查、导出。

### 9.2 镜头审核布局

复用分镜页的镜头轨和唯一候选事实源，但主预览为视频，默认处理“整集是否可合片”而不是重复首次生成配置：

- 左栏：镜头轨、缺失/失败/待采用/过期状态和场次筛选；
- 中栏：视频预览、A/B 比较、逐帧/稳定帧选择；
- 右栏：分镜来源快照、候选历史、技术检查、修复动作、稳定帧和 Video Gate；
- 底部：整集完成度、连续播放和“进入时间线”。

首次视频任务在分镜阶段提交。短片仍提供 `重新生成/补充候选` 和 `局部重拍`，打开与分镜相同的 Recipe、Reference Manifest、Provider 能力、时长、费用与降级确认 Sheet；新结果追加到同一候选组，不覆盖原片。用户可从审核页返回对应分镜修改结构或 Prompt。

视频候选点击只预览；点击 `使用这个候选` 才改写 adopted pointer。若该镜头已有 Timeline clip，必须询问 `替换当前时间线片段` 或 `仅改默认候选`。前者派生新 Timeline revision，后者保持现有 clip 固定的 candidate id；任何情况都不得静默换片。

从视频选择稳定帧时，显示帧时间点、来源 candidate id 和将影响的下一镜；确认后创建独立 reference artifact。

### 9.3 时间线布局

```text
┌ 素材/镜头 260 ┬──────────── 节目监视器 ────────────┬ 属性 320 ┐
│ 缺失/未采用    │ 播放、时间码、安全框、字幕预览     │ 裁剪/变速│
│ 视频/音频      │                                    │ 转场/音量│
├────────────────┴─────────────────────────────────────┴──────────┤
│ 时间线 240：视频｜对白/旁白｜音乐/音效｜字幕                    │
└──────────────────────────────────────────────────────────────────┘
```

V2.1 是短剧生产时间线，不追求替代专业 NLE。支持：

- 镜头排序、入点/出点、基础变速；
- 基础转场及持续时间；
- 对白/旁白、音乐/音效的增益、淡入淡出；
- 字幕片段编辑和吸附；
- 自动保存 Timeline Revision；
- 从任意 revision 派生新版本。

### 9.4 Picture Lock

点击 `锁定画面` 前检查：

- 所有必需镜头有已采用视频或豁免；
- 时间线无离线媒体、负时长或重叠冲突；
- 总时长和画幅有效；
- 没有运行中的必需视频任务。

锁定后当前 Timeline revision 只读。任何镜头替换、顺序、裁剪、画面变速或转场修改都必须派生新 Timeline revision。字幕、对白、旁白、音乐、音效、水印、调色和超分保存为绑定该 `picture_lock_id` 的 Post Revision；不改变画面时长时不打破 Picture Lock，改变画面边界或总时长时必须回到 Timeline。最终交付同时绑定明确的 Picture Lock id 与 Post Revision id。

### 9.5 后期处理顺序

默认处理链固定为：

```text
技术镜头匹配
  → 创意 Look/调色
  → 可选超分
  → 字幕与用户水印
  → 音频混合与响度标准化
  → 交付编码与校验
```

原因：先解决镜头间技术一致性，再施加创意风格；超分在合成元素前避免字幕被错误放大；最终音频在画面时长确定后混合。Provider/工具如有硬性顺序，任务创建时展示偏离和原因。

### 9.6 Delivery Gate

交付检查至少覆盖：

- Picture Lock 存在且引用有效；
- 输出分辨率、帧率、画幅、编码；
- 离线/损坏媒体；
- 黑帧、异常静音、音频削波和响度；
- 字幕越界、重叠和缺失；
- 可选水印和安全框；
- 超分/调色失败是否选择回退；
- 输出目录可写、预计磁盘空间；
- manifest、字幕和报告是否随包导出。

交付失败不删除中间成片。用户可从失败步骤重试，或选择无超分基础版本继续导出。

## 10. 全局任务抽屉

### 10.1 入口与布局

点击制作头任务按钮打开右侧 420px 抽屉，不离开当前阶段。顶部显示：运行、排队、失败、已完成筛选和总并发。

每个任务项显示：

- 任务类型和对象，例如“镜头 08 · 视频生成”；
- Provider/工具和模型；
- 状态、进度、提交/开始/完成时间、实际排队/处理/总耗时；运行中显示已运行和预计剩余区间；
- 远端费用：估算/实际/未知/本地零费用；
- 所属项目、剧集和可跳转对象；
- 查看输入、日志、取消、重试、打开结果。

### 10.2 状态契约

统一前端投影：

```text
queued | running | waiting_external | succeeded | failed | cancelled | unknown
```

`waiting_external` 表示任务已停在用户登录、外部网页操作、文件回填或人工确认，任务项必须显示“需要处理”和恢复入口。`unknown` 用于进程中断、Provider 查询失败或状态无法对账，不能直接显示“失败”。重试必须复用输入快照并使用幂等键，除非用户显式创建新候选。

### 10.3 通知

- 当前页短任务成功：对象内联更新，不刷屏 toast；
- 后台批次完成：一次汇总通知；
- 失败：任务抽屉徽标 + 对象内联错误；
- 需要用户登录/外部网页操作：持久“需要处理”项；
- 远端费用变化：仅在执行前和账单回填时提示。

## 11. 通用弹窗与抽屉

### 11.1 三类容器

| 容器 | 用途 | 关闭规则 |
|---|---|---|
| Detail Drawer | 查看/编辑资产、候选、历史 | 未保存时确认；Esc 可关闭 |
| Generation Sheet | 配置单次或批量生成 | 执行后关闭或固定到任务抽屉 |
| Confirm Dialog | 删除、批准、失效、Picture Lock、远端费用确认 | 必须明确按钮文案；不允许点击遮罩误关高风险确认 |

弹窗中不再打开第二层弹窗；需要深层内容时在原容器内切换标签或跳转完整页。

### 11.2 生成 Sheet

固定顺序：对象/范围 → Recipe/Provider → 引用与能力 → 参数 → 任务/费用摘要 → 执行。高级参数默认折叠，但摘要必须显示其是否使用默认、项目覆盖或单次覆盖。

### 11.3 历史与 provenance

历史面板按时间倒序展示 revision、操作者、来源、变更摘要、使用状态。点击某项可查看：输入 revision、prompt 编译结果、引用快照、Provider 参数、任务日志和输出 hash。敏感凭据始终脱敏且不进入导出 manifest。

## 12. 错误、加载、空状态与离线

### 12.1 加载

- 页面骨架只覆盖尚未返回的区域；阶段导航和上下文始终可用；
- 媒体用固定比例占位，避免布局跳动；
- 超过 2 秒显示“正在加载什么”；超过 10 秒提供重试；
- 后台任务不使用阻塞全屏 loading。

### 12.2 空状态

空状态必须说明“为什么为空”和“下一步”：

- 无剧集：创建剧集/导入剧集包；
- 无角色：从已批准剧本解析/手动添加；
- 无候选：检查输入并生成/上传；
- 筛选无结果：清除筛选；
- 媒体离线：定位文件/查看来源/从候选恢复。

### 12.3 错误分级

- 字段错误：字段下方说明；
- 对象错误：卡片/镜头内联；
- 批次错误：摘要成功/失败/跳过并可筛选失败项；
- 系统错误：页面错误条，保留用户草稿；
- 数据迁移/完整性错误：阻止危险写入，提供迁移报告或诊断包，不自动重置。

错误文案包含发生对象、原因、是否已保存、可执行动作。禁止只显示“操作失败”。

### 12.4 离线与 Provider 不可用

本地页面和本地素材应继续可读写。远端动作显示离线/未配置/认证过期/限流/余额不足等不同状态；本地预览、编辑和零费用处理不因远端离线整体禁用。

## 13. AI 配置、作用域与能力

### 13.1 配置层级

```text
全局默认
  < 项目覆盖
    < 剧集/阶段 Recipe
      < 单次任务覆盖
```

表单字段旁显示来源标签，例如“全局默认”“项目覆盖”。单次覆盖只写入任务快照，不反向修改全局配置。

### 13.2 Provider Capability

后端返回的 capability schema 同时驱动：

- 模型选择器；
- 画幅、尺寸、时长和数量字段；
- 多时段支持、最大时段数、多场景支持和最大场景资产数；
- 引用槽位数量和类型；
- 首尾帧、参考音频、遮罩等开关；
- 前端禁用原因；
- 后端最终校验；
- 任务输入快照。

能力加载失败时不使用过期前端常量猜测；可显示最近缓存及时间，但远端执行前必须重新校验。

## 14. 快速创作、媒体库与高级画布

### 14.1 快速创作

全局入口提供图片和视频 Recipe。生成前可不绑定项目；结果完成后必须提供：

- 下载；
- 保存到媒体库；
- 用于某项目的角色/场景/道具；
- 添加为某镜头候选；
- 添加到时间线素材。

用户关闭未归档结果时提示其仍保存在任务历史和临时媒体区，不强制选择。

### 14.2 媒体库

顶部组合筛选：项目、剧集、对象类型、媒体类型、Provider/工具、状态、日期、标签、是否被使用。卡片标题优先显示业务名称，如“镜头 08 · 视频候选 3”，文件名作为次级信息。

详情显示来源、输入快照、使用位置、版本关系、文件属性和完整本地路径。移动/重新定位文件必须更新索引，不能静默复制大文件。

### 14.3 高级画布

画布通过当前阶段的 `?mode=advanced` 展示剧本 revision、Look、资产版本、Shot Package、引用、候选、时间线和任务关系。默认执行 `Fit selection`，提供小地图、缩放、过滤和影响路径高亮。

画布编辑必须调用与标准模式相同的命令 API；禁止直接修改旧 metadata。删除节点只删除关系或草稿时要明确，已批准/被使用对象不能从画布直接物理删除。

## 15. 视觉系统

### 15.1 设计令牌

采用语义令牌，不在组件中硬编码品牌色：

```text
bg.canvas / bg.surface / bg.elevated
text.primary / text.secondary / text.muted / text.inverse
border.default / border.strong / border.focus
accent.primary / accent.hover / accent.subtle
status.info / success / warning / danger / stale / locked
overlay.scrim
```

浅色和深色主题保持同一语义。强调色只用于主 CTA、当前选择和焦点；状态色不取代文字标签。

### 15.2 尺寸与密度

- 基础间距：4px 网格；常用 8/12/16/24/32；
- 控件高度：紧凑 28、默认 36、主 CTA 40；
- 圆角：卡片 10、输入 8、标签 999；
- 正文字号：14px；次级 12px；页面标题 20px；
- 单行正文行高不低于 1.45；
- 缩略图统一比例，角色可 3:4，场景/镜头 16:9，道具 1:1；
- 一屏不展示超过一个主要阴影层级，以边框和背景层级为主。

### 15.3 选择、批准与焦点

- 当前选中：强调边框 + 浅强调背景；
- 当前确认版本：勾选标签；Project Look 使用“项目当前 Look”；项目资产媒体使用“当前使用”，不显示对象级批准；
- 键盘焦点：2px focus ring，与选择状态同时存在；
- hover 只显示快捷动作，不承载唯一信息；
- stale 使用警告图标和原因文字，不把旧产物染成不可读颜色。

## 16. 响应式与窗口策略

| 宽度 | 策略 |
|---:|---|
| ≥1440 | 完整多栏，任务抽屉覆盖或挤压由用户选择 |
| 1280–1439 | 完整主流程，侧栏使用最小宽度 |
| 1024–1279 | 次要检查器改抽屉，保留镜头轨和主预览 |
| <1024 | 项目浏览、剧本轻编辑、任务和媒体预览可用；分镜/时间线提示切换宽屏 |

V2.1 不承诺移动端完整生产，但不能出现页面级水平溢出导致基础导航不可用。

## 17. 键盘与可访问性

- `Ctrl/Cmd+S` 保存当前草稿；
- `Ctrl/Cmd+K` 全局搜索/命令；
- `Esc` 关闭最上层抽屉/菜单，不丢弃未保存内容；
- 左右方向键或 `[` `]` 切换镜头；
- 空格控制视频/时间线播放，输入框聚焦时不拦截；
- `J/K/L` 可作为高级播放快捷键；
- 所有图标按钮有可访问名称和 tooltip；
- 关键状态不只使用颜色；
- 正文、控件和焦点对比度达到 WCAG AA；
- 抽屉打开后正确管理焦点，关闭后回到触发元素；
- 减少动画偏好下禁用大幅位移动画和持续闪烁。

## 18. 分析与可观测性

本地优先不等于无诊断。默认只保存本地产品事件，不上传，至少记录：

- 进入阶段、阶段确认/退回；
- blocker 类型；
- 批量预检的命中/跳过/取消；
- 任务状态变化和错误类别；
- stale 原因和重编范围；
- 候选采用/拒绝；
- Picture Lock 和 Delivery Gate 结果；
- 页面性能：首屏、镜头切换、媒体预览。

任何远端遥测必须单独告知并由用户开启，不包含剧本文本、prompt、媒体和凭据。

## 19. 页面级验收摘要

### 19.1 应用壳

- 项目、剧集、阶段和当前状态始终可见；
- 可跨阶段浏览，不误触未批准下游的高成本操作；
- 长任务离开页面后仍可追踪；
- 刷新恢复当前阶段和选择对象。

### 19.2 剧本

- 草稿自动保存且冲突不静默覆盖；
- 已批准剧本编辑会派生新修订；
- 确认前展示检查和下游影响；
- 新 revision 只让实际受影响对象过期。

### 19.3 设定

- Look 的草稿/确认版本，以及角色（含条件使用的人物音色）、场景、道具的当前使用项/候选明确；
- 资产详情不挤入横向宽卡片；
- 批量远端生成明确范围、任务数和费用可知性；
- 修改资产当前使用项能查看受影响剧集和镜头；已确认剧集快照不被静默改写。

### 19.4 分镜

- 200 镜可流畅切换，主页面无水平溢出；
- Shot Package、Reference Manifest 和 Provider 能力可查看；
- 单时段与多时段均可保存和生成；时段时间码连续闭合；
- 不以 15 秒或 Provider 最大时长强制扩写分镜；
- 多场景分镜不被静默降级，不支持时给出拆分或换模型建议；
- 计划时长与 Provider 请求时长的差异可见；
- PromptStyleGate 可查看具体通过项或阻塞项，不展示结果级风格评分；
- 不支持引用被阻止或经用户明确降级；
- 图片与视频候选均可比较、采用、追溯和回退；正式视频任务可单镜或批量提交，成功不自动采用；
- 连续性引用可见且可断开。

### 19.5 短片

- 页面主入口明确为镜头审核，首次生成不与整集审核混为同一步；
- 每镜视频候选与最终时间线使用项可追溯，改选候选不静默替换 Timeline clip；
- 时间线每次关键编辑保存 revision；
- Picture Lock 后不直接变更；
- 超分或后处理失败可回退到基础成片；
- Delivery Package 包含成片、可选字幕、manifest 和报告。

## 21. 已确定的默认决策

为避免实施阶段重复确认，以下作为 V2.1 默认值：

1. 架构母稿继续作为唯一目标架构，在其上迭代，不另起平行设计；
2. 本地优先，单一 `local-user` 操作者；自动批准默认关闭；
3. 四阶段目标路由采用 `/projects/:projectId/episodes/:episodeId/:stage`；
4. 未批准上游允许浏览下游，但阻止高资源批量执行和依赖其正确性的锁定/交付；
5. 本地预览和零远端费用工具可直接执行；远端生成先确认范围、Provider、数量和费用可知性；
6. 标准模式默认，高级字段和画布按需进入；两者共享领域 API；
7. 桌面完整体验从 1280px 起，1024px 自适应，低于 1024px 不承诺完整分镜/剪辑；
8. 后期默认顺序为技术匹配 → 创意 Look → 可选超分 → 字幕/水印 → 音频响度 → 编码校验；
9. 时间线 Picture Lock 后只读，修改必须派生新 revision；
10. RunningHub 的账户、钱包、公开剧场、强制水印、团队审批不进入本地 V2.1 主线。
11. 分镜采用“场次—分镜—时段”方案 B；分镜是一次生成单元，视频是候选结果，时段数量为 1～N。
12. 15 秒不是固定拆分长度；先按剧情形成时段，再由 Provider 能力映射实际请求时长。
13. 风格自动校验仅使用 PromptStyleGate，不建设图片视觉理解、视频抽帧或结果级 StyleConformanceGate。
14. 外部 JSON 只允许创建新剧集或填充空白剧集；不支持合并、覆盖或追加到非空剧集，且导入不触发任何媒体生成任务。

这些默认值只有在真实代码/Provider 约束证明不可行时才需要重新评审，不再作为启动 Phase 0/1 的产品阻塞项。

## 23. 项目与剧集中心及外部 JSON 导入

### 23.1 项目列表

项目列表不是纯入口网格。每张项目卡必须显示：

- 项目名、封面、剧集数量和最近更新时间；
- 最近编辑剧集与上次工作位置；
- 剧本、设定、分镜、短片四阶段的紧凑进度；
- 运行任务数、失败/阻塞数量；
- 项目卡空白区域和键盘 `Enter/Space` 进入项目详情默认“概览”；卡内唯一醒目主动作是“继续剧本/设定/分镜/短片”，直接恢复最近工作位置。不得再放置与卡片点击落点重复的“项目详情”按钮。

项目卡不显示无法解释的综合百分比。四阶段分别显示内容状态，并附 `待确认 N / 已过期 N / 阻塞 N / 失败任务 N` 中非零项；阶段内完成度只能使用可审计的 `已确认对象数/必需对象总数`，不能把生成文件数量折算成进度。

页面头提供“新建项目”和“导入项目归档”。新建项目/首集来源选择器必须直接展示六类来源：空白手工、想法/剧本 AI、小说/长文本分章、外部 AI 协作、直接 V2.1 单集 JSON、已有视频。选择外部 AI 或单集 JSON 时先创建项目壳，再进入对应协作/导入流程；剧集 JSON 与项目归档 ZIP 始终是两个格式和入口。

### 23.2 项目详情

项目详情固定分为：概览、项目设定、剧集、资产。内部路由可继续沿用 `project-bible` 以保持已生成深链可恢复，但所有用户可见名称统一为“项目设定”。不得把低频本地维护工具作为第五个日常创作分区。

- 概览：项目 Look、画幅、可操作待处理项和下一步；
- 项目设定：外部 AI 创作上下文，以及现有项目梗概、Project Look、人物/状态、场景和道具的项目级聚合；
- 剧集：本项目所有剧集及四阶段状态，是剧集制作包的主入口；
- 资产：跨集复用和使用位置；

项目导航右侧提供次级“项目操作”：导出项目备份、从备份恢复、删除项目。备份恢复必须先校验归档和展示影响，恢复提交前创建当前状态备份并使用事务；删除项目进入可恢复回收站，不立即物理删除媒体。完整性检查、媒体重定位、迁移与恢复记录、物理清理统一进入“设置 → 高级数据工具”。其中完整性检查与查看 journal 为只读，媒体重定位须先扫描和确认匹配，物理清理须先 dry-run，并在引用非零、任务活动或路径越界时阻断。

概览只承担项目级聚合和继续工作的导航，不展开完整剧集列表或逐集明细；全部剧集、逐集四阶段状态和剧集操作统一由“剧集”页承载，避免两个页面形成重复事实源。

概览中的剧本、设定、分镜、短片四张状态卡都是项目级汇总入口。点击状态卡进入当前项目的“剧集”页并自动按对应阶段筛选，不得自动选择、推断或默认打开任意剧集；只有“下一步”中的“继续”按钮可以直接恢复具体剧集和最近工作位置。

Project Look 是项目级视觉规则。概览显示代表图、名称、当前版本、批准状态、画幅和使用数量；“查看 Look”打开项目级只读详情抽屉，展示来源、视觉规则、使用与影响范围以及版本记录。“管理 Look”只能进入项目级 Look 工作台，不得默认绑定任意剧集。

“待处理”直接聚合 Gate blocker、必需资产缺失/待确认/已过期以及失败、认证失效、等待外部回填等任务状态，不建立第二套待办数据。概览只显示影响当前推进的高优先级问题，建议最多 3～5 条；每项显示类型、影响对象、原因和唯一恢复动作，完整清单留在对应阶段或任务中心。每项必须携带自身的稳定目标：内容问题使用准确的 `projectId + episodeId + focusId + scenario` 恢复页面和对象焦点，任务问题使用稳定 `taskId` 打开任务中心并定位；不得复用“下一步”或最近工作的剧集 ID。

V2.1 首发不实现完整“最近活动”流。项目头保留最近修改时间，“下一步”保留最近工作位置；导入来源和报告位于剧集详情，迁移 journal、备份及恢复记录位于“设置 → 高级数据工具”。

项目设定采用轻量的三块式信息架构：外部 AI 创作上下文、项目视觉风格 Project Look、生产对象概览。项目梗概、故事基础设定、不可改变的设定和跨集连续性备注统一并入“外部 AI 创作上下文”；人物/状态、场景、道具只显示项目级统计、缺失/待确认摘要和精确处理入口，不在本页形成第二套编辑器。项目资产页维护对象资料、图片、音色、媒体候选、生成任务、资产媒体版本和跨集使用位置；剧集设定负责选择本集实际使用的状态与版本。

项目设定页的主操作固定为“生成外部 AI 上下文”。点击后进入当前项目的剧集创建/导入中心 `external-ai-context` 场景，依次选择目标集、根据当前项目数据生成预览、检查缺失项并复制 Markdown 或下载；外部创作完成后回流 V2.1 JSON，并继续走五步导入确认。上下文默认包含项目简介与题材、故事基础设定、不可改变的设定、跨集连续性备注、相邻剧集与最新剧本、人物当前状态、场景/道具索引、Project Look 摘要和目标集信息。缺失可选资料时明确显示“未填写/暂无”并允许继续，不把资料完整度提升为生成 Gate。

本页只允许直接编辑项目简介、题材、故事基础设定、不可改变的设定和跨集连续性备注；使用显式保存/取消，未保存离开必须确认，保存失败保留草稿。人物、场景、道具卡进入项目资产的对应 `focusId` 筛选；Project Look 卡进入项目级 Look 工作台且不携带 `episodeId`。外部 AI 新增生产对象必须经导入预览逐项接受、忽略或修正，不得静默覆盖已有 Look、资产当前使用项或现有对象，也不得自动触发生成任务。

项目设定不是图片/视频的通用 Prompt 来源，也不是生图或生视频的强制 Gate。生成链不得把项目梗概、世界观、人物背景/关系或跨集剧情连续性整段拼入 Provider Prompt；这些内容只服务外部 AI 创作上下文和人工一致性检查。只有 Project Look，以及已经归一化、明确选入当前任务的人物当前外观/生产状态、场景当前生产状态和道具当前生产状态可以参与生成。当前分镜、参考资产、生成模式、镜头连续性和 Provider 参数继续由对应制作阶段提供。

失效计算只跟踪实际进入任务快照的有效生成输入：人物性格、背景或剧情备注变化不得让既有图片和视频整体过期；外观、当前生产状态或 Look 变化只标记真正引用它们的编译结果和任务。镜头稳定帧、画面位置和相机轴线属于分镜/短片阶段，不得混入项目设定的跨集剧情连续性。

项目设定必须覆盖正常、空项目、信息缺失、加载、局部加载失败、保存失败和复制失败。非必填缺失只提示不阻断；错误保留已加载内容和用户草稿，并提供唯一恢复动作。产品页面不得把 Prompt/Gate/stale/Provider 或“V2.1 首版范围”作为主要说明卡，改用“信息待补充、查看并处理、项目视觉风格”等用户语言；状态不得只靠颜色表达。桌面采用上下文与 Look 两列、生产对象三卡布局，窄屏改为单列并保留完整键盘焦点。

V2.1 首版的项目设定不建设百科式结构化世界观事实库、伏笔追踪器、人物关系图或事件时间线，也不自动推断剧情事实；不承载媒体候选、生成队列、资产删除/回滚、分镜连续性、剧集时间线、直接生图/视频、JSON 差异确认和迁移恢复。生成或复制上下文本身不调用外部模型、不创建剧集，也不产生费用。

#### 23.2.1 项目资产

项目资产采用“生产对象优先”，管理当前项目跨集复用的人物/人物状态（含人物音色）、场景资产和道具，以及它们的当前使用项、媒体候选、版本历史、生成记录和使用位置。它不是包含全部文件的媒体图库：分镜图片和逐镜正式视频候选归分镜阶段，整集审核、环境声、音效、音乐与时间线归短片阶段，全局个人资产库负责跨项目复用；用户从剧集设定进入分镜时，系统自动保存本集实际使用项的 Asset Gate 快照。

首屏固定包含：可解释统计、`全部/人物/场景/道具` 类型导航、搜索和状态/使用/来源/媒体/剧集筛选、最近更新/名称/使用最多/问题优先排序、卡片/紧凑列表切换、批量操作栏及资产详情抽屉。默认卡片视图并保存本地偏好；类型、搜索、筛选、排序和对象焦点写入 URL，页面显示结果数、筛选标签、逐项清除及清除全部。统计项点击后施加对应精确筛选，不得把“人物状态”或“需要处理”退化为全部。统计只显示对象、状态、缺失和任务数量，不生成综合完成百分比。资产卡显示当前使用媒体、业务名、类型、当前版本、候选数、跨集/分镜使用、最高优先级问题和更新时间；人物卡同时显示状态数量、最多三个状态缩略图及音色已设置/未设置、来源和快捷试听。卡片打开详情，编辑、复制、加入个人库、下载与归档等低频动作收进更多菜单。首版每次加载 30～50 项，不提前实现虚拟滚动。

详情抽屉固定为“概览 / 版本与候选 / 使用位置 / 生成记录 / 高级”，五个标签都必须切换到真实内容区，不得只显示静态标题或轻提示。“概览”承担资料编辑、剧情状态、视图参考和参考图管理；“版本与候选”承担目标状态/视图、生成模式、候选使用和四宫格拆分；“使用位置”按剧集/场次/分镜精确跳转；“生成记录”展示渠道、模型、模式、Prompt 快照、时间、状态和失败恢复；“高级”展示正负 Prompt、继承的 Project Look、来源、fingerprint 和受引用保护的归档。生成入口保留 API、ChatGPT 网页、ComfyUI、生成模式、参考图、四视图、自动/人工/负向 Prompt、模型、画幅、费用和统一任务；结果只能进入候选。点击候选卡即保存为该对象或状态的当前使用项，旧 current 回到候选历史；不再显示“临时选中、采用为当前、提交批准”。上传同样进入候选，不能覆盖当前使用媒体；重复 hash 必须选择复用、辅助参考或取消。

人物详情必须在主图下方直接展示全部人物状态切换条，不得只在列表卡片显示“4 个状态”的数量。状态卡至少显示缩略图、名称、默认标记、当前使用/有新候选/缺失问题和使用位置；点击状态后切换该状态自己的当前图、候选、生成设置和影响位置，并提供“新增状态”。概览直接提供“查看候选与生成图片”；版本与候选区必须同时展示目标状态、生图模式、全部候选、生成、上传和两项以上候选的并排对比，不能因为音色归入人物而隐藏人物形象生产入口。人物本体和人物状态只使用本地已有 `SINGLE` 单图与 `TURNAROUND` 三/四视图两种模式，模式按状态独立保存；生成或上传只新增该状态候选，点击候选才更新该状态 current。

“新增资产”采用两步轻量流程：先选人物/场景/道具，再填写该类型最低必要字段；默认仅创建空白草稿，也可选择创建并上传或创建并进入生成参数确认，任何入口都不得未经确认自动提交收费任务。重名必须提供打开已有项、改名创建或取消，禁止静默合并。“从个人资产库添加”提供搜索、类型、预览、版本、许可、项目内重复标记和多选，并明确区分“引用固定版本”和“复制到项目”：前者默认推荐并锁定来源版本，后者创建独立项目副本并保留来源 ID/version/hash；两者都不随库更新自动漂移。重复来源不得静默新增；库出现新版本时只显示更新提示，用户比较后才能派生新项目草稿。项目发布到个人资产库先建立草稿、移除项目私有剧集引用并检查许可，不能静默公开。

人物状态是人物子资产，保留身份主图、四视图、服装/受伤/年龄/妆容/姿态、SD2 身份与音色和历史图。人物音色归人物对象，不建立平级声音资产；形象和音色各自维护候选/current，试听不改选，点击“使用此音色”一次完成改选。音色来源包含已有的本地上传，以及 V2.1 的 TTS 预设、个人素材库固定引用和 Provider 支持时的音频提取；智能音色设计标记为后续增强，未实现前不得作为可用入口。场景资产与叙事场次严格分离，采用“场景对象 → 剧情状态 → 视图参考 → 候选”：时段、天气、照明和损坏属于剧情状态；全景、门口、区域、俯视等属于可自定义视图参考，不硬编码为每个场景必填项。场景生成模式独立于这层关系：单图和四宫格为旧版已有能力，四宫格包含主视角、反向视角、俯视角和补充视角；独立俯视图与全景图是 V2.1 新增预设。四宫格可拆成视图参考候选，但不得自动设为当前使用图。道具采用“道具对象 → 剧情状态 → 视图参考 → 候选”：手持、开合、损坏、耗尽和变形属于剧情状态，正面、侧面和特写属于视图参考。选择候选只更新当前状态/视图组合，不影响其他组合。对白/旁白 owner、环境声、音效、音乐、时间线音量、ducking 和最终混音归 Episode Audio Plan/Cut。

场景详情继承旧版地点、时间、状态、描述、氛围、Prompt、负向提示词、参考图、从图提取、单图/四视图、生成/上传、场景库及影响分镜；道具详情继承名称、类型、描述、剧情用途、Prompt、负向提示词、参考图、从图提取、单图/四视图、生成/上传、道具库及关联分镜。“实际尺寸/比例”和“默认持有人”必须标记为待确认增强字段，不能冒充旧版既有能力。

批量操作只允许生成缺失候选、设置未来默认生成模式、添加/移除标签和归档未使用项；个人资产库固定引用/复制仍在专用流程中逐次确认关系。提交前展示已选、可执行、跳过、阻塞、Provider、模型、任务数、预计费用和并发，部分失败支持仅重试失败项。V2.1 不允许批量生成后自动设为当前使用项，也不允许批量批准或批量物理删除。日常删除使用可恢复归档；被剧集、分镜、任务、候选或交付引用的媒体不能物理删除。永久清理统一由“设置 → 高级数据工具”执行 dry-run、依赖、活动任务和路径边界检查。

对象状态、候选状态、任务状态、使用状态和问题状态必须同时显示，不得用生成失败覆盖已有当前使用项。页面至少覆盖全空、筛选空、无媒体、候选未使用、缺少当前使用项、媒体离线、上传/生成失败、认证过期、外部等待、库离线、版本冲突、引用删除阻断和外部导入待确认；每种状态保留已有数据并提供唯一恢复动作。桌面使用卡片加右抽屉，小屏单列且详情全屏，卡片支持键盘，状态不能只靠颜色。

不得再把项目设置、剧集卡、资产编辑和高风险数据工具混排为一个无层级长页。

### 23.3 剧集列表

每个剧集行显示集号、标题、目标时长、来源、上次工作位置和四阶段状态。外部导入剧集显示“外部来源 2.1”标签，点击只读查看原始 JSON、规范化数据、文件名、SHA-256 和导入报告。主动作恢复最近工作位置；空白剧集显示“编辑或导入”。

剧集中心默认使用紧凑列表，不再重复项目卡片视觉。顶部显示剧集总数、正在制作、需要处理和外部来源四个可解释计数；支持搜索、集号/最近工作排序，以及全部、剧本、设定、分镜、短片阶段筛选。从项目概览阶段汇总进入时自动应用对应筛选；阶段格点击进入该集准确阶段，不能复用其他剧集的最近位置。

列表头主动作是“新建/导入剧集”，打开同一六来源选择器；外部 AI 协作和直接 V2.1 JSON 必须与空白、AI、小说来源同级可见。排序、归档等管理操作进入剧集次级菜单，项目备份/恢复/删除进入项目操作，避免与创作来源竞争。

剧集次级菜单固定提供重命名、复制为草稿、设置目标时长、调整集序、可恢复归档和查看导入来源。复制不复制运行任务；归档不物理删除剧本、资产快照、分镜、候选或来源记录。已有视频来源只登记原始媒体、hash、路径和媒体信息后进入短片时间线，不复制大文件、不自动生成镜头或调用远端 Provider。

外部 AI 协作在剧集中心按“生成创作上下文 → 创建本集任务包 → 用户前往外部会话 → 选择结果 JSON → 统一五步预览导入”执行。ZIP 与单文件任务 JSON 使用同一 `package_id/assets_digest`；等待页可复制任务说明、重新下载任务包和选择结果，关闭页面不丢失 package attempt。想法/剧本 AI 先展示范围、模型和预计费用，结果只保存为可审阅草稿；小说/长文本必须先预览章节、拆集和编号冲突；两者均不自动解析资产或确认阶段。

### 23.4 剧集制作包导入向导

完整制作包导入是项目/剧集级跨阶段操作，入口位于项目详情的剧集列表、新建项目向导及空状态。分镜阶段头不显示“导入外部 JSON”；Production Studio 对已导入剧集只显示紧凑的“查看外部来源”。

导入向导分五步：

1. **目标与文件**：选择创建新剧集或填充空白剧集，读取文件并显示 Schema、文件名和哈希；
2. **剧本与场次**：预览剧集信息、剧本和 `story_scenes[]`；
3. **资产匹配**：逐项确认角色/状态、场景资产和道具的创建、复用与冲突，不允许 JSON 覆盖项目 Look；
4. **分镜与时段**：预览 `shot_packages[]`、`timed_segments[]`、时长闭合及逐时段引用；
5. **确认写入**：汇总创建/复用数量、安全边界和“远端生成费用为 0”，确认后原子写入草稿。

导入成功页提供“查看报告”“进入剧本”“检查设定”“进入分镜”。不自动把导入媒体设为当前使用项，不自动确认阶段，也不自动生成资产图、分镜图、视频或音频。

### 23.5 非空剧集拒绝规则

以下任一条件成立即视为非空：

- 剧本或梗概非空；
- 已有叙事场次或分镜；
- 分镜已有图片、视频或其他媒体候选；
- 已有成功制作包导入记录。

用户选中非空剧集时立即展示阻断说明；正式提交前服务端必须在同一事务中再次检查，防止预览后目标被修改。错误码固定为 `TARGET_NOT_BLANK`。可执行动作只有：选择空白剧集、创建新剧集、取消。不得显示或接受合并、覆盖、追加、忽略检查等动作。

### 23.6 页面级验收

- 项目卡能直接回答最近工作、阶段进度、运行任务和阻塞；
- 项目详情只保留概览、项目设定、剧集和资产四个创作分区，项目操作与高级数据工具职责分离；
- 完整制作包导入入口不出现在分镜阶段主操作区；
- 创建新剧集和填充空白剧集可进入五步预览；
- 非空剧集在预览和提交时均被拒绝，且没有覆盖绕过入口；
- 导入成功只产生结构化草稿，任务中心不出现由导入自动创建的媒体生成任务；
- 导入来源可从剧集列表和 Studio 查看，但保持只读。

## 24. 统一原型剩余页面交互收口

本节记录 2026-09-09 已确认并进入统一原型的其余页面合同。它与第 23 节共同覆盖 17 个注册页面；详细理由见[逐页交互评审决策记录](../../superpowers/specs/2026-09-08-production-studio-v2.1-page-review-decision-log.md)。

### 24.1 剧本阶段

桌面采用“场次导航—正文编辑—版本与检查器”三栏。草稿在输入停止 800ms 后自动保存，并支持 `Ctrl/Cmd+S`；保存失败必须保留浏览器恢复副本，409 时先比较版本。AI 续写、改写、多集生成、项目复制和外部回流都只产生草稿。资产解析先展示新增、变化、删除和人工锁定差异，确认后创建新 revision。“确认剧本”只创建 approved Script Revision，不自动刷新设定、分镜或媒体；下游显示来源变化并允许继续旧快照或主动刷新。

### 24.2 剧集设定

页面用户名称固定为“设定”，说明为“当前剧集使用的资产”。只列当前已确认剧本实际引用的人物状态、场景状态/视图、道具状态和条件音色；项目级生产与候选管理继续进入项目资产。每项同时显示项目 current、本集选择、是否有更新及阻塞原因。项目 current 或 Project Look 变化不得静默改写本集选择。“进入分镜”一次完成预检、不可变 Asset Snapshot 写入和导航；快照至少固定 asset/version id、媒体 hash、音色 revision、Look revision 和选择理由，事务失败不得留下部分结果。

### 24.3 AI 配置与全局任务

AI 配置展示全局默认、项目覆盖和任务快照三个层级，以及用途到 Provider/模型的明确映射。密钥只显示脱敏值；导出不含密钥；导入冲突逐项解决。连接测试不创建生成任务或费用。全局任务按进行中、需要处理、历史分组，动作严格来自 Provider capability。只有 Provider 返回可信进度时显示百分比；否则显示生命周期、已用时、历史耗时区间和“估算/不可用”。ChatGPT 网页任务必须保存 session、attempt 与输入 fingerprint，支持等待、选择结果和同 attempt 重绑。

### 24.4 新建项目与项目归档导入

新建项目先填写项目名、画幅、默认单集时长和输出位置，显式建立可见的最小项目壳，再复用剧集中心的六类来源选择器。创建壳后取消不静默删除项目。

项目归档入口只接受 `local-mini-drama.project-archive@2.1`，不得接受 Episode Package、External AI Result 或 Shot Package。提交前展示 manifest、版本、剧集/媒体/任务数量、缺失媒体、磁盘空间、hash 和名称冲突；默认只导入为新项目。事务失败零写入并保留报告，成功后提供打开项目、查看报告和处理缺失媒体入口。

### 24.5 常规设置与高级数据工具

常规设置只维护工作区、备份保留、媒体/成片/临时目录、默认画幅、默认单集时长和语言。路径离线不得自动改写，保存冲突保留用户未提交值。完整性检查、媒体重定位、迁移与恢复 journal、受引用保护的物理清理继续由“高级数据工具”承载。

### 24.6 个人资产库

库页面支持类型、在线状态、许可和最近使用筛选；卡片/详情展示版本、来源、许可、路径或 Provider URI 和跨项目使用位置。加入项目时必须选择“固定版本引用”或“复制到项目”，两者都不自动随库版本漂移。相同来源 hash 冲突逐项选择；离线媒体保留元数据并提供重定位；有引用的条目只能归档。

### 24.7 自由创作与高级画布

自由创作是可选便捷旁路，不参与四阶段 Gate。图片和视频 Recipe 复用统一 Provider、Generation Job、媒体与候选；提交前显示引用、输出参数、费用与耗时，关闭页面不停止任务。结果必须明确下载、入库、绑定项目资产、加入分镜候选、加入短片时间线或放弃，不能形成无归属文件。

高级画布是标准页面的关系与批量编排投影，不拥有第二套业务数据。它恢复项目、剧集、阶段、焦点与视口，所有对象修改通过共享 command API 与标准页同步；布局单独保存为视图状态。完整 2D 画板、完整 3D 导演台和视频重绘不属于 V2.1，不能显示成可用成品入口。

### 24.8 短片门禁、基础合片与交付

默认 Cut 若仅 `6/9` 必需镜头已有 adopted 候选，或仍有运行/失败任务，Picture Lock 必须禁用并列出逐项阻塞；不能以“已生成候选”替代“已采用候选”。锁画后先形成带 hash 的基础合片母版，再进入技术匹配、创意 Look、可选超分、字幕/水印、混音/响度和编码校验。超分的跳过、成功、失败后回退基础母版都写入 Post Revision；任何后期失败保留基础合片与既有中间结果。编码校验未通过时导出按钮禁用；交付必须显示 Picture Revision → Base Composite → Post Revision → Delivery Revision 的 lineage。

### 24.9 覆盖与原型边界

统一原型入口为 [Production Studio V2.1 完整可交互原型](./production-studio-v2.1-full-prototype.html)。52 个产品能力编号由单一覆盖模型映射到 17 个注册页面，每项具备可导航入口和可查看状态；高风险主流程提供完整交互，普通功能至少展示前置、正常/异常状态、恢复动作和成功落点。覆盖导航器、场景切换和 `data-feature-id` 仅用于评审原型，产品实现不得显示这些开发工具。原型通过不代表 API、SQLite、Provider、FFmpeg 或迁移已经实现。

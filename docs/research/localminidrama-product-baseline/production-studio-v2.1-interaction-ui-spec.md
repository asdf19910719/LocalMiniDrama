## 1. 规格定位

本文把 V2.1 架构母稿落实为页面、组件、状态、操作和视觉规则。它不是另一套架构，也不改变母稿中的 Stage、Approval、Revision、Invalidation、Shot Package、Reference Manifest、Candidate、Timeline Revision 和 Delivery Package。六类来源、外部协作、AI 配置、网页生成、归档、个人库、声音所有权、重拍、任务和危险操作的完整状态转换以[关键交互流程合同](../../superpowers/specs/2026-09-08-production-studio-v2.1-interaction-flow-contracts.md)为准。

本文用于产品评审、交互原型、前端拆分、API 契约检查和验收用例编写。若页面实现需要绕过上述领域对象，必须先修正设计，不能通过组件本地状态或 `metadata` 旁路写入。

> **2026-09-09 呈现口径**：本文较早章节中的用户界面名称“设定 / 短片 / 项目资产 / Project Look / 全局任务抽屉”，统一按“本集素材 / 成片 / 项目素材 / 项目画面风格 / 独立任务页”解释。内部路由 `assets/cut` 和 Revision、Gate、Picture Lock 等领域概念保持不变。第 24 节及[个人创作者体验收敛设计](../../superpowers/specs/2026-09-09-production-studio-v2.1-personal-creator-simplification-design.md)是最新呈现规则。

## 2. 体验目标

### 2.1 用户每时每刻都能回答五个问题

1. 我在哪个项目、哪一集、哪个阶段、哪个对象？
2. 当前阶段完成到什么程度？
3. 哪些内容已批准，哪些只是草稿或候选？
4. 下一步是什么，为什么某个动作不可用？
5. 这次操作会影响哪些对象、触发多少任务、是否可能产生远端费用？

### 2.2 设计原则

- **阶段清晰**：主流程只有剧本、本集素材、分镜、成片四个阶段。
- **决策可见**：草稿、候选、当前使用、需要更新和当前剪辑已固定不能只靠颜色区分；内部批准和版本编号按需展开。
- **影响先于执行**：上游修改和批量生成先展示影响范围，再确认执行。
- **普通优先、高级不丢**：默认界面展示业务语义；H3、槽位、工作流参数在高级模式中完整可用。
- **本地优先**：本地编辑、预览和零远端费用工具直接执行；远端生成明确确认。
- **渐进展开**：列表/轨道负责扫描，详情抽屉负责编辑，历史/日志按需展开。
- **不中断长任务**：离开页面后任务继续，状态在全局任务抽屉中可追踪。
- **证据可追溯**：任何当前产物都能打开来源、输入快照和历史版本。

## 3. 路由与上下文恢复

### 3.1 目标路由

```text
/projects
/projects/:projectId
/projects/:projectId/episodes/:episodeId/script
/projects/:projectId/episodes/:episodeId/assets
/projects/:projectId/episodes/:episodeId/storyboard
/projects/:projectId/episodes/:episodeId/cut
/library
/quick-create
/settings/ai
/settings/tools
```

`:stage` 只允许 `script | assets | storyboard | cut`，未知值回退到该集最近有效阶段；没有历史时进入 `script`。

高级画布不是第五个阶段。唯一入口是当前阶段路由加 `?mode=advanced`。旧 `/projects/:projectId/episodes/:episodeId/canvas`、`/film/:id/canvas`、`/drama/:id/canvas` 不注册、不跳转，也不保留旧页面。

### 3.2 缺少上下文时的行为

| 情况 | 行为 |
|---|---|
| 项目不存在 | 显示 404 内容卡，提供返回项目列表；不自动创建 |
| 项目存在但剧集不存在 | 回到项目详情的剧集区，显示“剧集不存在或已移除” |
| 项目没有剧集 | 项目详情显示创建/导入剧集空状态 |
| 阶段依赖未批准 | 页面允许只读浏览；生成主动作禁用并列出 blocker |
| 未注册或旧 URL | 使用统一 404；提供进入 `/projects` 的动作，不加载旧实现 |

### 3.3 URL 可恢复状态

阶段必须体现在 URL。当前镜头/资产和模式使用查询参数，便于刷新和分享本地链接：

```text
?shot=42
?asset=character:18
?mode=advanced
?panel=history
```

纯视觉状态（抽屉宽度、轨道滚动位置）保存在本地偏好，不写入服务端领域数据。

## 4. 桌面端应用骨架

### 4.1 完整布局

```text
┌────────┬──────────────────────────────────────────────────────────┐
│ 全局栏 │ 项目 / 剧集切换       保存态 任务 预算 主题 用户/设置   │ 56
│  64    ├──────────────────────────────────────────────────────────┤
│        │ 剧本        设定        分镜        短片    阶段进度/阻塞 │ 48
│        ├──────────────────────────────────────────────────────────┤
│        │                                                          │
│        │                    当前阶段工作区                         │
│        │                                                          │
│        ├──────────────────────────────────────────────────────────┤
│        │ 可选：镜头轨 / 时间线 / 批量操作栏                       │
└────────┴──────────────────────────────────────────────────────────┘
```

### 4.2 全局栏

宽度 64px，图标加 tooltip，依次为：

1. 项目；
2. 资产库；
3. 快速创作；
4. 高级画布；
5. 任务；
6. 设置。

当前入口使用 3px 左侧指示条和强调背景；不能只改变图标颜色。64px 模式不显示文字，1280 以下不再缩窄。

### 4.3 制作头

高度 56px，固定于顶部：

- 左侧：返回项目、项目名、剧集下拉；
- 中部：最近保存状态，格式为“已保存 · 14:32”或“保存失败 · 重试”；
- 右侧：撤销/重做（当前阶段）、任务按钮及数量、远端预算摘要、主题、更多。

项目名和剧集名过长时分别截断，悬浮显示完整值。切集前如有未保存草稿，先尝试自动保存；失败时弹出“重试/放弃本地草稿/留在此页”，不得静默丢失。

### 4.4 阶段导航

四个阶段固定显示：剧本、设定、分镜、短片。每项包含：

- 序号或图标；
- 阶段名；
- 内容状态文字：未开始、进行中、可确认、已确认、已过期；
- 完成度，如 `8/10 镜已确认`；
- 需要处理时另列 blocker、warning 和失败任务数量徽标；“被阻塞”不得替代内容状态。

点击后允许浏览任何阶段。只有高资源生成、批量执行、Picture Lock 和最终导出受 Gate 限制。

### 4.5 阶段头

每个页面内容区顶部固定 56px 阶段头：

- 左：标题、简短状态、最近批准版本；
- 中：筛选、搜索或当前选择摘要；
- 右：一个实心主 CTA，最多两个次级按钮和“更多”；
- 存在 blocker 时，在阶段头下方显示可折叠阻塞条。

禁止把超过三个同级按钮平铺到阶段头。

## 5. 状态语言

### 5.1 对象 revision 状态

| 状态 | 标签文案 | 图标/形状 | 允许操作 |
|---|---|---|---|
| draft | 草稿 | 空心圆 | 编辑、删除、提交确认 |
| ready_for_review | 待确认 | 时钟 | 对比、确认、退回 |
| approved | 已确认 | 勾选圆 | 用于下游、创建新修订 |
| stale | 已过期 | 警告三角 | 查看原因、查看旧批准版本、重新编译 |
| superseded | 已被新版本取代 | 历史标 | 查看、比较、从此派生 |

`locked` 仅用于 Timeline/Picture/Post/Delivery 不可变 revision。`blocked` 是 Gate 评估，`generating/failed` 是任务状态，`waived` 是独立豁免记录；它们以 badge 与对象/阶段主状态并列显示，不进入对象 revision 枚举。

所有状态同时显示文字与图标；颜色只是辅助。

### 5.2 阶段状态

```text
not_started → in_progress → ready_for_review → approved
approved --上游变化--> stale --复核/重编--> ready_for_review
```

Gate 有 blocker 时保持当前阶段内容状态并返回 `block`；不把阶段持久化为 `blocked`。阶段批准不自动批准其内部所有草稿；批准 API 必须验证必需对象，明确跳过项写独立 waiver，记录原因、创建者和输入变化过期规则。

### 5.3 自动使用与确认默认值

V2.1 关闭资产候选自动使用。批量生成成功只产生候选；技术检测通过只标记 `technically_eligible`，不会自动成为 current。用户点击候选卡即执行“使用此图/使用此音色”并保存 current pointer，不再经过“临时选中→采用为当前→对象批准”三层动作。剧本、Look、Shot、Picture Lock 和交付仍保留各自必要的阶段确认。

单机阶段确认者为 `local-user`；一次性迁移生成的记录可标记 `system`，并说明迁移来源。字段预留未来多人身份，不在 V2.1 引入 RBAC。

## 6. Script Stage｜剧本

### 6.1 页面布局

```text
┌ 场次/结构 240 ┬──────────── 剧本编辑器 fluid ────────────┬ 检查 320 ┐
│ 集/场次列表    │ 标题、场景头、动作、角色对白、旁白       │ 结构摘要 │
│ 搜索/过滤      │ 当前修订、行级问题标记                   │ 角色场景 │
│ 变更点         │                                          │ 问题列表 │
└────────────────┴──────────────────────────────────────────┴──────────┘
```

最小工作区宽度 1024。1280 以上三栏；1024–1279 时右栏变为抽屉；小于 1024 进入有限编辑模式并提示使用桌面宽屏进行完整制作。

顶部返回入口固定为“返回剧集”，其后显示“项目名 / 第 N 集”面包屑；页面主标题只写“剧本”，副标题写当前草稿与已确认版本的关系，不罗列“版本比较、素材解析”等系统能力。阶段导航允许提前浏览后续内容；后续内容若仍基于上一版已确认剧本，必须持续显示来源提醒，且未确认的新草稿不得启动依赖它的收费生成。

### 6.2 核心操作

- 新建/粘贴/导入剧本；
- 从梗概生成草稿；
- 解析角色、场景、道具和镜头建议；
- 查看修订历史与 diff；
- 保存草稿；
- “提交确认”进入检查；
- “确认剧本”创建 Approval Revision；
- 已确认剧本的编辑自动派生新草稿，不覆盖批准版。

### 6.3 保存规则

- 停止输入 800ms 后自动保存当前草稿；
- 保存中显示非阻塞状态，不弹 toast；
- 失败后保留浏览器内草稿，顶部显示持久错误条；
- `Ctrl/Cmd+S` 立即保存；
- 冲突时显示服务端版本和本地版本 diff，不采用最后写入覆盖。

用户层只显示“有未保存修改 → 保存中 → 已保存于 HH:mm”；不得同时出现“已保存”和“有修改”。800ms 是内部防抖参数，界面只写“更改会自动保存”。“立即保存”只在有修改、失败或快捷键触发时可执行；“恢复副本”只在浏览器副本与服务端内容不同时出现。保存失败、离线、冲突和保存中均禁用剧本确认，保存成功也不等于已经确认。

场次编辑区明确分离场次标题、内/外景、地点、时间与正文；列表显示全集总字数和预计成片时长。重命名、上下移动、复制和可撤销删除属于 P1 单场次操作，不引入多选批量编辑。

### 6.4 检查器

分为“阻塞”和“建议”：

- 阻塞：无法解析的场次、缺失正文、未知角色归属、重复 id、非法导入；
- 建议：场次过长、镜头过密、角色名近似、场景缺视觉信息、对白过长。

点击问题跳转到对应场次和文本位置。确认时只阻止“阻塞”项，建议可带说明忽略。

### 6.5 上游变更影响确认

修改已批准剧本并再次确认前，弹出影响摘要：

```text
本次修订影响
  3 个场次已修改
  2 个角色设定可能过期
  6 个镜头 Shot Package 将过期
  4 张已确认镜头图可继续保留，但需复核

[查看明细] [取消] [确认新修订]
```

确认只写入新 revision 和失效标记，不自动触发任何远端生成。

草稿保存后允许后台轻量解析，确认前统一称“预计素材变化”，逐项展示新增、属性变化、删除候选、人工锁定以及采用/忽略决定；解析失败不妨碍保存草稿，可稍后重试。确认检查必须展示场次数、字数、预计时长、预计素材变化，以及角色、场景、分镜和已生成媒体的具体受影响数量。

### 6.6 主 CTA

- 草稿未检查：`检查并提交`；
- 已检查可确认：`确认剧本`；
- 已确认无新改动：`进入设定`；
- 有阻塞：禁用 CTA，按钮下或阻塞条说明具体原因。

已有已确认版本且新草稿检查完成时使用“确认新版本”；当前草稿已经确认且没有新修改时使用“进入本集素材”。保存失败改为“重试保存”，409 冲突改为“解决版本冲突”。确认过程显示“确认中…”，成功后才切换 CTA；任何确认都不得自动删除、覆盖或重新生成已有媒体。

AI 创作必须使用候选流程：选择创作方式、范围、模型/服务和预计消耗，异步生成后展示原文/候选差异；只有“应用到草稿”才改变正文并进入未保存状态。选段改写在没有有效文本选区时禁用。多集生成和从其他项目复制保留在次级选项，不与当前场次续写、改写竞争首屏。

## 7. Assets Stage｜设定

### 7.1 页面信息架构

顶部标签：`总览`、`画风`、`角色`、`场景`、`道具`。人物音色在角色卡和人物详情中管理，不再建立平级“音色”标签；标签右侧显示待处理数量。

页面提供模式切换：

- **标准模式**：卡片、列表、详情抽屉和批量操作；默认。
- **高级画布**：自由组织和查看依赖；写操作仍调用统一 V2 API。

### 7.2 总览

总览首屏依次为：

1. readiness：Look、角色（含本集音频策略实际要求的音色）、场景、道具已确认数；
2. blocker：缺失、失败、过期；
3. 最近变更及下游影响；
4. 各资产类型缩略列表；
5. 批量预检入口。

用户点击“进入分镜”时，系统自动检查 Look 已确认，且本集实际使用的必需人物状态、场景和道具有可用 current。人物音色采用条件 Gate：只有本集所选音频策略明确需要该人物音色且 current 缺失时才阻断；人物无对白、使用无需参考音色的 H3 原声或允许 Provider 默认音色时只提示。检查通过即保存本集实际引用的精确资产版本/hash 快照并跳转，不增加独立的阶段确认或批准动作；项目资产之后改选不会静默改写该快照。

### 7.3 Look/画风

Look 卡片显示：

- 名称、代表图、来源（预设/自定义/导入）；
- 业务描述和可读标签；
- 适用的图片/视频 Provider 能力摘要；
- 当前修订号和批准状态；
- 使用该 Look 的镜头数量。

打开详情抽屉后分为：

1. 视觉意图：媒介、线条、色彩、光线、质感、时代/类型；
2. 样例图：上传/生成/选择；
3. 编译预览：标准模式只读摘要，高级模式显示 prompt 片段和 Provider 输出；
4. 版本与影响：历史、diff、受影响资产/镜头；
5. 操作：保存草稿、生成样例、提交确认、确认版本。

选择卡片不等于批准；批准后卡片显示“项目当前 Look”。场次或分镜覆盖分别显示“本场覆盖”“本镜覆盖”，不得出现不存在的 Episode Look 或“当前用于本集”。

### 7.4 角色/场景/道具卡

卡片只保留扫描所需信息：

- 缩略图或音色波形；
- 名称、类型和一行描述；
- 当前使用版本；
- 草稿/过期/失败/缺失标签；
- 被多少镜头使用；
- 快捷“打开详情”和“生成候选”。

编辑字段、Provider 参数、负向 prompt、身份锚点、造型阶段、历史候选全部进入详情抽屉，避免恢复当前横向宽卡片。

### 7.5 详情抽屉

桌面宽 440px，可拖至 640px；打开后保持列表上下文。固定结构：

1. Header：名称、状态、关闭；
2. Preview：当前批准版 + 候选数量；
3. 基础设定；
4. 版本/变体；
5. 生成 Recipe 与引用；
6. 使用位置；
7. 历史与 provenance；
8. Footer：保存、生成候选、提交/确认。

角色额外包含身份锚点、造型状态和人物声音身份。人物卡直接显示音色已设置/未设置、来源和快捷试听；人物详情的“版本与候选”提供“人物形象/人物音色”切换。音色记录稳定的语言、口音、年龄感、音质描述、来源许可和 Provider 能力；愤怒、耳语、哭腔、语速、停顿等表演要求属于对白/时段，不固化为人物音色属性。场景包含时段/天气变体；道具包含比例/持有关系。

### 7.6 批量生成预检

任何远端批量生成先显示：

- 选择范围：全部/缺失/已过期/手选；
- 将跳过：已确认、生成中、无必需输入；
- Provider 和模型；
- 预计任务数；
- 费用：已知估算或“Provider 未返回价格”；
- 并发数；
- 失败策略：继续其余任务；
- 完成行为：进入待确认，不自动批准。

主按钮文案必须具体，如 `创建 8 个远端任务`，不能只写“确定”。

## 8. Storyboard Stage｜分镜

> 本章由 2026-09-10 分镜页重设计（STORYBOARD-021）整体替代 STORYBOARD-020 的三栏四区方案。
> 布局基准为 RunningHub 分镜页五区结构，交互素材来自当前产品版本（FilmCreate 分镜卡片）。
> 设计依据见 `docs/superpowers/specs/2026-09-10-production-studio-v2.1-storyboard-redesign-design.md`。

### 8.0 方案 B 的界面语义

分镜阶段采用“场次—分镜—时段”：

- 场次是剧本叙事分组；设定阶段的 `scenes` 在 UI 中统一称为“场景资产”；
- 分镜是一次视频生成单元，不增加用户可见的“视频段”层；
- 每个分镜含 1～N 个时段，单时段是常规合法形态；
- 时段以连续时间码表达动作、运镜、对白、声音以及场景资产/角色/道具的生效范围；
- 15 秒只作为特定 Provider 的上限或规格，不作为自动拆分长度和必须填满的目标。

### 8.1 桌面布局（RunningHub 式五区）

```text
┌ 页头：阶段导航（剧本 → 设定 → 分镜 → 成片）＋ 异常状态条（仅异常场景显示）
├ 工具栏：场次 ▾ · 镜头 ▾ · ‹上一镜｜下一镜› · x/y 已采用 ‖ 批量生成 · 更多 ▾
├────────────┬──────────────────────────┬──────────────────┐
│ 左：镜头检查器  │ 中：时段提示词工作台（核心）        │ 右：视频审核（大区域）    │
│ 出场角色       │ 引用素材 chips（@图片N）          │ 大视频主预览             │
│   （可点击预览） │ 时段卡（时码+画面动作+对白声音，      │ 候选胶片条               │
│ 分镜场景       │   可编辑/拆分/合并/上移/下移）        │ 用于本镜/撤销/重试        │
│ 场景道具       │ 分镜图提示词（可编辑/可恢复自动拼装）   │ 生成历史（抽屉）          │
│ 首尾帧衔接     │ H3 提示词条（状态芯片+生成按钮        │                       │
│ 分镜图候选      │   +可折叠可编辑草稿）              │                       │
│   （生成/上传）  │ 生成条：用 H3 生成视频              │                       │
├────────────┴──────────────────────────┴──────────────────┤
│ 镜头轨：筛选 · 逐镜缩略卡（图/视频状态）· 进入成片审核（x/y）     │
└─────────────────────────────────────────────────────────────┘
```

输入（左＋中）与输出（右）分离：**分镜图与素材同属“输入”，放左栏**（与 RunningHub 的 `故事板 | 分镜图` 标签位一致）；**视频是“输出”**，独占右侧大预览区。主页面本身不允许横向滚动，镜头轨可横向滚动。标题副文案显示 `镜头 3/9 · 4 镜已采用 · 2 镜待生成 · 1 镜失败`。

一级工具栏只保留场次选择、当前镜头、上一镜/下一镜、完成度、批量生成；以下结构操作进入“更多”菜单：

- `更新分镜结构`：只读取当前剧集已确认剧本，展示结构模型、预计费用/耗时与新增/变化/拟删除/不变镜头差异；人工锁定进入冲突处理，确认后创建新分镜版本，不删除原版本及图片/视频候选历史；
- `导入分镜文件`：V2.1 支持 Excel `.xls/.xlsx`、CSV `.csv` 与 `shot-package@2.1` JSON，经选择文件、解析/字段映射、结构预览、资产匹配、版本差异、确认写入后创建新分镜版本；DOCX/普通文本 AI 辅助解析留待后续；完整 Episode Package 固定转到剧集页导入；
- `导出分镜资料`：HTML 分镜表 / SRT 字幕草稿 / Shot Package；
- `高级画布`：以只读关系视图进入，不建立第二套业务数据。

两个结构入口均不得直接覆盖当前结构，也不能因结构重建而删除媒体历史。页面恢复参数为 `scene / shot / tab(image|video) / candidate`。

### 8.2 左栏：镜头检查器与分镜图

左栏为单列检查器，不再提供分区切换。固定自上而下：

- 分镜号、计划时长、自动保存状态（`已自动保存 / 有未保存修改 / 保存中 / 版本冲突 / 保存失败`）；
- 出场角色：每行头像、名称与人物状态（变体）；缺失引用以红色标记；**每行可点击**，打开素材预览抽屉（大图、类型、本集状态、版本信息、出现时段与 `@图片N` 槽位说明）；
- 分镜场景：场景资产及版本，同样可点击预览；
- 场景道具：道具资产引用，同样可点击预览；
- 首尾帧衔接：`镜头 N-1 尾帧 → 本镜首帧`，显示 `已衔接 / 可衔接 / 等待上一镜完成`；
- **分镜图区**：当前图与候选以缩略图横排展示（当前项绿色描边），底部提供 `生成分镜图` 与 `上传图片` 入口。点击缩略图打开大图预览抽屉，内含该图使用的图片提示词与 `设为当前分镜图` 按钮；上传的图片直接进入候选，不自动替换当前图。

“管理镜头引用”打开引用管理抽屉：按出场角色 / 分镜场景 / 场景道具三组列出引用（名称、固定版本状态、移除按钮），每组下方提供从项目素材目录添加的入口（已在本镜的素材不重复出现）。本镜场景是结构性的，不可移除。任何增删即时重排中栏引用 chips、令 H3 草稿标记 `引用已变化`（需重新编译），并同步刷新自动拼装的分镜图提示词（手工覆盖的不受影响）。保存失败保留本机恢复副本，409 展示双方差异并只允许合并为新版本或载入最新版。

素材预览抽屉在类型与本集状态之外，展示版本信息（本集固定版本、素材库最新版本、是否可换绑）与 `出现时段`（该素材被哪些时段的提示词直接提及），并提供两个操作：`换绑到最新版`（仅当素材库有更新时可用；换绑后 H3 与自动分镜图提示词标脏）与 `在素材库中查看`（跳转项目素材页）。

### 8.3 中栏：时段提示词工作台（核心）

中栏是本页的核心生产区，自上而下五段：

**引用素材 chips**：以 `@图片1 林夏 · 酒店制服 v3` 形式列出本镜全部引用及时段内生效标记；缺失引用红色标记。chips 顺序即生成时的槽位顺序。

**时段提示词编辑器**（`STORYBOARD-004`）：每个时段一张卡片，显示 `开始—结束` 时码、可直接编辑的画面与动作、对白与声音，以及资产生效芯片；提供拆分、与下一段合并、上移、下移。拆分/合并/重排必须真实改变数据、保持时间连续闭合与总时长，并进入 `dirty → saving → saved`。只有一个时段时不显示结构不足警告；单时段与多时段都是合法结构。

**分镜图提示词**：默认按“时段画面描述 + 引用素材 + 项目风格”自动拼装并折叠展示；可展开直接编辑（标记 `已手工覆盖`，之后自动拼装不再覆盖它），也可一键 `恢复自动拼装`。左栏「生成分镜图」确认抽屉内展示本次将使用的完整提示词。

**H3 提示词条（一等公民）**：H3 是本项目的特有视频链路，直接在中栏展示而非折叠进高级设置：

- 状态芯片：`AI 生成 / 已编辑 / 保存中 / 校验通过 / 校验失败 / 需要更新`；
- `生成 H3 提示词` 按钮（来源变化后变为 `重新生成 H3 提示词`），生成前在确认抽屉展示结构输入（时段数、引用槽位）、来源与预计处理时间，并说明不会覆盖人工草稿；
- 可折叠草稿编辑器：展示来源摘要与四项校验（结构校验、引用槽位、音频语义覆盖、提示词风格），可直接编辑并 `保存并校验`；
- 状态机：`ai-generated → dirty → saving → valid/invalid`；来源变化 → `stale`。dirty/saving/stale/invalid 全部阻断视频提交；系统永不覆盖人工文本。

改选当前分镜图会立即令 H3 草稿 `需要更新`，并使已完成旧视频显示“基于旧分镜图”、退出完成计数；重新生成或改回后恢复。时段或分镜图提示词的实质变化同样通过来源判定让 H3 草稿过期。

**生成条**（`STORYBOARD-009`）：

- `用 H3 生成视频 · ¥x.xx`：主生成按钮，先打开费用确认抽屉（生成数量、输出时长、模型与规格、预计耗时、预计费用），确认后提交；
- **生成数量**：确认抽屉内可选 1 / 2 / 3 个候选（默认 1）；费用按数量乘算，耗时按并行提交口径展示；提交时一次创建 N 个并行任务，成功结果只追加候选、不自动采用；取消与重试逐任务执行，互不影响其他任务；
- 生成中显示 `取消当前任务`；取消进入可追踪的 `cancel-requested`，保留任务记录与输入快照；
- 输出时长只有单一字段（如 `7s`），不再区分“计划时长 / 请求时长”；预计耗时单行显示，不再拆分排队/处理/总耗时；
- 生成前联合检查四行：引用素材、模型能力、生成描述（H3 草稿）、重复任务。任一未通过时按钮禁用并逐行展示原因，生成中也禁用重复提交。

模型不支持当前结构时显示具体边界与两种动作：`按建议拆分分镜`、`更换模型`；不得静默删除时段或场景引用。Provider 不支持必需引用时阻止执行；可选引用默认阻止并提供显式降级勾选，降级写入任务快照。

### 8.4 右栏：视频审核

右栏专属视频审核（分镜图已在左栏），提供本页面积最大的媒体区域：

- 大尺寸主播放器：点击视频候选必须把可读媒体成功载入主播放器，播放器显示来源图片与 H3 草稿是否仍为当前；只有成功载入的 ready 候选可 `用于本镜`；
- 候选胶片条：当前镜的全部视频候选；每类候选只有一个权威指针，采用新候选同步取消旧候选标记，支持 `撤销采用`；视频采用不强制完整播放；
- 面板头 `生成历史` 按钮打开历史抽屉：每次任务的提交时间、完成时间、规格、状态与采用标记；失败任务保留在历史中，`按原输入重试` 创建新任务，不覆盖失败记录；
- 取消进入可追踪的 `cancel-requested`；生成中禁用重复提交。

任务成功只追加候选，不自动采用、不替换旧候选，也不自动进入成片。历史中不展示 revision、fingerprint、Manifest、AV contract 等技术概念；站位图、连续性面板、动作预演等辅助视图已从分镜页移除（连续性收敛为左栏首尾帧衔接，见 8.6）。

### 8.5 镜头轨

镜头轨固定在底部并与场次选择、当前镜头下拉、上一镜/下一镜共用同一选中状态。每个缩略块包含：编号、时长、图片任务状态、视频任务状态。交互：

- 单击切换当前镜头；
- 按状态筛选未完成、失败、处理中；
- `[` / `]` 键切换上一/下一镜（输入框聚焦时不拦截）；
- 镜头重排与结构调整统一走“更新分镜结构 / 导入分镜文件”，镜头轨不提供拖拽重排。

完成度只统计仍基于当前输入且明确采用的镜头。`进入成片审核（4/9）` 点击后列出“有候选未采用或需确认旧结果 / 尚未生成 / 生成失败”。成片审核可提前进入（软进入），但开始合片仍受全部必需镜头采用或有效豁免的硬门禁。

### 8.6 首尾帧衔接（连续性的收敛形态）

连续性不再使用独立面板，收敛为左栏一行：

- 显示上一镜尾帧与本镜首帧的衔接关系与状态；
- `已衔接`：上一镜采用视频的尾帧已作为本镜首帧参考；
- `可衔接`：上一镜已有采用视频，可一键建立衔接；
- `等待上一镜完成`：上一镜尚无采用视频。

衔接必须由用户确认建立；系统不得自动形成不可见的级联依赖，断开衔接不删除任何媒体。

### 8.7 批量操作

批量生成入口在工具栏，打开批量预检抽屉，固定三项：

- 生成缺失分镜图；
- 生成缺失镜头视频；
- 重试失败任务。

抽屉先展示命中/跳过/阻塞数量、预计任务数和费用或资源；正式视频批量生成仍需明确确认。单个失败不回滚已成功镜头，完成后保留成功项并按失败原因分组提供重试（`只重试失败项`）。

### 8.8 阶段完成条件

每个必需镜头必须满足：

- 引用的剧本与资产版本仍有效；
- H3 草稿（或该 Provider 对应的生成描述）处于 `valid` 且来源未过期；
- 有明确采用的候选视频，或基于当前输入的有效豁免；
- 没有会影响当前输入的运行中或未知任务。

分镜图是生成输入而非通用完成条件：镜头可以只有视频候选而无分镜图（文生视频路径），但一旦分镜图被用作视频参考，它就成为输入的一部分并参与失效传播。`进入成片审核` 是阶段导航，不等于所有镜头已完成；Picture Lock 仍由成片页 Video Gate 硬性要求。

## 9. Cut Stage｜短片

> 本章由 2026-09-10 短片页重设计（CUT-002）整体替代原三标签 NLE 方案。
> 短片页的定位是**成片前的"验收间"+ 一键合片出口**：看（逐镜审看 + 连续播放）→ 补（回分镜修复）→ 合（带声音策略的一键合成）→ 出（导出 MP4/SRT）。
> 设计依据见 `docs/superpowers/specs/2026-09-10-production-studio-v2.1-cut-redesign-design.md`。

### 9.1 单屏工作台（无标签页）

```text
┌ 页头：阶段导航（剧本 → 设定 → 分镜 → 短片）＋ 异常状态条（仅异常场景显示）
├ 工具栏：场次 ▾ · 镜头 x/y · x/y 已完成 ‖ 连续播放 · 生成成片（主按钮，硬门禁）
├──────────────────────────────┬────────────────┐
│ 大播放器（整页最大区域）              │ 成片设置（右栏）      │
│ · 逐镜审看：上一镜/播放/下一镜          │ · 整集 BGM：关/开     │
│ · 连播模式：按镜头顺序连播已完成镜头      │ · 旁白 TTS：开/关     │
│ · 来源标注：候选 A · 用于本镜 /          │ · 字幕烧录：关/开     │
│   基于旧分镜图（沿用手语）              │ · 超分：关/开（可选）   │
│ · 「回分镜修复此镜」                  │ · 完成度与门禁说明     │
├──────────────────────────────┴────────────────┤
│ 成片结果条：生成中进度(可取消) | 成片 vN 预览 · 导出 MP4 / SRT · 历史版本 │
├───────────────────────────────────────────────┤
│ 底部镜头时间线：复用分镜页镜头轨（缩略 + 状态着色），点击切镜                │
└───────────────────────────────────────────────┘
```

页面不提供多轨时间线、裁剪、变速、转场、声音归属矩阵、字幕编辑器和七步后期链。镜头顺序就是分镜顺序；要调整结构或重选候选，回分镜页操作。阶段导航不得把"能进入分镜"误写为"分镜完成"：仅有 `6/9` 镜头已完成时显示 `分镜 · 需处理 3 镜`，但仍允许进入短片页提前审片。

### 9.2 审片（大播放器 + 镜头时间线）

- 大播放器默认逐镜审看当前镜头，显示来源标注（`候选 A · 用于本镜` / `候选 A · 基于旧分镜图` / `生成中` / `未生成`）；
- 「连续播放」按镜头顺序连播全部已完成镜头，模拟观众视角检查节奏与衔接；再次点击停止并回到逐镜模式；
- 上一镜/下一镜与镜头时间线、镜头下拉共用同一选中状态；
- 底部镜头时间线平铺本集全部镜头（场次筛选可用）：已完成显示候选来源，生成中/失败/未生成按状态着色；
- 「回分镜修复此镜」跳转到分镜页并定位当前镜头；短片页不提供重新生成、候选比较或改选——候选的权威指针在分镜页。

### 9.3 成片设置与一键合成

合成设置固定四项，全部有安全默认值：

- **整集 BGM**：不使用 / 整集 BGM（继承剧集音频策略的曲目）；
- **旁白 TTS**：开（混入旁白配音）/ 关；
- **字幕烧录**：开（烧录进画面）/ 关（仅导出 SRT）；
- **超分增强**：开（更清晰、耗时更长）/ 关。

合成保留镜头原声；旁白 TTS 与 BGM 混音，不覆盖原声。声音来源冲突不在此页逐段裁决——若上游存在归属冲突，在此显示一条提示并引导回分镜/音频设置处理。

「生成成片」为硬门禁：全部镜头"用于本镜"或有效豁免、无基于旧分镜图的未确认镜头、无运行中任务时才可提交；否则禁用并逐条展示缺失/失败/生成中/需确认镜头。确认抽屉展示四项设置摘要后提交。合成是可恢复任务：进行中显示进度并可取消（`cancel-requested` 保留记录）；失败保留镜头、候选与设置，按原设置重试。

### 9.4 成片版本与导出

- 每次合成生成新的**成片版本**（成片 v1、v2…）；结果条显示当前版本预览、文件名、时长与分辨率，历史版本可回看但互不覆盖；
- 导出内联在结果条：**导出 MP4**（默认输出）与**导出 SRT 字幕**（可选）；
- 页面不展示 Picture Lock、Post/Delivery revision、后期链步骤、交付检查清单等工程语义；这些在产品内部执行（基础合片 → 统一规格 → 项目风格 → 可选超分 → 字幕 → 混音 → 编码），UI 只呈现一个合成任务的进度与终态。

### 9.5 状态与恢复

场景固定为 7 种：`loading`、`empty`（本集无已采用镜头，引导返回分镜）、`blocked`（有镜头未完成，可审片但不可合成）、`stale`（有镜头基于旧分镜图，可审片，合成前建议确认）、`composing`（合成中，可取消）、`compose-failed`（按原设置重试，中间结果保留）、`exported`（导出成功，可打开输出目录与比较历史版本）。每种状态都有明确恢复动作；交付失败不删除成片与中间结果。

## 10. 全局任务抽屉

### 10.1 入口与布局

点击制作头任务按钮打开右侧 420px 抽屉，不离开当前阶段。顶部显示：运行、排队、失败、已完成筛选和总并发。

每个任务项显示：

- 任务类型和对象，例如“镜头 08 · 视频生成”；
- Provider/工具和模型；
- 状态、进度、提交/开始/完成时间、实际排队/处理/总耗时；运行中显示已运行和预计剩余区间；
- 远端费用：估算/实际/未知/本地零费用；
- 所属项目、剧集和可跳转对象；
- 查看输入、日志、取消、重试、打开结果。

### 10.2 状态契约

统一前端投影：

```text
queued | running | waiting_external | succeeded | failed | cancelled | unknown
```

`waiting_external` 表示任务已停在用户登录、外部网页操作、文件回填或人工确认，任务项必须显示“需要处理”和恢复入口。`unknown` 用于进程中断、Provider 查询失败或状态无法对账，不能直接显示“失败”。重试必须复用输入快照并使用幂等键，除非用户显式创建新候选。

### 10.3 通知

- 当前页短任务成功：对象内联更新，不刷屏 toast；
- 后台批次完成：一次汇总通知；
- 失败：任务抽屉徽标 + 对象内联错误；
- 需要用户登录/外部网页操作：持久“需要处理”项；
- 远端费用变化：仅在执行前和账单回填时提示。

## 11. 通用弹窗与抽屉

### 11.1 三类容器

| 容器 | 用途 | 关闭规则 |
|---|---|---|
| Detail Drawer | 查看/编辑资产、候选、历史 | 未保存时确认；Esc 可关闭 |
| Generation Sheet | 配置单次或批量生成 | 执行后关闭或固定到任务抽屉 |
| Confirm Dialog | 删除、批准、失效、Picture Lock、远端费用确认 | 必须明确按钮文案；不允许点击遮罩误关高风险确认 |

弹窗中不再打开第二层弹窗；需要深层内容时在原容器内切换标签或跳转完整页。

### 11.2 生成 Sheet

固定顺序：对象/范围 → Recipe/Provider → 引用与能力 → 参数 → 任务/费用摘要 → 执行。高级参数默认折叠，但摘要必须显示其是否使用默认、项目覆盖或单次覆盖。

### 11.3 历史与 provenance

历史面板按时间倒序展示 revision、操作者、来源、变更摘要、使用状态。点击某项可查看：输入 revision、prompt 编译结果、引用快照、Provider 参数、任务日志和输出 hash。敏感凭据始终脱敏且不进入导出 manifest。

## 12. 错误、加载、空状态与离线

### 12.1 加载

- 页面骨架只覆盖尚未返回的区域；阶段导航和上下文始终可用；
- 媒体用固定比例占位，避免布局跳动；
- 超过 2 秒显示“正在加载什么”；超过 10 秒提供重试；
- 后台任务不使用阻塞全屏 loading。

### 12.2 空状态

空状态必须说明“为什么为空”和“下一步”：

- 无剧集：创建剧集/导入剧集包；
- 无角色：从已批准剧本解析/手动添加；
- 无候选：检查输入并生成/上传；
- 筛选无结果：清除筛选；
- 媒体离线：定位文件/查看来源/从候选恢复。

### 12.3 错误分级

- 字段错误：字段下方说明；
- 对象错误：卡片/镜头内联；
- 批次错误：摘要成功/失败/跳过并可筛选失败项；
- 系统错误：页面错误条，保留用户草稿；
- 数据迁移/完整性错误：阻止危险写入，提供迁移报告或诊断包，不自动重置。

错误文案包含发生对象、原因、是否已保存、可执行动作。禁止只显示“操作失败”。

### 12.4 离线与 Provider 不可用

本地页面和本地素材应继续可读写。远端动作显示离线/未配置/认证过期/限流/余额不足等不同状态；本地预览、编辑和零费用处理不因远端离线整体禁用。

## 13. AI 配置、作用域与能力

### 13.1 配置层级

```text
全局默认
  < 项目覆盖
    < 剧集/阶段 Recipe
      < 单次任务覆盖
```

表单字段旁显示来源标签，例如“全局默认”“项目覆盖”。单次覆盖只写入任务快照，不反向修改全局配置。

### 13.2 Provider Capability

后端返回的 capability schema 同时驱动：

- 模型选择器；
- 画幅、尺寸、时长和数量字段；
- 多时段支持、最大时段数、多场景支持和最大场景资产数；
- 引用槽位数量和类型；
- 首尾帧、参考音频、遮罩等开关；
- 前端禁用原因；
- 后端最终校验；
- 任务输入快照。

能力加载失败时不使用过期前端常量猜测；可显示最近缓存及时间，但远端执行前必须重新校验。

### 13.3 个人创作者默认配置契约

AI 配置页同时解释四层解析顺序：本次任务覆盖 → 项目默认 → 全局默认 → 安装默认；任务创建后保存不可变的 Provider、模型、能力、费用和输入快照。一次性通道必须回到当前任务配置 Drawer，预填 Provider 并重新执行能力预检，不得写回项目或全局默认。

默认通道卡片显示适用任务类型、网络/本地来源、费用口径、可否提供可信进度、取消/暂停能力、是否需要用户在场和当前可用性。ChatGPT 网页环境检查至少展示检查时间、诊断、对新任务是否阻断和对运行中任务是否有影响；修复、重新绑定和一次性改用都进入 Drawer 或明确目标页，禁止仅用 Toast 表示失败。

Provider 编辑使用 Drawer，密钥只进入本机安全存储，不进入项目、导出文件或任务快照。零费用测试依次检查地址、认证、模型列表和 capability；模型列表失败、停用、本地不可用、证书/代理错误、部分能力、模型下线、保存冲突/失败、密钥格式错误和快照不一致都必须给出原因、影响范围和恢复动作。

业务映射按“创作与协作 / 图片、视频与声音 / 后期处理”分组，覆盖剧本、图片、视频、TTS、外部 AI、基础合片、超分和音频后期。导入配置不携带密钥或浏览器授权，冲突逐项选择保留本机、采用导入映射或跳过；导出显示包含和排除项，并在最终确认前再次提示脱敏范围。

## 14. 快速创作、媒体库与高级画布

### 14.1 快速创作

全局入口通过“更多工具 → 自由创作”进入，仅提供快速图片和快速视频两个 Recipe，不参与四阶段 Gate。生成前可不绑定项目，但页面必须允许选择项目/剧集上下文；副标题明确提示“如果最终用于项目，请在生成前或保存时选择项目和剧集”。

点击 Recipe 先打开配置 Drawer，不直接提交。配置至少包含 Prompt、参考素材、画幅、分辨率、Provider/模型、生成数量；视频额外包含首帧、尾帧、参考视频/音频、输出时长，H3 结构编辑默认折叠到高级设置。参考素材需校验格式、大小、数量、Provider 支持类型和本地可访问性。

提交路径固定为“配置 → 预检 → 费用/耗时确认 → queued → running”。预检显示引用、Provider 能力、输出参数、预计费用、排队与处理时间、失败重试策略和输入快照；只创建统一 `canonical-generation-job`，关闭页面不会停止任务。取消必须经过 `cancel_requested`，Provider 未确认时显示状态未知，禁止伪造已取消。

成功先进入“已生成、尚未归档”，必须提供实际媒体预览、任务/Attempt、提交与完成时间、实际费用和归档状态。结果去向包括下载、加入个人资产库、绑定项目资产、加入指定剧集/场次/镜头候选、加入指定剧集时间线；每个去向都先选择真实目标并检查版本、锁定和时间线冲突。关闭未归档结果必须让用户选择保存或明确放弃，不能留下孤儿文件；任务历史保留所有输入、候选、失败和归档记录。首发不做批量生成。

### 14.2 媒体库

顶部组合筛选：项目、剧集、对象类型、媒体类型、Provider/工具、状态、日期、标签、是否被使用。卡片标题优先显示业务名称，如“镜头 08 · 视频候选 3”，文件名作为次级信息。

详情显示来源、输入快照、使用位置、版本关系、文件属性和完整本地路径。移动/重新定位文件必须更新索引，不能静默复制大文件。

### 14.3 高级画布

画布通过当前阶段的 `?mode=advanced` 展示剧本 revision、Look、资产版本、Shot Package、引用、候选、时间线和任务关系。默认执行 `Fit selection`，提供小地图、缩放、过滤和影响路径高亮。

画布编辑必须调用与标准模式相同的命令 API；禁止直接修改旧 metadata。删除节点只删除关系或草稿时要明确，已批准/被使用对象不能从画布直接物理删除。

## 15. 视觉系统

### 15.1 设计令牌

采用语义令牌，不在组件中硬编码品牌色：

```text
bg.canvas / bg.surface / bg.elevated
text.primary / text.secondary / text.muted / text.inverse
border.default / border.strong / border.focus
accent.primary / accent.hover / accent.subtle
status.info / success / warning / danger / stale / locked
overlay.scrim
```

浅色和深色主题保持同一语义。强调色只用于主 CTA、当前选择和焦点；状态色不取代文字标签。

### 15.2 尺寸与密度

- 基础间距：4px 网格；常用 8/12/16/24/32；
- 控件高度：紧凑 28、默认 36、主 CTA 40；
- 圆角：卡片 10、输入 8、标签 999；
- 正文字号：14px；次级 12px；页面标题 20px；
- 单行正文行高不低于 1.45；
- 缩略图统一比例，角色可 3:4，场景/镜头 16:9，道具 1:1；
- 一屏不展示超过一个主要阴影层级，以边框和背景层级为主。

### 15.3 选择、批准与焦点

- 当前选中：强调边框 + 浅强调背景；
- 当前确认版本：勾选标签；Project Look 使用“项目当前 Look”；项目资产媒体使用“当前使用”，不显示对象级批准；
- 键盘焦点：2px focus ring，与选择状态同时存在；
- hover 只显示快捷动作，不承载唯一信息；
- stale 使用警告图标和原因文字，不把旧产物染成不可读颜色。

## 16. 响应式与窗口策略

| 宽度 | 策略 |
|---:|---|
| ≥1440 | 完整多栏，任务抽屉覆盖或挤压由用户选择 |
| 1280–1439 | 完整主流程，侧栏使用最小宽度 |
| 1024–1279 | 次要检查器改抽屉，保留镜头轨和主预览 |
| <1024 | 项目浏览、剧本轻编辑、任务和媒体预览可用；分镜/时间线提示切换宽屏 |

V2.1 不承诺移动端完整生产，但不能出现页面级水平溢出导致基础导航不可用。

## 17. 键盘与可访问性

- `Ctrl/Cmd+S` 保存当前草稿；
- `Ctrl/Cmd+K` 全局搜索/命令；
- `Esc` 关闭最上层抽屉/菜单，不丢弃未保存内容；
- 左右方向键或 `[` `]` 切换镜头；
- 空格控制视频/时间线播放，输入框聚焦时不拦截；
- `J/K/L` 可作为高级播放快捷键；
- 所有图标按钮有可访问名称和 tooltip；
- 关键状态不只使用颜色；
- 正文、控件和焦点对比度达到 WCAG AA；
- 抽屉打开后正确管理焦点，关闭后回到触发元素；
- 减少动画偏好下禁用大幅位移动画和持续闪烁。

## 18. 分析与可观测性

本地优先不等于无诊断。默认只保存本地产品事件，不上传，至少记录：

- 进入阶段、阶段确认/退回；
- blocker 类型；
- 批量预检的命中/跳过/取消；
- 任务状态变化和错误类别；
- stale 原因和重编范围；
- 候选采用/拒绝；
- Picture Lock 和 Delivery Gate 结果；
- 页面性能：首屏、镜头切换、媒体预览。

任何远端遥测必须单独告知并由用户开启，不包含剧本文本、prompt、媒体和凭据。

## 19. 页面级验收摘要

### 19.1 应用壳

- 项目、剧集、阶段和当前状态始终可见；
- 可跨阶段浏览，不误触未批准下游的高成本操作；
- 长任务离开页面后仍可追踪；
- 刷新恢复当前阶段和选择对象。

### 19.2 剧本

- 草稿自动保存且冲突不静默覆盖；
- 已批准剧本编辑会派生新修订；
- 确认前展示检查和下游影响；
- 新 revision 只让实际受影响对象过期。

### 19.3 设定

- Look 的草稿/确认版本，以及角色（含条件使用的人物音色）、场景、道具的当前使用项/候选明确；
- 资产详情不挤入横向宽卡片；
- 批量远端生成明确范围、任务数和费用可知性；
- 修改资产当前使用项能查看受影响剧集和镜头；已确认剧集快照不被静默改写。

### 19.4 分镜

- 200 镜可流畅切换，主页面无水平溢出；
- Shot Package、Reference Manifest 和 Provider 能力可查看；
- 单时段与多时段均可保存和生成；时段时间码连续闭合；
- 不以 15 秒或 Provider 最大时长强制扩写分镜；
- 多场景分镜不被静默降级，不支持时给出拆分或换模型建议；
- 计划时长与 Provider 请求时长的差异可见；
- PromptStyleGate 可查看具体通过项或阻塞项，不展示结果级风格评分；
- 不支持引用被阻止或经用户明确降级；
- 图片与视频候选均可比较、采用、追溯和回退；正式视频任务可单镜或批量提交，成功不自动采用；
- 连续性引用可见且可断开。

### 19.5 短片

- 页面主入口明确为镜头审核，首次生成不与整集审核混为同一步；
- 每镜视频候选与最终时间线使用项可追溯，改选候选不静默替换 Timeline clip；
- 时间线每次关键编辑保存 revision；
- Picture Lock 后不直接变更；
- 超分或后处理失败可回退到基础成片；
- Delivery Package 包含成片、可选字幕、manifest 和报告。

## 21. 已确定的默认决策

为避免实施阶段重复确认，以下作为 V2.1 默认值：

1. 架构母稿继续作为唯一目标架构，在其上迭代，不另起平行设计；
2. 本地优先，单一 `local-user` 操作者；自动批准默认关闭；
3. 四阶段目标路由采用 `/projects/:projectId/episodes/:episodeId/:stage`；
4. 未批准上游允许浏览下游，但阻止高资源批量执行和依赖其正确性的锁定/交付；
5. 本地预览和零远端费用工具可直接执行；远端生成先确认范围、Provider、数量和费用可知性；
6. 标准模式默认，高级字段和画布按需进入；两者共享领域 API；
7. 桌面完整体验从 1280px 起，1024px 自适应，低于 1024px 不承诺完整分镜/剪辑；
8. 后期默认顺序为技术匹配 → 创意 Look → 可选超分 → 字幕/水印 → 音频响度 → 编码校验；
9. 时间线 Picture Lock 后只读，修改必须派生新 revision；
10. RunningHub 的账户、钱包、公开剧场、强制水印、团队审批不进入本地 V2.1 主线。
11. 分镜采用“场次—分镜—时段”方案 B；分镜是一次生成单元，视频是候选结果，时段数量为 1～N。
12. 15 秒不是固定拆分长度；先按剧情形成时段，再由 Provider 能力映射实际请求时长。
13. 风格自动校验仅使用 PromptStyleGate，不建设图片视觉理解、视频抽帧或结果级 StyleConformanceGate。
14. 外部 JSON 只允许创建新剧集或填充空白剧集；不支持合并、覆盖或追加到非空剧集，且导入不触发任何媒体生成任务。

这些默认值只有在真实代码/Provider 约束证明不可行时才需要重新评审，不再作为启动 Phase 0/1 的产品阻塞项。

## 23. 项目与剧集中心及外部 JSON 导入

### 23.1 项目列表

项目列表不是纯入口网格。每张项目卡必须显示：

- 项目名、封面、剧集数量和最近更新时间；
- 最近编辑剧集、当前阶段及该阶段可解释进度；
- 非零的生成中、待处理和需要更新数量；
- 项目卡空白区域和键盘 `Enter/Space` 进入项目详情默认“概览”；卡内唯一醒目主动作是“继续第 N 集 · 剧本/本集素材/分镜/成片”，直接恢复最近工作位置。点击后短暂显示恢复状态并阻止重复提交。不得再放置与卡片点击落点重复的“项目详情”按钮。

项目卡不显示无法解释的综合百分比，也不同时展示四组单位和分母不同的阶段计数。完整四阶段汇总放在项目概览；卡片只显示最近工作阶段的可审计进度。用户文案统一为 `生成中 N / 待处理 N / 需要更新 N`，不得使用容易误解的“阻塞”“已过期”。运行任务摘要进入项目过滤后的任务页，其余问题进入项目概览。

页面头提供唯一主动作“新建项目”和次动作“导入项目备份”。新建项目/首集来源选择器按个人版规则首屏展示“我有剧本、让 AI 帮我写、我有制作包”，空白创建、小说拆集和已有视频进入更多开始方式；剧集制作包与完整项目备份始终是两个格式和入口。

项目查找只承诺搜索项目名，输入 280ms 后更新。搜索 `q`、状态 `status` 和排序 `sort` 写入 URL；状态选项固定为全部、制作中、需要处理、已完成、已归档，排序固定为最近更新和项目名称。页面显示匹配数；无结果必须提供清除条件。卡片/列表偏好保存到本地，列表模式使用紧凑行布局。

封面来源依次使用项目封面、最新成片、当前分镜和低占用占位。所有项目都位于本地时不重复显示“本地项目”；仅目录离线、外部位置或备份恢复等特殊情况显示位置标签。正常“本地可用”在顶栏弱化，离线或项目索引异常时再提升为提醒。

页面状态必须覆盖：保留主标题和主操作位置的 Loading；同时提供新建和导入备份的 Empty；与真实筛选连通的 No Results；可继续本地编辑的 Offline；定位具体项目及任务入口的 Task Paused；不暗示文件丢失且提供重新读取、只读重建索引和高级数据工具的索引加载失败。52 功能覆盖与场景切换只允许出现在评审构建，正式产品不得呈现。

### 23.2 项目详情

项目详情固定分为：概览、剧集、项目素材、项目设置。内部路由可继续沿用 `project-bible` 和 `project-assets` 以保持已生成深链可恢复，但用户可见名称不得泄漏旧术语。不得把低频本地维护工具作为第五个日常创作分区。

- 概览：项目画面风格、画幅、可操作待处理项和下一步；
- 项目设置：外部 AI 创作上下文，以及现有项目梗概、Project Look、人物/状态、场景和道具的项目级聚合；
- 剧集：本项目所有剧集及四阶段状态，是剧集制作包的主入口；
- 项目素材：跨集复用和使用位置；

项目导航右侧提供次级“项目操作”。第一层必须是轻量 Context Menu/Popover，直接列出“导出项目备份、从备份恢复、移入回收站、高级数据工具”，不得先打开大型操作 Drawer 再让所有按钮都显示“打开”。导出备份和恢复再进入带范围/影响预览的 Drawer；移入回收站进入确认层且不立即物理删除媒体；高级数据工具跳转独立页面。备份恢复必须先校验归档和展示影响，恢复提交前创建当前状态备份并使用事务。完整性检查、媒体重定位、迁移与恢复记录、物理清理统一进入“设置 → 高级数据工具”；其中完整性检查与查看 journal 为只读，媒体重定位须先扫描和确认匹配，物理清理须先 dry-run，并在引用非零、任务活动或路径越界时阻断。

概览只承担项目级聚合和继续工作的导航，不展开完整剧集列表或逐集明细；全部剧集、逐集四阶段状态和剧集操作统一由“剧集”页承载，避免两个页面形成重复事实源。项目 Hero 压缩为封面、名称、单行简介、题材/画幅/集数/更新时间和“返回项目列表”；名称、简介与封面编辑留在项目设置。首屏将“下一步”和“待处理”并列，随后依次显示项目阶段概览和项目画面风格。

概览中的剧本、本集素材、分镜、成片四张状态卡都是项目级汇总入口，并统一使用“集”作为统计单位。卡片显示各阶段的已确认/已完成、制作中、需处理和未开始剧集分布；不得混入素材项数、镜头数或某一集的分母。点击状态卡进入当前项目的“剧集”页并自动按对应阶段筛选，不得自动选择、推断或默认打开任意剧集。

“继续工作”必须基于独立持久化的 `ResumePosition`，至少保存 `projectId + episodeId + stage`，并按阶段选择性保存 `sceneId、shotId、workspaceTab、inspectorSection、timelineTime、candidateId、updatedAt`。它表示最近成功保存的可恢复位置，不等同于最近访问位置或当前推荐动作；深链刷新后仍须恢复工作对象、标签/工作区、检查区和候选焦点。若硬 Gate 直接阻断该位置，主动作先引导处理问题并承诺处理后返回；不影响当前位置的其他剧集/对象问题只进入待处理区，并明确影响范围。

Project Look 是项目级视觉规则。概览显示代表图、名称、当前版本、确认状态、画幅和使用数量；用户文案使用“当前风格版本”和“查看风格”，内部技术详情才使用 Project Look。“查看风格”打开项目级只读详情抽屉，展示来源、视觉规则、使用与影响范围以及版本记录；管理入口只能进入项目级风格工作台，不得默认绑定任意剧集。未设置风格不得阻止空白剧本创作，风格变化只使真实引用该版本的结果需要更新。

“待处理”直接聚合 Gate blocker、必需资产缺失/待确认/已过期以及失败、认证失效、等待外部回填等任务状态，不建立第二套待办数据。概览只显示需要人工处理的项目级高优先级问题，建议最多 3～5 条；每项显示类型、影响对象、原因、是否阻断当前恢复位置和唯一恢复动作，完整清单留在对应阶段或任务中心。每项必须携带自身的稳定目标：内容问题使用准确的 `projectId + episodeId + focusId + scenario` 恢复页面和对象焦点，任务问题使用稳定 `taskId` 打开任务中心并定位；不得复用“下一步”或最近工作的剧集 ID。

概览状态必须覆盖：空项目（创建第 1 集）、Loading（稳定项目头/返回入口/分区导航与内容骨架）、Load Failed（保留壳并重新加载）、Storage Offline（只读查看、禁用继续、重新连接和查看任务）、Needs Attention（硬 Gate 联动主动作）、All Complete（查看或导出最新成片）和 Project Missing（返回项目列表或检查本地数据）。不得注册与默认内容相同的虚假 `blocked` 场景。

V2.1 首发不实现完整“最近活动”流。项目头保留最近修改时间，“下一步”保留最近工作位置；导入来源和报告位于剧集详情，迁移 journal、备份及恢复记录位于“设置 → 高级数据工具”。

项目设置采用四段式视觉顺序：第一行并列“项目资料”和“项目画面风格”，随后是“生产对象概览”，最后是“外部 AI 创作”。页面 Header 不放页面级保存或外部 AI 主按钮；每个区域独立完成编辑、保存和状态反馈。项目资料维护名称、封面、画幅、题材、默认单集时长和输出偏好，本地项目位置只读并把移动/修复交给项目操作或高级数据工具。外部 AI 创作上下文只维护故事基础设定、不可改变的设定和跨集连续性备注，不与项目资料共用表单或 Dirty 状态。

项目画面风格在默认页显示当前版本、状态、画幅和引用摘要。“更换画面风格”必须提供预设/自定义两层入口、预设搜索与选择；确认前展示真实引用数、将标记需要更新数、保留历史数及“不会自动重新生成”，确认后创建新风格版本。查看历史、比较版本和设为当前属于项目级操作，不得携带 `episodeId`。高级 Look 节点编辑器延后，不阻断基础风格选择。

人物、场景、道具只显示项目级数量、状态数量与最高优先问题，使用“查看/创建人物、场景、道具”携带对应 `focusId` 进入项目素材；候选、媒体生成、版本与跨集使用仍只在项目素材维护。生产对象摘要不得形成第二套资产详情编辑器。

“外部 AI 创作”卡内分离三个动作：编辑创作上下文、复制创作上下文、创建外部 AI 制作任务。复制动作在抽屉预览纳入来源并可复制或下载 Markdown，不先要求选择目标集；制作任务进入剧集中心统一来源和 `EpisodeTargetSelector`，再执行“选择目标 → 生成上下文 → 创建任务包 → 外部创作 → 选择结果 → 五步导入”。缺失可选资料只提示不阻断。外部 AI 新增生产对象仍须在导入预览逐项接受、忽略或修正，不得静默覆盖已有 Look、素材当前使用项或现有对象，也不得自动触发生成任务。

项目资料和创作上下文编辑器必须覆盖 Idle、Dirty、Saving、Save Failed、Storage Offline 与草稿恢复。初始保存禁用；首次修改后显示未保存状态；Saving 锁定控件；失败保留输入；有草稿关闭时提供继续编辑/放弃。继续编辑必须同时恢复表单值、Dirty 提示和保存按钮。项目资料变化使已生成协作上下文显示“需要更新”；复制失败保留预览并可重试或下载，任务包失败可重试或打开任务中心。

项目设定不是图片/视频的通用 Prompt 来源，也不是生图或生视频的强制 Gate。生成链不得把项目梗概、世界观、人物背景/关系或跨集剧情连续性整段拼入 Provider Prompt；这些内容只服务外部 AI 创作上下文和人工一致性检查。只有 Project Look，以及已经归一化、明确选入当前任务的人物当前外观/生产状态、场景当前生产状态和道具当前生产状态可以参与生成。当前分镜、参考资产、生成模式、镜头连续性和 Provider 参数继续由对应制作阶段提供。

失效计算只跟踪实际进入任务快照的有效生成输入：人物性格、背景或剧情备注变化不得让既有图片和视频整体过期；外观、当前生产状态或 Look 变化只标记真正引用它们的编译结果和任务。镜头稳定帧、画面位置和相机轴线属于分镜/短片阶段，不得混入项目设定的跨集剧情连续性。

项目设置必须覆盖正常、空项目、信息缺失、加载、局部加载失败、保存失败、存储离线、上下文需更新、复制失败和任务包失败。非必填缺失只提示不阻断；错误保留已加载内容和用户草稿，并提供唯一恢复动作。产品页面不得把 Prompt/Gate/stale/Provider 或“V2.1 首版范围”作为主要说明卡，改用“信息待补充、查看并处理、项目画面风格”等用户语言；状态不得只靠颜色表达。桌面采用资料与风格两列、生产对象横向摘要和外部 AI 独立区域，窄屏改为单列并保留完整键盘焦点。

V2.1 首版的项目设定不建设百科式结构化世界观事实库、伏笔追踪器、人物关系图或事件时间线，也不自动推断剧情事实；不承载媒体候选、生成队列、资产删除/回滚、分镜连续性、剧集时间线、直接生图/视频、JSON 差异确认和迁移恢复。生成或复制上下文本身不调用外部模型、不创建剧集，也不产生费用。

#### 23.2.1 项目资产

项目资产采用“生产对象优先”，管理当前项目跨集复用的人物/人物状态（含人物音色）、场景资产和道具，以及它们的当前使用项、媒体候选、版本历史、生成记录和使用位置。它不是包含全部文件的媒体图库：分镜图片和逐镜正式视频候选归分镜阶段，整集审核、环境声、音效、音乐与时间线归短片阶段，全局个人资产库负责跨项目复用；用户从剧集设定进入分镜时，系统自动保存本集实际使用项的 Asset Gate 快照。

首屏固定包含：人物、场景、道具、需要处理四项统计；`全部/人物/场景/道具` 类型导航；搜索、简化状态和排序；“更多筛选”；卡片及详情抽屉。使用情况、来源、媒体、所在剧集和已归档收入“更多筛选”，条件仍可组合并写入 URL；默认卡片视图并保存本地偏好，紧凑列表作为已确认的低频显示偏好放入更多区域。批量栏不常驻，只有用户点击“选择多个”并真正选择素材后才出现。人物状态不作为一级统计或伪筛选，数量显示在人物卡。素材卡只显示当前图、名称、类型/角色、状态数、主要问题、使用集数和生成中/新候选；资料修订弱化显示，来源、音色时长和精确分镜数进入详情。整卡打开详情，不再重复“打开详情”按钮；低频操作进入 `•••`。

详情抽屉固定为“概览 / 版本与候选 / 使用位置 / 生成记录 / 高级”，五个标签都必须切换到真实内容区。默认只展开当前状态及其主视图，其他状态和视图按需展开；候选集中在“版本与候选”。资料、Prompt 与状态定义称“资料修订”，生成/上传结果称“候选图”，当前选择称“当前图”，三者不得共用一个“当前使用 vN”。点击候选即更新精确 current pointer，旧图回到历史，并显示“已设为当前图｜撤销”；变化只影响未来选择，已确认剧集快照不变。

API、ChatGPT 网页和 ComfyUI 必须共用同一份 Generation Envelope 与确认抽屉：生成对象、状态/视图、模式、通道、项目画面风格、参考图用途、Prompt 预览、输出数、任务数、预计费用、引用数量/权重、格式尺寸和降级结论都在提交前显示。ChatGPT 额外显示浏览器、桥接、登录、结果捕获的零费用环境检查，但不得形成另一套提交语义。确认只创建可恢复的排队任务；关闭抽屉或刷新不丢任务；成功回填只新增候选，失败保留输入快照，不得在确认后立即伪造已完成结果。

人物详情必须在主图下方直接展示全部人物状态切换条，不得只在列表卡片显示“4 个状态”的数量。状态卡至少显示缩略图、名称、默认标记、当前使用/有新候选/缺失问题和使用位置；点击状态后切换该状态自己的当前图、候选、生成设置和影响位置，并提供“新增状态”。概览直接提供“查看候选与生成图片”；版本与候选区必须同时展示目标状态、生图模式、全部候选、生成、上传和两项以上候选的并排对比，不能因为音色归入人物而隐藏人物形象生产入口。人物本体和人物状态只使用本地已有 `SINGLE` 单图与 `TURNAROUND` 三/四视图两种模式，模式按状态独立保存；生成或上传只新增该状态候选，点击候选才更新该状态 current。

“新增素材”采用两步轻量流程：先选人物/场景/道具，再填写最低必要字段；唯一主动作是“创建素材”，创建后进入详情再选择上传或生成，创建本身不调用 AI。重名必须提供打开已有项、改名或仍创建独立项，禁止静默合并。“从个人资产库添加”继续区分“引用固定版本”和“复制到项目”，默认引用固定版本且库更新不自动漂移。

人物状态是人物子资产，稳定身份、外观状态和剧情状态分开；愤怒、哭泣、转头等单镜表演不得创建人物状态。人物默认使用单图，三/四视图只在跨镜一致性需要且通道支持时展开。人物音色归人物对象；从音视频提取前必须确认来源、许可范围和用途。场景资产与叙事场次严格分离，采用“场景对象 → 剧情状态 → 视图参考 → 候选”；单图为默认，四宫格按需补充空间视角。独立俯视图与全景图保留为高级模式，因为下游明确由分镜参考绑定、H3 引用编译和走位/连续性检查消费；它们不占默认第一层，也不显示版本新增角标。道具继续采用“道具对象 → 剧情状态 → 视图参考 → 候选”。

场景详情继承旧版地点、时间、状态、描述、氛围、Prompt、负向提示词、参考图、从图提取、单图/四视图、生成/上传、场景库及影响分镜；道具详情继承名称、类型、描述、剧情用途、Prompt、负向提示词、参考图、从图提取、单图/四视图、生成/上传、道具库及关联分镜。“实际尺寸/比例”和“默认持有人”必须标记为待确认增强字段，不能冒充旧版既有能力。

批量操作必须先进入多选、显示卡片复选框并由用户明确选择范围，再展示固定批量栏和预检；不能用硬编码“已选 5 项”。预检展示所选、可执行、跳过、阻塞、通道、模型、任务数、费用和并发；部分失败保留成功项并只重试失败项。生成结果不自动设为当前图，也不允许批量批准或物理删除。

对象状态、候选状态、任务状态、使用状态和问题状态必须同时显示，不得用生成失败覆盖已有当前图。页面至少覆盖全空、筛选空、Loading、Load Failed、详情加载失败、媒体离线、候选损坏、生成失败、模式不支持、参考图超限、上传格式错误、批量部分成功、当前图保存失败、只读项目、磁盘不足、版本冲突、引用删除阻断和库更新；每种状态保留已有事实并提供唯一恢复动作。

不得再把项目设置、剧集卡、资产编辑和高风险数据工具混排为一个无层级长页。

### 23.3 剧集列表

每个剧集行显示集号、标题、目标时长、用户可理解的来源、上次工作位置和四阶段状态。来源文案使用“外部 AI 导入、制作包导入、已有视频”，协议版本、文件名、SHA-256 与规范化记录进入只读来源详情。主动作必须按 `硬阻塞 → 精确恢复位置 → 空白创建 → 查看成片` 计算，不得仅按最近打开阶段计算。

剧集中心默认使用紧凑列表和紧凑项目头，不重复概览页的大封面、完整简介或项目卡片视觉。顶部计数固定为全部、制作中、需要处理和已完成；空项目必须全部归零。“外部来源”是筛选维度而不是进度指标，不占顶部统计。

第一层筛选固定为全部、需要处理、制作中、已完成、空白、已归档；第二层保留剧本、本集素材、分镜、成片阶段筛选，用于承接概览阶段卡深链。项目空状态、搜索无结果和筛选无结果必须使用不同文案与恢复动作。搜索覆盖集号、标题和上次位置，输入停止 280ms 后更新；“最近工作”使用真实 `lastWorkedAt/updatedAt`，不得以集号倒序模拟。集号升序仍是默认排序。

四阶段单元格由 Gate 投影为五类交互：可进入、未解锁、有阻塞、已完成、需要更新。未解锁视觉置灰并解释前置条件；有阻塞允许进入但直接定位阻塞；已完成打开当前确认版本；需要更新显示原因。空白剧集只允许从剧本格或“开始创建”进入来源选择器，不能直接进入本集素材、分镜或成片。

“继续”恢复真实 locator，至少可包含场次、分镜、Inspector 分区、当前候选和时间线位置。locator 中的对象失效时回到正确阶段并解释，不能承诺恢复却只打开阶段首页。locator、revision、hash 等底层字段默认不暴露给个人用户。

列表头唯一主动作是“新建/导入剧集”。首屏只显示“我有剧本、让 AI 帮我写、我有制作包”；空白、小说拆集、从已有视频开始剪辑进入更多方式，外部 AI 协作是制作包入口内的明确次动作。所有来源在读取内容或创建任务前必须进入同一个 `EpisodeTargetSelector`：已有项目只列“创建第 N 集”和允许填充的空白剧集，新项目只列“创建第 1 集”，非空剧集不进入可选集合。不得默认写入 E01。

剧集次级菜单固定提供重命名、复制为草稿、设置目标时长、调整集序、可恢复归档和查看导入来源。行内“调整集序”与工具栏必须打开同一面板；原型不宣称未实现的拖拽，可使用真实可操作的上移/下移。复制只复制剧本与场次结构，项目素材继续引用固定版本，不复制运行任务、媒体候选、批准状态或外部协作记录。归档不物理删除剧本、资产快照、分镜、候选或来源记录；已归档筛选必须提供恢复入口。

“已有视频”统一改称“从已有视频开始剪辑”。流程只登记原始媒体、hash、路径和媒体信息后进入短片时间线；默认引用原文件并只读保护，也允许显式复制进项目。必须覆盖文件离线、内容 Hash 变化、重新定位和复制入项目；不得暗示视频重绘，不自动生成镜头或调用远端 Provider。

外部 AI 协作在剧集中心按“选择安全目标 → 生成创作上下文 → 创建本集任务包 → 用户前往外部会话 → 选择结果 JSON → 统一五步预览导入”执行。上下文显示目标、生成时间、项目上下文版本和素材快照版本；允许取消非必要信息，绝不输出无关本地绝对路径。ZIP 与单文件任务 JSON 使用同一 `package_id/assets_digest`。

等待态必须持久化为外部协作任务，并同时显示在剧集中心和全局任务中心；至少展示目标剧集、任务包名、创建时间及选择结果、重新下载、复制说明、取消任务。结果回流必须匹配 `package_id`、`assets_digest`、Schema、项目、目标剧集和上下文版本；素材变化时明确提供按冻结快照导入、重新匹配当前素材或放弃并创建新任务，不得仅因 JSON 可解析就导入。

想法/剧本 AI 先展示目标编号、生成范围、模型和预计费用；多集任务逐集保存，部分成功保留成功草稿并只重试失败集。小说/长文本必须先预览章节、拆集和编号冲突；两者均不自动解析资产或确认阶段。

### 23.4 剧集制作包导入向导

完整制作包导入是项目/剧集级跨阶段操作，入口位于项目详情的剧集列表、新建项目向导及空状态。分镜阶段头不显示“导入外部 JSON”；Production Studio 对已导入剧集只显示紧凑的“查看外部来源”。

导入向导分五步：

1. **目标与文件**：展示选择、读取、校验后的真实状态；创建新剧集计算项目下一个可用集号，填充空白保持原集号；显示 Schema、文件名和哈希；
2. **剧本与场次**：展示标题、梗概、剧本前几段、完整剧本入口、场次顺序和空标题/空正文/超长文本等问题；
3. **资产匹配**：逐项确认角色/状态、场景资产和道具的创建、复用与冲突；复用必须固定具体 `assetId + assetVersionId + stateId + mediaVersionId`，不允许 JSON 覆盖项目 Look；
4. **分镜与时段**：预览 `shot_packages[]`、`timed_segments[]`、时长闭合及逐时段引用；Provider 时长/引用数/格式显示“生成前校验”，不得伪装为已通过；
5. **确认写入**：用“10 个分镜 · 14 个时段”等无歧义文案汇总目标、新建人物、复用素材、新建素材、跳过对象、外部媒体、安全边界和远端费用为 0，确认后原子写入草稿。

导入成功必须返回真实 `createdEpisodeId/updatedEpisodeId`，立刻更新对应剧集行、统计、来源标签、最近工作位置并高亮结果；查看报告、检查剧本、检查本集素材和查看导入分镜全部绑定同一结果剧集。导入分镜可查看结构，但确认剧本、本集素材和生成媒体仍遵守 Gate。不自动把导入媒体设为当前使用项，不自动确认阶段，也不自动生成资产图、分镜图、视频或音频。

### 23.5 非空剧集拒绝规则

以下任一条件成立即视为非空：

- 剧本或梗概非空；
- 已有叙事场次或分镜；
- 分镜已有图片、视频或其他媒体候选；
- 已有成功制作包导入记录。

用户选中非空剧集时立即展示阻断说明；正式提交前服务端必须在同一事务中再次检查，防止预览后目标被修改。错误码固定为 `TARGET_NOT_BLANK`。可执行动作只有：选择空白剧集、创建新剧集、取消。不得显示或接受合并、覆盖、追加、忽略检查等动作。

### 23.6 页面级验收

- 项目卡能直接回答最近工作、当前阶段进度、生成中和待处理，不显示四组异构阶段仪表盘；
- 搜索、排序和状态筛选真实改变项目集合，URL 可恢复；Empty、No Results、Offline、Task Paused 和索引加载失败均有明确恢复动作；
- 项目详情只保留概览、项目设定、剧集和资产四个创作分区，项目操作与高级数据工具职责分离；
- 完整制作包导入入口不出现在分镜阶段主操作区；
- 创建新剧集和填充空白剧集可进入五步预览；
- 非空剧集在预览和提交时均被拒绝，且没有覆盖绕过入口；
- 导入成功只产生结构化草稿，任务中心不出现由导入自动创建的媒体生成任务；
- 导入来源可从剧集列表和 Studio 查看，但保持只读。

## 24. 统一原型剩余页面交互收口

本节记录 2026-09-09 已确认并进入统一原型的其余页面合同。它与第 23 节共同覆盖 18 个注册页面；详细理由见[逐页交互评审决策记录](../../superpowers/specs/2026-09-08-production-studio-v2.1-page-review-decision-log.md)。

### 24.1 剧本阶段

桌面采用“场次导航—正文编辑—版本与影响”三栏。草稿在输入停止 800ms 后自动保存，并支持 `Ctrl/Cmd+S`；界面使用唯一保存状态，失败必须保留浏览器恢复副本，409 先比较本机与服务端内容并创建新草稿。空剧本真实为空且不能确认。AI 续写和改写先生成候选、显示差异，应用后才修改草稿；多集生成、项目复制和外部回流也只产生草稿。版本比较展示真实场次/段落差异，历史恢复只复制为新草稿。草稿保存后后台生成“预计素材变化”，确认检查显示场次、字数、时长、素材和下游影响；“确认剧本/确认新版本”只创建 approved Script Revision 与 stale 标记，不自动刷新、删除或重新生成设定、分镜和媒体。确认成功后主操作变为“进入本集素材”。

### 24.2 本集素材

页面用户名称固定为“本集素材”，页头显示“项目 / 第 N 集”并提供“返回剧集”。默认只显示带缩略图的继承摘要、本集新增对象、与项目默认不同的状态、缺失媒体、条件性音色问题、失效引用和进入分镜前的阻塞；项目已准备好的内容自动继承，不要求逐项再次确认。完整继承清单通过次级入口展开；首次准备且尚无可信快照时展开本集全部所需素材。是否首次准备由实际快照/素材状态决定，不得用集号推断。

图片版本差异在本页抽屉并排展示“本集使用图 / 项目最新图”、缩略图、来源、时间和受影响位置；“继续使用原图 / 本集改用新图”只改变本集选择，完整资料编辑才进入项目素材。条件音色在本页抽屉完成试听、预设/素材库/上传/许可音视频提取和“用于本集”，也允许把本集声音策略改为模型默认声音；每次选择后自动重新检查。

唯一主操作固定为“进入分镜”。点击后按 `checking → snapshot-saving → snapshot-succeeded → storyboard` 执行进入分镜前检查和事务型不可变 Asset Snapshot 写入，不增加用户可见的批准、阶段确认或二次确认。检查失败与快照失败分别提供“再次检查 / 重试准备分镜”，媒体离线提供重新定位或换图；人工“重新检查”只在自动检查失败后出现。外部制作包来源额外展示“外部包候选 / 项目当前图 / 本集选择”映射，所有不匹配先人工处理，“准备缺失素材”只为真实缺失项展示通道、模型、参考、任务数、费用与耗时，结果仍作为候选而不自动选用。技术编号、hash 与 revision 默认收进“技术详情”，事务失败不得留下部分结果。

### 24.3 AI 配置与任务页

AI 配置展示全局默认、项目覆盖和任务快照三个层级。ChatGPT 网页、API、ComfyUI 均为一级可选生图通道，ChatGPT 可设为全局或项目默认；解析顺序为本次选择→项目默认→全局默认→安装默认。环境检测只检查浏览器/Profile、桥接、登录和结果捕获，不提交生成、不产生费用。环境异常时保留已保存默认值，只允许修复或仅对本次任务改用 API/ComfyUI。独立任务页按进行中、需要处理、已完成分组，并按项目、剧集、类型、通道筛选；只有 Provider 返回可信进度时显示百分比，否则只显示已用时与历史区间。session、attempt、fingerprint 和原始状态默认折叠到技术详情。

### 24.4 新建项目与项目归档导入

新建项目采用一次明确提交。来源卡只负责选中，不写入项目；项目名称和开始方式齐备后，主动作按来源显示“创建项目并导入剧本 / 生成剧本 / 导入制作包 / 创建空白项目”等。点击后依次校验名称、固定画幅、目标时长、目录权限、重名和空间，原子创建项目并直接打开所选来源流程。底层可建立 Project Shell，但默认 UI 不出现“项目壳”。

名称默认留空；画幅使用固定选项并继承全局默认；时长使用数字输入与 `60/90/120` 秒预设；保存位置只读展示，通过目录选择器更改。首屏来源固定为“我有剧本、让 AI 帮我写、我有制作包”，其余三类进入更多开始方式；外部 AI 协作位于制作包向导内。新项目来源使用首集上下文，只能创建第 1 集，不得显示填充既有空白集或非空目标冲突。提交前取消有修改才确认且零写入；提交后取消来源保留空项目并明确提示。必须覆盖校验失败、创建中、名称冲突、目录不可用、空间不足、创建失败、防重复提交和成功跳转。

项目归档入口采用独立 Page，只接受 `local-mini-drama.project-archive@2.1`，不得接受 Episode Package、External AI Result 或 Shot Package。页面固定为“选择归档、校验并确认、导入结果”三阶段，稳定状态链为 `initial → validating → ready / ready-with-warnings / unsupported → importing → success / partial-success / rolled-back`。主动作必须逐态切换：未选择时为“选择项目归档”，校验/导入中禁用，不支持时仅允许重新选择，可导入警告时为“仍然导入为新项目”，失败时为“重试导入”，成功和部分成功时只显示“打开项目”。

首层只显示项目名、归档版本、剧集、媒体、任务历史和预计新增空间；Manifest、Schema、Hash 与对象数量进入“技术检查详情”。确认区可编辑最终项目名和工作区位置，并展示最终目录、媒体复制/原路径引用策略、剩余空间及包含临时解压的峰值空间。格式/版本、结构、完整性、媒体、空间和名称检查分别具有检查中、通过、警告、阻断状态；缺失媒体属于可导入警告，不得显示为通过。

提交后创建持久化本地任务，显示当前步骤和字节进度，离开页面不停止并可从全局任务中心恢复查看。事务失败零写入，报告失败步骤、临时文件清理和安全重试。媒体缺失形成部分成功，保留引用并提供重定位入口；恢复的历史任务只读，不自动重新执行或调用 Provider。页面从不提供覆盖已有项目的动作，“从备份恢复”只从目标项目内进入。

### 24.5 常规设置与高级数据工具

常规设置只维护工作区、备份保留、媒体/成片/临时目录、默认画幅、默认单集时长和语言。默认值只影响新建项目、新建剧集和新任务；项目级设置优先，任务创建时冻结最终配置。保存按钮按 `clean → dirty → saving → saved / failed / conflict` 变化，无修改时禁用；保存失败保留当前输入，离开页面只在 dirty 时提示。

路径字段不得作为普通文本直接保存。媒体、成片和临时目录每行显示当前状态、权限、可用空间、占用、重叠检查和最近检查时间，并提供“选择目录 / 重新检测”；临时目录额外显示可安全清理大小，清理入口进入高级数据工具。路径不存在、无权限、空间不足、目录重叠、只读和离线都必须保留旧路径，不自动改写媒体引用。

更改工作区必须进入独立向导：选择目录 → 检查数据库和项目结构 → 检查权限与空间 → 检查活动任务 → 迁移范围预览 → 确认迁移并重新打开工作区。预览明确数据库、媒体、任务和备份影响，以及是否复制数据库、复制媒体、保留原目录、是否需要重新打开；有运行中任务时禁止确认危险迁移，迁移前创建备份和回滚点。

备份保留使用有范围限制的数字输入，不允许设置为 0 静默关闭保护；页面显示备份目录、预计占用和“立即创建备份”。存储离线状态要明确区分会影响播放候选/本地任务/合片超分与不会影响剧本/任务记录/已完成元数据。完整性检查、媒体重定位、迁移 journal、备份恢复、引用扫描和物理清理继续由“高级数据工具”承载。

### 24.6 个人资产库

个人资产库是跨项目复用入口，整体优先级为 `IMPORTANT / P1`，不阻塞首集制作。首版只收人物、场景、道具和音色，不把分镜图、镜头视频、成片、BGM 或任意本地文件混成媒体资产。

页面头部只提供“添加到资产库”，进入后选择“从本地文件添加”或“从现有项目保存”。默认卡片网格以预览为第一信息层：人物/场景/道具显示当前缩略图，音色显示试听入口；随后显示名称、类型、可用状态、版本和使用数量。完整路径、Provider URI、hash 和许可条款只在详情抽屉中显示。

工具栏提供搜索、类型（全部/人物/场景/道具/音色）、在线状态（本地可用/文件不可访问/已归档）、来源（项目沉淀/自有素材/Provider）和排序（最近使用/添加、名称）。筛选必须真实改变结果，展示结果数量、已启用条件和清除动作，并覆盖无结果与筛选空态；不要求首版复杂分页、多选或商城推荐。

详情抽屉至少包含“预览、基本资料、版本历史、来源与许可、使用位置、文件状态”六个区段。点击“用于项目”先选择目标项目，再选择“使用这个版本”（默认，固定当前版本，库更新只提醒）或“复制到项目”（创建独立副本，保留来源 ID、版本和 hash）。确认后展示创建的项目对象和打开目标项目素材的入口。被引用条目只能归档，不能物理删除；归档和重新定位都保留已有使用位置。

本地导入采用“文件名/类型 → 预览校验 → 名称/许可 → 导入结果”向导，覆盖格式不支持、损坏、重复 hash、同名不同文件、导入中、失败、部分成功和安全重试。从项目保存只保存明确选中的当前版本，不带入候选、任务或剧集私有信息；相同 source hash 必须并排展示现有/待保存版本，再选择使用已有、保存为新版本或创建独立资产。离线对象在卡片上显示“文件不可访问”，禁止用于新项目并提供重新定位；已有项目引用不得被清空。页面或路由变化时自动关闭旧详情抽屉。

### 24.7 自由创作与高级画布

自由创作是“更多工具”中的可选便捷旁路，不进入默认 Rail，也不参与四阶段 Gate。图片和视频生成复用统一 Provider、Generation Job、媒体与候选；提交前显示引用、输出参数、费用与耗时，关闭页面不停止任务。结果必须明确下载、入库、绑定项目素材、加入分镜候选、加入成片时间线或放弃，不能形成无归属文件。

高级画布只从当前阶段的“高级画布”入口进入，不进入默认 Rail。它是标准页面的关系与批量编排投影，不拥有第二套业务数据；恢复项目、剧集、阶段、焦点与视口，所有对象修改通过共享 command API 与标准页同步。完整 2D 画板、完整 3D 导演台和视频重绘不属于 V2.1，不能显示成可用成品入口。

### 24.8 成片检查、基础合片与交付

默认成片页若仅 `6/9` 必需镜头已有采用候选，或仍有运行/失败任务，“开始合片”必须禁用并列出逐项问题；不能以“已生成候选”替代“已采用候选”。点击开始合片后先提示“当前剪辑将被固定，后续修改会产生新版本”，确认后系统内部创建 Picture Lock 与带 hash 的基础合片母版。超分始终可跳过，失败时直接提供“使用基础成片继续导出”。编码校验未通过时导出按钮禁用；已导出终态不得仍显示超分未决定或编码等待。Picture/Post/Delivery 等 lineage 默认折叠到技术详情。

### 24.9 覆盖与原型边界

统一原型入口为 [Production Studio V2.1 完整可交互原型](./production-studio-v2.1-full-prototype.html)。52 个产品能力编号由单一覆盖模型映射到 18 个注册页面，每项具备可导航入口和可查看状态；高风险主流程提供完整交互，普通功能至少展示前置、正常/异常状态、恢复动作和成功落点。覆盖导航器、场景切换和 `data-feature-id` 仅用于评审原型，产品实现不得显示这些开发工具。原型通过不代表 API、SQLite、Provider、FFmpeg 或迁移已经实现。

### 24.10 全局任务中心（J-01）复审收口

任务中心是跨项目恢复入口，不是团队待办或钱包消费中心。页面固定使用 `进行中 / 需要处理 / 历史` 三个用户页签，按下一步责任人而不是技术字段分组：排队、运行和系统仍在监控外部结果属于进行中；等待选择 JSON、等待登录/授权、Provider 失败、结果缺失和未知状态属于需要处理；成功、失败终态和已取消进入历史。内部 `waiting_external` 必须投影为 `monitoring_external`、`waiting_user`、`blocked_auth` 或 `unknown`。

默认显示紧凑任务行，行内显示项目/集/阶段/对象、任务类型、执行方式/Provider/模型、可信进度或“暂无可信百分比”、预计费用、已用时间和最后确认时间。点击任务主体或“查看任务”打开右侧详情 Drawer，顺序固定为：可理解状态、生命周期时间线、输入快照摘要、Provider/规格、时间与费用、输出候选、错误/恢复、折叠技术详情。主操作必须携带稳定 `projectId + episodeId + stage + objectId + taskId + attemptId` 落到外部 JSON、ChatGPT 环境、AI 配置、分镜/资产/成片候选或任务详情；不得只弹 Toast、不得创建重复任务。

筛选顺序为项目 → 集 → 状态 → 任务类型 → 执行方式/Provider → 时间，并提供对象搜索。深链接聚焦任务时自动切换正确页签、滚动、高亮、打开详情并聚焦主操作。离线状态显示最后确认时间、暂停自动刷新、区分前端与执行器状态，并禁用连接依赖动作。批任务显示父任务和成功/进行中/失败/未知统计，支持仅重试失败项并保留成功结果。成本台账仅记录预计、实际、是否计费/未知；本地执行明确“本地执行，不产生 API 费用”，不引入钱包、充值或团队分配。

### 24.11 高级画布（X-01）复审收口

高级画布保持 OPTIONAL/P2。它只从当前阶段进入，恢复项目、剧集、阶段、焦点对象和视口；上下文标签使用项目名、集号、阶段名和对象名，内部 ID 只放技术详情。关系图必须绘制有方向的连线和关系类型（引用/生成），stale 关系使用虚线与文字表达，选中节点高亮上下游；可提供缩放、Fit selection、缩略导航和多选，但这些都只是视图行为。

节点动作必须按类型精确落点：人物/场景回项目素材 Inspector，分镜回镜头，视频候选回成片审核，任务回任务中心。影响路径为只读 Drawer，列出直接影响、间接影响和不会影响的对象/版本，不自动编译或生成。批量重编译必须经过“选择 → 影响预览 → 确认 → 创建批量任务 → 任务中心跟踪”，预览展示对象数、是否包含已采用候选、预计费用和耗时；部分成功保留成功项并允许仅重试失败项。

布局状态与业务对象状态严格分离：布局未保存只影响视图，保存成功记录 layout revision 和时间，失败保留本地布局；对象修改仍通过标准页面共享命令保存。必须可查看加载、上下文恢复失败、空关系、只读、离线、stale、对象缺失、批量处理中/部分成功和保存失败状态。完整 2D/3D 导演台、画布内独立模型/生成和视频重绘不属于 V2.1。

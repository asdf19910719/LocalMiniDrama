# RunningHub × LocalMiniDrama 全量差异矩阵

> 对比时点：2026-09-08
> RunningHub 证据：[逆向 PRD](../runninghub-product-design/runninghub-reverse-prd.md)、[交互与 UI 规范](../runninghub-product-design/runninghub-interaction-ui-spec.md)、[截图目录](../runninghub-product-design/screenshot-catalog.md)
> LocalMiniDrama 证据：[As-Is PRD](./localminidrama-as-is-prd.md)、[本地截图目录](./localminidrama-screenshot-catalog.md)

## 1. 结论先行

两者并不是“RunningHub 功能完整、LocalMiniDrama 功能缺失”的简单关系：

- RunningHub 在主流程编排、页面分工、标准/自由模式、全站资产/工具/商业化和视觉成熟度上明显领先；
- LocalMiniDrama 在本地优先、Provider 可替换、H3、引用槽位、Director 数据、外部网页回填、任务恢复、剧集包 provenance、音频/合片/超分技术链上有不可丢失的深层能力；
- RunningHub 的多人审批、发布审核、视频重绘内部流程和真实模型质量仍有未验证项，不能作为已确认事实照抄；
- V2.1 应采用“RunningHub 式清晰阶段壳 + LocalMiniDrama 式可追踪生产内核”，而不是视觉复刻或全量重写。

因此，当前已经可以确定目标架构和产品主方向，但不能只拿架构母稿直接开写全部 UI；页面级行为、状态和异常规则由配套 [V2.1 交互与 UI 规格](./production-studio-v2.1-interaction-ui-spec.md) 约束。

## 2. 判定规则

### 2.1 差异状态

- **RH 领先**：RunningHub 已把能力组织成更成熟的用户流程或界面。
- **LMD 领先**：LocalMiniDrama 已有更深或更开放的技术/数据能力。
- **各有优势**：需要组合，不应二选一。
- **共同缺口**：两边都未充分解决，V2.1 需要自主设计。
- **范围不同**：RunningHub 的商业云能力不应直接转化为本地产品需求。
- **未验证**：证据不足，不作为版本承诺。

### 2.2 优先级

- **P0**：生产正确性、数据模型、迁移地基或主流程骨架；首个里程碑必须覆盖。
- **P1**：四阶段完整可用和高频效率；大版本主要范围。
- **P2**：增强工具、规模化管理和体验完善；可在主流程稳定后加入。
- **P3**：商业云、社区或低频扩展；当前只保留接口和信息架构位置。
- **不采纳**：与本地优先定位冲突或无证据支持。

## 13. 明确不照搬 RunningHub 的设计

1. 不强制云账户、钱包或平台积分才能使用本地项目；
2. 不把 RunningHub 调查时点的模型、价格、画幅、分辨率或配额硬编码到产品；
3. 不用平台水印替代用户自己的交付水印；
4. 不把公开剧场/社区作为 V2.1 主流程完成条件；
5. 不把“下一步”按钮等同于严谨批准，V2.1 需要 revision 和依赖失效语义；
6. 不因采用四阶段 UI 而删除 H3、Director、外部网页生成、任务恢复和本地文件能力；
7. 不把 2D/节点画布设为唯一入口；普通用户仍以线性阶段工作台为主；
8. 不假定 RunningHub 未验证的团队、发布审核或重绘内部机制已经成熟可复制。

## 14. 仍需在实施中验证、但不阻塞架构的事项

以下不再作为“先问用户才能继续”的需求问题，而作为实现阶段的验证任务：

- 每个已接入 Provider 的实时能力 schema、引用上限和错误码；
- 当前旧项目中各种 metadata/override 的真实分布；
- 外部网页生成恢复在浏览器关闭、登录过期和重复回填时的表现；
- 200 镜项目的真实内存、渲染和轮询基线；
- 音频/合片/超分各服务的输入输出约束和可取消性；
- 旧 FilmCreate 中低频按钮的使用率与是否迁移到高级工具；
- RunningHub 的多人审批、发布撤回、重绘内部步骤和模型质量，仅在相关范围启动时复查。

## 16. 对“是否已完整对比”的最终口径

在产品、业务流程、子功能、交互、UI、数据与本地技术能力层面，本矩阵已经形成可用于大版本设计的完整对比基线；明确未验证项也已列出，不再混入确定性结论。

“完整”不等于已执行 RunningHub 的付费生成、多人协作和发布操作，也不等于已经评测所有模型质量。若未来要把商业化、团队或发布纳入 LocalMiniDrama，必须针对对应未验证项追加专项调查。对当前 V2.1 本地优先生产主线，这些未知项不构成阻塞。

# RunningHub RH剧场交互与 UI 规范

> 本文描述截图与实机页面体现出的交互模式，并把它们转换为可供 LocalMiniDrama 设计评审的规范。像素、色值和断点属于测量/推断值，不是 RunningHub 官方设计令牌。

## 1. 体验原则

1. **阶段清楚**：任何页面都能回答“我在哪一集、哪一阶段、距离成片还差什么”。
2. **上下文不丢**：项目名、剧集、阶段、余额和项目助手常驻。
3. **先摘要、后细节**：列表/卡片展示状态，复杂设置进入抽屉、弹窗或中栏编辑器。
4. **生成可预期**：模型、规格、价格和禁用原因在点击前可见。
5. **历史不覆盖**：AI 生成、改图、重拍和增强产生候选或新版本，用户再确认主结果。
6. **结构化与自由共存**：标准模式服务效率，自由画布服务关系与深度控制，两者共享数据。

## 2. 桌面端应用骨架

### 2.1 全站导航

站点级主导航固定提供：开始创作、视频重绘、工具箱、我的项目、资产库。右侧聚合 RunningHub 主站、客服、消息和账户面板。

- 主导航负责跨项目跳转；进入单集工作台后，以“返回项目”保留回到项目详情的稳定出口。
- 当前模块必须有选中态；外部主站、充值或新手指引应标识跨域/新窗口行为。
- 账户面板属于经营与治理入口，不应把余额、团队、水印、邀请和退出等动作散落到创作页面。

### 2.2 制作工作台头部

推荐高度：64–72 px；背景接近纯黑；下方以细边界与内容区分。

从左到右：

1. 返回项目按钮。
2. 项目名称。
3. 剧集下拉。
4. 居中的四阶段步骤条：剧本—设定—分镜—短片。
5. 余额、充值、账户/空间入口。

交互规则：

- 当前阶段为高对比填充；已完成阶段可回访；未解锁阶段禁用并在悬停/聚焦时解释条件。
- 项目名超长省略，完整名称通过可访问描述提供。
- 剧集切换前若有未保存编辑，提示保存/放弃，不静默切换。
- 余额在生成页保持可见；不应使用余额颜色暗示“可以消费”，实际仍以任务预检为准。

### 2.3 工作区层级

```text
全局头部
├─ 阶段工具栏：筛选、统计、批量、模式、全局设置
├─ 主工作区：按阶段变化
├─ 底部/侧边局部导航：镜头轨、历史、会话
└─ 覆盖层：详情抽屉、设置弹窗、选择器、确认框
```

头部稳定、阶段工具栏半稳定、主区高度变化。不得把全局导航、资产局部操作和生成参数混在同一行。

## 3. 视觉语言

### 3.1 颜色

基于 1280×720 截图的近似建议：

| 用途 | 参考值 | 规则 |
|---|---|---|
| 应用背景 | `#050505` | 大面积纯黑或接近纯黑 |
| 一级表面 | `#111111` | 卡片、播放器、面板 |
| 二级表面 | `#1A1A1A` | 输入、按钮、弹窗内部 |
| 主文本 | `#F4F4F5` | 标题与关键数据 |
| 次文本 | `#A1A1AA` | 描述、统计、未激活信息 |
| 边界 | `#2A2A2E` | 1px，避免过多框线 |
| 品牌强调 | `#C8FF00` | 当前步骤、选中项、关键计数 |
| 高强调背景 | `#F4F4F5` | “进入下一步”等推进按钮 |
| 危险 | `#EF4444` | 删除/失败，仅用于真正风险 |

品牌荧光绿只用于“当前/选中/可推进”的少数信号。普通按钮保持中性，避免整页争抢注意力。

### 3.2 字体与密度

- 中文采用系统无衬线字体；数字和价格建议等宽数字。
- 页面标题 18–20 px、分区标题 16 px、正文 14 px、辅助 12–13 px。
- 正文行高 1.5–1.7；镜头提示词编辑器要比普通表单更宽松。
- 设计是高密度专业工具，不使用大面积营销卡或超大标题。

### 3.3 圆角、间距与边界

- 主面板/播放器：16–20 px 圆角。
- 卡片/输入/按钮：8–12 px。
- 主区外边距约 24 px；组件间距 12–16 px；紧凑工具间距 8 px。
- 面板以背景层级和留白分组，避免每个容器都加边框或阴影。

### 3.4 图像

- 角色卡使用 16:9 或近似宽幅三视图，突出身份脸与全身转面。
- 风格库使用 4:3/宽矩形封面，名称覆盖底部渐变区域。
- 镜头轨使用视频帧缩略图；未生成使用统一占位符，不使用空白黑块。
- 图片必须保存生成/更新时间，避免缓存导致候选误判。

## 4. 四阶段交互

### 4.1 剧本页

布局：左侧约 240–280 px 分场大纲，中间自适应正文，右下常驻会话入口。

- 点击场次定位正文，不改变正文版本。
- 编辑后页面显示未保存状态。
- “保存草稿”为次操作，“确认/重新确认”为高影响操作。
- 下游已存在时，确认按钮文案必须体现影响，不宜仍使用模糊的“下一步”。

关键状态：

- 空白：给粘贴/上传/生成入口。
- 解析中：展示场次级进度或阶段文本。
- 已保存未确认：步骤条设定仍锁定。
- 已确认：允许进入设定。
- 已修改：标记当前草稿相对已确认版本有变化。

### 4.2 设定页标准模式

阶段工具栏顺序：场次筛选 → 资产分类 → 模式切换 → 重新提取/批量生成 → 画风/画布。

资产卡只展示：主图、类型标签、名称、生成/确认状态、最常用动作。模型、提示词、参考图和历史进入详情抽屉。

空卡片末尾提供“添加角色/场景/道具”，它属于内容列表，不放入全局头部。

### 4.3 资产详情抽屉

建议宽度为屏幕的 38%–48%，最小 520 px；右侧进入，保留背景上下文。

从上到下：

1. 标题、出镜范围、确认/下载/关闭。
2. 当前主图与查看大图。
3. 任务 ID、改图、上传、删除。
4. 当前形象/候选历史与主版本/派生版本。
5. 参考素材与描述编辑。
6. 固定在底部的模型、画幅、预设、画风、价格和生成按钮。

生成按钮不能只显示价格；必须有可访问名称，例如“生成角色图，预计 ¥0.1”。删除与生成在视觉上分离。

### 4.4 画风库

- 顶部为来源/分类标签与搜索；内容为自适应卡片网格。
- 卡片至少展示缩略图、名称和选中态；详情区域展示说明和推荐模型。
- 点击局部画风只更新当前资产；点击全局画风更新项目/剧集绑定。
- 关闭弹窗前若选择即生效，需要明确反馈；更稳妥的设计是“选择—预览影响—应用”。

### 4.5 自由模式

左侧资产目录固定宽度；中央无限画布；右下小地图；画布节点内展示结构化字段与局部生成入口。

- 选择资产时在画布聚焦对应节点。
- 连线表达“角色实体 → 主形象/变装”或“场景 → 衍生状态”等真实关系，不做装饰连线。
- 标准/自由切换不得复制数据；任一视图修改后另一视图立即反映。
- 自动布局、缩放和小地图属于导航辅助，不能改变业务排序。

### 4.6 分镜页

建议列宽：左 320 px、中 420–520 px、右自适应，底部轨道 140–180 px。

- 实机左侧检查器支持拖拽调宽并可双击恢复默认。LocalMiniDrama 若采用可调列宽，应持久化用户偏好，并提供显式“恢复布局”。
- 调整列宽时不得挤压生成按钮、费用和当前镜头状态；低于最小宽度时应折叠次要栏，而不是让字段不可读。

#### 左栏

- 在镜头级集中检查资产和输入条件。
- 每项引用同时显示名称、缩略图、版本和状态。
- 素材删除或过期时保留文本描述，但必须显示降级状态。
- 站位图与故事板/分镜图区分，避免用户误以为都参与同一种模型输入。

#### 中栏

- 分时码段作为可编辑块；角色/场景/道具以芯片渲染。
- 插入芯片时同步维护引用注册表；删除芯片不自动删除资产绑定，反之亦然，应提示不一致。
- 参数条紧邻生成按钮，价格是按钮决策的一部分。
- 模型变化时无损保留通用设置，只重置不兼容字段并提示。

#### 右栏

- 无结果：明确占位和生成条件。
- 生成中：任务状态、耗时、取消能力和费用状态。
- 有候选：播放器/图像、选用、历史、下载与增强。

#### 底部轨道

- 当前镜头以边框和镜号双重标识。
- 支持插入、删除、合并、排序；危险动作仅在局部菜单出现。
- 错误、缺失引用、已完成、已选用使用图标+文字，不能只依赖颜色。

### 4.7 短片页

- 主区优先展示播放器，减少编辑控件。
- 顶部显示完成比和当前镜头；“连续播放”与“保存至成片”并列但层级不同。
- 时间线同时提供总时间标尺、场次分段、镜头长度略图和时长。
- 保存至成片禁用时理由应可直接定位到问题镜头。
- 视频增强放在播放器附近，但每次增强产生新候选并保留来源。

## 5. 弹窗与抽屉规范

| 类型 | 场景 | 关闭规则 | 主操作 |
|---|---|---|---|
| 选择器弹窗 | 画风、模型、音色库 | Esc/关闭，未应用不修改 | 应用/选择 |
| 参数弹窗 | 批量生成、导入预览 | 未提交可安全关闭 | 创建任务/确认导入 |
| 详情抽屉 | 角色、场景、道具、历史 | 保留背景上下文 | 生成、选用、确认 |
| 确认框 | 删除、重新确认、发布 | 取消默认聚焦 | 破坏性按钮明确对象 |
| 大图/视频预览 | 质量检查 | 点击关闭或 Esc | 下载/选用 |

弹窗不能嵌套超过两层。需要选择素材时，从详情抽屉打开单层选择器，返回后保留详情滚动和表单状态。

## 6. 状态反馈

### 6.1 加载

- 首次页面加载用骨架屏维持布局。
- 局部生成只锁定对应资产/镜头，不冻结整个页面。
- 批量生成显示总体进度和逐项状态，允许查看失败项。

### 6.2 空态

空态必须包含：为什么为空、用户下一步、不会发生什么。例如“暂无成片，请在短片页完成所有镜头并保存至成片”。

### 6.3 禁用

禁用按钮提供明确原因：阶段未确认、资产未准备、余额不足、模型不支持、仍有任务运行。不要只降低透明度。

### 6.4 失败

错误信息按层次呈现：一句用户语言原因 → 可操作建议 → 技术详情/任务 ID。失败任务仍可查看输入快照与费用。

### 6.5 成功

成功反馈必须说明结果落在哪里，例如“角色图已生成，待确认”“已保存为候选 3”“成片已加入项目—我的视频”。

## 7. 文案规则

- “保存”表示持久化草稿，“确认”表示建立下游基线，“生成”表示创建 AI 任务，“选用”表示候选成为当前主结果，“导出/保存至成片”表示派生成品。
- 不混用“重新生成”和“改图”：前者通常复用快照或重新编译，后者表达局部编辑意图。
- 费用统一格式：`预计 ¥x/次`、`预计 ¥x/秒`、`批量预计 ¥x`；任务结束显示实际费用。
- 时间统一到镜头秒数与分时码区间，整集使用 `mm:ss`。

## 8. 可访问性与键盘

以下为建议规范，未完全从实机证明：

- 四阶段标签、资产类型标签和标准/自由模式使用真实 tab/segmented control 语义。
- 图片卡片的操作按钮有名称，不能只显示图标。
- 编辑器中的引用芯片可用键盘选择和删除，并朗读引用状态。
- 弹窗打开后焦点进入标题或首个控件，关闭后返回触发按钮。
- 颜色状态同时配合文字、图标或边框。

## 9. 原型覆盖范围

[可交互流程原型](./runninghub-workflow-prototype.html)覆盖以下核心评审问题：

- 全局头部和四阶段步骤条是否足够稳定。
- 同一内容在剧本、设定、分镜和短片阶段如何改变主区布局。
- 标准模式的资产卡与详情抽屉如何分工。
- 分镜三栏和底部镜头轨道的职责是否清晰。
- 短片阶段如何把“逐镜生成”转成“整集审片与导出”。

原型只用于信息架构和交互层级评审，不代表最终视觉复刻，也不包含真实生成、支付、发布或数据保存。

## 10. 全站级页面交互补充

四阶段工作台之外，外部补全调查确认了项目、素材、自由生成、重绘、消费与社区等页面。它们共同承担“进入生产、沉淀资产、补充生产、核算成本、分发结果”的外围闭环。

### 10.1 开始创作与短片剧场

- 首屏并列“有想法 / 有剧本 / 有视频”三条入口，先说明输入与结果，再显示主操作。
- 有想法显示当前字数和调查时点的 15 万字上限；有剧本同时支持拖拽、点击和粘贴，并在解析前列出格式。
- 社区作品卡展示集数、总时长、播放、点赞、作者和日期；创作入口与消费型内容流应视觉分区，避免用户误以为浏览即会创建项目。

### 10.2 项目列表与项目详情

- 列表按“我的项目 / 我的发布”以及“剧本项目 / 重绘项目”切换，搜索和排序保持在结果列表上方。
- 项目卡以封面、名称、集数、更新时间和局部更多菜单构成；重命名和删除不能挤占主点击区。
- 项目详情用剧集管理、我的视频、我的图片三个稳定入口组织产物；视频再区分分镜视频与成片。
- 每集显示独立阶段标签。发布按钮在没有合法成片时禁用，并直接解释缺失条件。

### 10.3 跨项目资产库

- 顶部先切换素材库、项目素材、我的素材，再按角色/场景/道具和关键词过滤。
- 资产卡应显示来源、画风、主版本/派生数量和可导入范围；导入项目前预览将创建的绑定，而不是静默复制。
- 分页、搜索和筛选条件需写入 URL 或本地状态，进入详情后返回不丢失定位。

### 10.4 工具箱

- 左栏承载图片/视频模式、参考素材、提示词和模型规格；主区为轻量片段时间线；右栏为历史记录。
- 上传区在用户选择素材前显示上限。调查时点观察到 30 图、10 视频、10 音频，但实现应读取 Provider 能力而非写死。
- 工具箱生成物需要“保存到素材库 / 送入项目镜头 / 保存至成片”等明确落点，避免成为不可复用的历史记录。

### 10.5 视频重绘

- 文件夹上传和单视频上传并列；上传前展示 MP4/MOV、单文件大小/时长和集数命名规则。
- 上传后先呈现集数识别与失败文件清单，再开放语言、画幅、分辨率、画风和“创建重制项目”。
- 版权声明必须靠近上传/创建动作，不能只藏在页脚。

### 10.6 消耗看板与账户面板

- 消耗看板从时间范围、创作流程、项目三个维度筛选，先展示总览，再展示趋势、环节分布、项目排行和任务明细。
- 任务明细至少包括项目/剧集、任务类型、模型、任务 ID、计费量、实际消耗和状态；失败任务仍保留且明确是否扣费。
- 充值、会员、团队、邀请码属于账户经营层；生成页面只显示与当前决策有关的余额、预估价格和费用异常。
- 水印设置必须解释默认 AI 标识、去除后的责任以及后续修改入口；发布时仍需再次校验。

## 11. 实测值与设计令牌的边界

模型名称、价格、上传配额、字数上限和画风数量是 2026-09-08 的界面快照。UI 规范只借鉴其“生成前暴露约束、价格和结果落点”的交互原则，具体数值必须来自能力配置、计费服务或运行环境检测。

## 1. 产品全景

### 1.1 产品定位

- **产品名**：RH剧场 / RHSTORY，Slogan"让故事即刻上演"，主站入口 `story.runninghub.cn/ai-comic`。
- **从属关系**：RunningHub 主站（ComfyUI 工作流平台）的 AI 漫剧/短剧子产品。顶部导航有返回主站链接；充值、邀请均跳转主站页面；算力与计费共用主站钱包。
- **三条创作路线**（首页显式分流）：
  1. **有想法**：输入脑洞（占位文案举例"追妻火葬场、破镜重圆、替嫁新娘、失忆梗"），上限 15 万字，点"生成剧本"；
  2. **有剧本**：上传/粘贴剧本（txt、docx、md、xlsx，支持拖拽和 Ctrl+V），点"解析剧本"；
  3. **有视频**：跳转"视频重绘"，对已有视频做风格重制。
- **社区闭环**：首页下方"短片剧场"展示用户发布作品（集数、总时长、播放数、点赞数、作者、日期），项目详情页有"发布至剧场"按钮（成片完成前禁用）。

## 2. 单集四阶段工作台（增量观察）

四阶段流水线 `剧本 → 设定 → 分镜 → 短片` 的顶部步骤条、阶段门禁、双模式等总体设计前篇已详述，此处只记录本次新增观察。

### 2.1 跨画风样例证实

本集样例《以我残躯护你周全》第 2 集（"凌晨两点的客房服务"）使用**现代都市悬疑风格**（描述："现代中国城市悬疑写实电影感，适合刑侦、调查、都市秘密和心理悬疑角色，该风格推荐模型为全能图片PRO-官方稳定版"），角色三视图为真人写实摄影风格。结合前篇样例（3D 国潮动漫），证实：

- 画风是**项目级可配置**的（全局画风 + 资产级"跟随全局/覆盖"）；
- 画风预设自带**描述文案与推荐模型**，选择画风会联动推荐生成模型；
- 资产提取与画风无关（先从剧本抽角色/场景/道具文字档案，图由画风渲染）。

### 2.2 剧本阶段增量

- 左栏"分场大纲"：场次卡片列表 + "N 个场次 + N 字"统计；点击场次卡片定位正文。
- 正文编辑器上方标注"可手动在剧本正文中编辑修改"；底部两个语义分离的操作：**保存草稿**（存文字）/ **重新确认剧本**（重建下游批准状态）。
- **AI 项目会话**（右侧抽屉，"展开会话/收起会话"）：
  - 顶部显示连接状态"已连接"（WebSocket 长连接）；
  - 引导语："向项目助手提问，了解当前剧本、设定、分镜或短片进度"；
  - 输入框占位："问问当前剧本、角色或分镜…"；
  - **历史会话**入口；
  - 四阶段页面均带此入口（每个页面都会出现"展开会话"按钮），是贯穿全流程的上下文感知助手。

### 2.3 设定阶段增量

工具栏：`全部场次 ▾ ｜ 角色|03 场景|01 道具|01 ｜ 标准模式｜自由模式 ｜ 重新提取 / 批量生成 / 全局画风 / 画布编辑`，下方显示当前画风全名。

**角色卡**：三视图形象图 + 主角/配角标签 + 编辑名称 + **配置音色**。点击形象图打开详情抽屉：

- 标题"角色名｜主形象"；出镜剧集（如"第2集"）+ 编辑出镜场次；
- **确认角色**（生成后可用）、下载角色图、查看大图；
- `TaskID: xxx` 按钮（溯源生成任务）；
- 改图 / 本地上传 / 删除；
- **主形象 + 添加变装**（变装 = 命名的新形象版本，弹窗仅一个名称输入）；
- 素材参考图；"展开输入框"；
- 角色描述结构化文案（本次实测："角色描述：男，青年，独自出差的职场人士 / 谨慎多疑，反应敏捷 / 变装：—"）；
- 生成参数条（自左向右）：**模型 → 画幅 → 分辨率 → 预设类型 → 画风 → 价格**；
- 另有一个简化"角色"弹窗带"当前形象 / 最新形象"对比双槽。

**画风库**（点"跟随全局"或"全局画风"打开，见截图 01）：

- 顶部筛选：我的风格 / 全部 / 真人 / 3D / 2D + 搜索框；
- 数百种预设画风卡片（缩略图 + 名称），实测涵盖：电影超写实、黑白电影、复古胶片、赛博朋克、蒸汽朋克、失焦美学、纪录片写实风、各国电影风格（90年代港片、韩国冷淡、日本黑白胶片悬疑、90年代中国农村…）、3D 类（皮克斯/迪士尼3D、乐高、黏土/盲盒、UE5写实、国风3D…）、2D 类（吉卜力、新海诚、韩漫、浮世绘、水墨写意、赛璐璐…）等；
- 每个画风带一句用途描述与推荐模型（选中后显示在工具栏）。

**配置音色**（角色卡入口，抽屉弹窗）四个标签页：

1. **智能音色设计**：提示词输入（占位"描述性别、年龄、音调、质感、气息、情绪和语速等音色特征"，自动预填角色描述生成的音色设计指令）+ 试听文本（默认"你好，我的声音，为你演尽喜怒哀乐。"）+ 生成按钮（¥0.1/次）+ 历史列表；
2. **音色库**：26+ 预设音色（男声/温柔男声/中年男声/老年男声/女声/元气女声/成熟女声/温柔女声/老年女声/深情女声/俏皮少女/儒雅先生/厚重大叔/叛逆少年/可靠大叔 等）；
3. **本地上传**；
4. **提取音色**。

**批量生成**（弹窗）：角色卡多选（含身份/个性摘要）、统一模型/预设/尺寸选择、底部"取消全选（N）"+ 总价（如 3 角色 ¥0.3）。生成后逐资产回填。

**自由模式**（节点画布，见截图 05）：

- 左侧资产列表（头像缩写 + 名称 + 编辑）；画布为 Vue Flow 节点图（带小地图、缩放、对齐吸附、连线曲线/直线切换）；
- 角色节点 → 连线到"主形象"节点；主形象节点内是结构化提示词表单：**主体人物（性别/年龄/身份/性格）/ 外貌特征（五官/体型/发型/肤色）/ 主形象**；
- 节点级模型选择（画布内默认推荐 PRO 官方版 ¥0.8）+ 生成按钮；
- 与标准模式操作同一套资产数据（切回标准模式数据一致）。

### 2.4 分镜阶段增量

顶部统计条：`全部场次 ▾ ｜ 共 1 个场次 · 4 个镜头 · 预计 58s ｜ 重新提取分镜脚本 / 导入分镜脚本 / 批量生成 ▾`。

**批量生成下拉四项**：批量生成视频 / 批量生成故事板 / 批量生成分镜图 / 批量生成站位图。→ 分镜阶段有四种独立产物：故事板（sketch）、分镜图（frame image）、站位图（blocking）、视频。

**导入分镜脚本弹窗**：支持 .xls/.xlsx/.docx，可拖拽；注明"导入脚本单镜头时长过短时，系统将自动合并镜头，仅优化时长，完整保留所有画面、台词、音效，不修改剧情，保证画面连贯"。

**左栏镜头检查器**（每镜）：

- 镜头号（场次-序号）、时长 spinbutton（秒）；
- 出镜角色：头像 + 角色 + **选择音色（含 ▶ 试听）** + 从本镜移除；
- 分镜场景：场景卡（若场景变体未生成图片，显示"该变体尚未生成图片，暂不可选"）+ 从本镜移除；
- 场景道具：+ 添加；
- 故事板 | 分镜图 切换；站位图；
- 其他关联：+ 上传参考图片 / 参考视频 / 参考音频；
- **3D导演台 / 2D画板** 按钮。

**中栏提示词编辑器**（见截图 03）：

- 顶部：出镜角色头像芯片 + 场景芯片快捷插入；
- 正文：**分时码结构化描述**，实测形态："0-2.5 秒:【镜头】中景，平视，固定，标准镜头，中景深带出环境，常速，稳定器固定。镜头从床头柜电子钟的红色数字 02:17 起，焦点从数字切到床上的 @周启，落到 @周启 惊坐起的未态。…"——@提及的角色名以绿色芯片内联渲染；
- 生成参数条：视频模型（seedance2.0/多模态视频）→ 规格（16:9 / 720p / 15s / …）→ **价格 ¥18** → 生成按钮（↑）。

**底部镜头时间线**：镜头卡序列（镜头号 · 时长），每张卡提供"在此新增片段（前后插入）/ 删除 / 合并到下一个镜头"；最右"进入下一步"。

**后处理工具栏**（未生成视频时全部禁用）：截屏 / 片段重拍 / 高清修复 / 去字幕 / 画质增强 / 人声增强 / 提取伴奏。

**3D导演台**（独立路由 `/infinite-canvas?mode=3d`，带项目/集/镜/配额参数 `imageUsed=2&imageMax=9…`）：

- "3D 导演台 / 2D 画板"双标签 + 保存工程 / 工程列表；
- 自由视角 / 机位视角；视角立方体（前/后/左/右/上/下 + 90° 旋转）+ 重置相机；
- 场景环境：全景图背景（可上传或从漫剧项目选图）、全景球、名称显示/地面网格开关、地面高度/透明度滑杆；
- 工具：添加（对象）、位移(V)、灯光、机位、画幅比例、截图、录制、全屏；
- 对象列表（可搜索）、FOV 滑杆（实测 39.6°）、相机距离滑杆。

**2D画板**：缩放（-/100%/+/适应）、选择、画笔、矩形、实线、橡皮擦、填充、文本、图片、颜色、描边、"低"（稳定器/质量）、撤销/重做、清空画布、保存工程、截图、图层、快捷键。

### 2.5 短片阶段（本次实测，前篇未能进入）

页面结构（见截图 04）：

- **视频播放器**：播放选中镜头的已生成视频（进度 0:00/0:12），带快退/播放/快进/音量/全屏/更多；右上角**视频增强**下拉；
- **镜头时间线**：标尺 00:00–05:40，按场次顺序平铺全部 29 个镜头段（镜头号 + 时长标签）；已生成的镜头显示视频缩略图，未生成的显示占位图标；左右箭头滚动；
- "连续播放"：按时间线顺序连播所有已完成镜头；
- "保存至成片"：合成整集（未全部完成时禁用）；
- 右侧保留"历史记录"抽屉与 AI 会话入口。

结合项目详情页"我的视频"面板（成片 / 分镜 两个子标签 + 批量下载 + 空态文案"暂无成片，请在短片页面点击「导出至成片」"），短片阶段的产物分两类：

- **分镜视频**：逐镜生成的单镜视频（可单独下载、重生成）；
- **成片**：由分镜视频按时间线合成的整集视频（导出后进入"我的视频>成片"，可批量下载）。

**关键设计**：流程门禁与进度以**集**为单位；角色等资产跨集复用（角色详情里"出镜剧集：第2集"说明角色属于项目、按集标记出场）。

## 4. 资产库（跨项目素材中心）

路由 `/assets`，三个标签：**素材库 / 项目素材 / 我的素材**，资产类型筛选（角色 / 场景 / 道具）+ 搜索 + 分页（实测 7 页）。

- **素材库**：官方预设角色包，按"画风:职业"组织（如"极简现代扁平插画:社区书报亭管理员"、"折面雕塑感重彩手绘风格:城市规划师"、"欧式古典厚涂油画:林间花墅秋千闲坐人"、"风格化3D:糖果造型师"），每包"2 个素材"（主形象 + 变体）——可直接复用到项目；
- 项目素材 / 我的素材：项目内资产沉淀与用户自建素材。

意义：资产不只是单项目内的一次性提取结果，而是**可跨项目复用、可沉淀的个人素材体系**。

## 5. 工具箱（自由生成沙盒）

路由 `/toolbox`，定位：**脱离完整项目流程的即兴生成工作台**。

- 顶部：项目选择器（默认项目）+ 集选择器 + 更多操作 + 历史项目；
- 左栏生成面板：视频生成 / 图片生成切换；参考素材（上限：30 图 / 10 视频 / 10 音频；本地上传 + 导入素材）；提示词输入（占位"描述你想要的镜头，可用 @ 引用上传的素材"；工具：撤销 / 优化 / 智能识别 / 全屏编辑）；模型选择（seedance2.5/多模态视频）+ 规格（Auto / 720p / 25s）+ 开始生成；
- 主区：片段时间线（"镜头 1 · 0s"，可新增片段/删除；统计"1 个镜头 · 1 个待生成 · 已成片 0s"）+ **保存至成片**；
- 右栏：历史记录。

与主流程的关系：主流程（四阶段）面向"从想法到整集"的完整生产；工具箱面向"单镜头快速试验/补素材"，产物可保存为成片片段。

## 6. 视频重绘（旧视频 AI 重制）

路由 `/ai-comic/repaint`，Slogan"视频一键迭代，旧素材解锁新流量"。

- 上传方式：上传文件夹 / 上传视频；MP4/MOV，**文件名需包含集数信息**，单视频 ≤500M、≤300s；
- 重制参数：语言（中文）、画幅（16:9）、分辨率（720p）、画风（如电影超写实）；
- "创建重制项目"（上传后可用）；重绘项目出现在项目列表"重绘项目"标签下；
- 版权声明："请仅上传您拥有版权或已获得合法授权的视频"。

本质是 v2v 批量风格迁移管线，将已有实拍/旧动画短剧批量转成选定画风，文件名集数规则暗示其面向"整季批量重制"场景。

## 7. 计费、消耗看板与合规

## 10. 对 LocalMiniDrama 的迭代参考（增量建议）

前篇 §11–12 已给出能力对照与"值得吸收/不应照搬"清单，本节只补充本次新增观察带来的建议：

1. **短片工作台落地为"逐镜审片 + 时间线"**：本机产品已有合片管线，但缺少"镜头 N / 共 M 个、M/N 已完成、连续播放、缩略图时间线、保存至成片"的审片界面。这是四阶段闭环的最后一公里，建议优先补齐——它是把已有后处理能力（超分、字幕、水印、TTS）组织成用户可感知价值的收口页面。
2. **产物分级：分镜视频 vs 成片**：视频资产分"单镜生成物"与"合成成片"两类管理（对应 RH 的"我的视频>分镜/成片"），分别支持下载/重生成/批量导出，避免合片结果覆盖单镜素材。
3. **全站级资产库**：本机素材库可向"跨项目素材中心"演进（素材库/项目素材/我的素材 三层 + 角色/场景/道具筛选），官方预设包（画风×职业）是冷启动的好方式。
4. **自由生成沙盒（工具箱）**：为"单镜头试验"提供脱离项目流程的入口，产物可回灌项目——这与本机 FreeCreate 页方向一致，可参考其"参考素材配额（30图/10视频/10音频）+ @引用 + 保存至成片"设计。
5. **AI 项目会话**：右侧常驻、WebSocket 实时、感知当前剧本/设定/分镜/短片进度的项目助手，是低成本的"引导式创作"增强点。
6. **费用预检与消耗看板**：本机调用云端 API 时同样产生成本。参考其"生成前显示本次价格 + 失败不扣费 + 任务明细（模型/用量/费用/状态）"，在本地实现 preflight 报价与按任务的成本台账，对商业化或内部成本核算都必需。
7. **合规内建**：若产品面向公开发布场景，AI 内容标识（水印默认开、可申请关、责任声明）应作为功能而非补丁。
8. **社区剧场（远期）**：作品展示页（集数/时长/播放/点赞）+ 项目内"发布"动作，构成创作-分发闭环；本地产品可先做"导出发布包"再考虑社区。
9. **多画风项目验证**：画风决定推荐模型与全项目视觉基调（本项目两集样例分别跑了 3D 国潮与真人写实），本机"资产生成模式"迭代可引入"画风预设 → 推荐模型/参数联动"的映射，而不是让用户逐资产试模型。

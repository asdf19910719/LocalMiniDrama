# Production Studio V2.1 · UI 设计稿

> 版本：2026-09-11 · 依据 [V2.1 交互与 UI 规格](../../research/localminidrama-product-baseline/production-studio-v2.1-interaction-ui-spec.md)、[单人创作者收敛设计](../../superpowers/specs/2026-09-10-production-studio-v2.1-single-creator-refinement-design.md)、[分镜页重设计](../../superpowers/specs/2026-09-10-production-studio-v2.1-storyboard-redesign-design.md)、[短片页重设计](../../superpowers/specs/2026-09-10-production-studio-v2.1-cut-redesign-design.md)绘制。
> 用途：V2.1 前端实现（`frontweb/src/views/productionStudio/`）的视觉基准。35 张 1440×900 高保真设计图（2x 输出 2880×1800），覆盖 V2.1 canonical 路由全部页面 + 规格定义的全部独立容器（独立向导页 / Drawer / 中央 Modal）。
> 图库索引：打开 `index.html`（相对引用 `out/png/*.png`）。

## 覆盖口径

- **页面（23 张）**：canonical 路由 13 个页面 + Studio 四阶段 + 4 个独立向导/工具页（归档导入、数据工具、更改工作区、物理清理）+ 自由创作、高级画布、媒体库 3 个旁路工具；
- **容器（12 张）**：规格 §11 的三类容器各有实例——Detail Drawer 7 张（素材详情/任务详情/引用管理/素材预览/生成历史/历史版本/编辑项目/资产详情/音色，见清单）、Generation Sheet 1 张（单镜生成确认）、Confirm Modal 4 张（影响摘要/版本比较/删除确认/风格选择）；
- 未单独出图的次级状态（向导其余步骤、生成配置在自由创作抽屉内、画布批量重编译确认等）复用图中已出现的同一组件模式，不引入新形态。

## 设计风格定位

对标同类 AI 视频创作工具的深色专业工作台风格：**即梦AI / 剪映专业版 / Runway / 可灵**。

- 深色底 + 发丝级边框分区，靠背景层级（canvas → surface → elevated）而非重阴影区分层次；
- 紫罗兰强调色只用于主 CTA、当前选择、焦点；状态一律「图标 + 文字标签」，颜色仅作辅助；
- 信息密度「普通优先、高级折叠」：默认界面只呈现当前主任务与少量异常，技术详情、批量能力按需展开；
- 内容语义优先：示例文案全部使用用户语言（"需要处理"而非"阻塞"，"生成中"而非任务内部状态机值）。

## 1. 设计令牌（Design Tokens）

实现时以 CSS 自定义属性落地（见 `shared/ui.css`），组件内禁止硬编码品牌色。

### 1.1 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `bg.canvas` | `#0b0d12` | 应用底色 |
| `bg.surface` | `#12151d` | 卡片 / 面板 / Rail 沉底 |
| `bg.elevated` | `#181c26` | 输入框 / 悬浮层 / hover |
| `text.primary` | `#f4f6fb` | 主文本 |
| `text.secondary` | `#c3c9d6` | 次级文本 |
| `text.muted` | `#8d95a8` | 辅助说明、占位 |
| `border.default` | `#2a3040` | 常规边框（发丝线） |
| `border.strong` | `#3a4256` | 悬浮 / 抽屉描边 |
| `accent.primary` | `#7c5cff` | 主 CTA / 当前选择 / 焦点 |
| `accent.hover` | `#8f74ff` | 主 CTA 悬停 |
| `accent.subtle` | `rgba(124,92,255,.14)` | 选中底 / Rail 激活底 |
| `status.ok` | `#45d39c` | 已确认 / 已完成 / 校验通过 |
| `status.warn` | `#ffb65c` | 待处理 / 已过期 / 建议 |
| `status.danger` | `#ff6b78` | 失败 / 删除 / 缺失 |
| `status.info` | `#58a6ff` | 生成中 / 进行中 / 提示 |
| `status.neutral` | `#8d95a8` | 草稿 / 锁定 / 未开始 |

状态色各配 12–14% 透明度的 subtle 底色用于徽标底（`-subtle` 后缀）。**徽标必须带文字，不允许只靠颜色区分状态。**

### 1.2 字体与字号

- 字体栈：`"Segoe UI", "Microsoft YaHei", "PingFang SC", "Noto Sans SC", sans-serif`；数字使用 tabular-nums；
- 页面标题 20px/600 · 区块标题 13–14px/600 · 正文 14px · 次级 12px · 辅助 11px；
- 行高 ≥1.45；正文编辑器（剧本页）14.5px / 1.9。

### 1.3 几何

- 基础间距 4px 网格，常用 8/12/16/24；
- 控件高度：紧凑 28 · 默认 36 · 主 CTA 40（向导终态 44）；
- 圆角：卡片 10 · 输入/按钮 8 · 徽标/chip 999 · 大播放器 12；
- 阴影仅用于浮层（抽屉/Modal）一层：`0 18px 55px rgba(0,0,0,.34)`；页面内靠边框分层；
- 焦点：2px `#7c5cff` focus ring。

## 2. 应用骨架

```text
┌ Rail 64px ┬ 页面区 ──────────────────────────────┐
│ logo      │ 页头 64px（标题/项目内导航/搜索/CTA） │
│ 项目      │ ─ Studio 页：                        │
│ 资产库    │ │ 制作头 56px（面包屑·保存态·任务·预算）│
│ 任务中心  │ │ 阶段导航 48px（剧本→设定→分镜→成片） │
│ …         │ │ 状态条/工具栏/工作区                  │
│ AI 配置   │ ─ 非Studio页：page-body               │
│ 设置      │                                       │
└───────────┴───────────────────────────────────────┘
```

- **Rail**：图标 21px + tooltip；激活项 = 左侧 3px 指示条 + subtle 背景，不改字色凑合；
- **项目内导航**（概览/剧集/项目素材）：页头内 pill 分段，激活 = subtle 底 + 白字；
- **阶段导航**：居中，每项 = 序号圆点 + 阶段名 + 状态副文本（如 `草稿 v3 · 已确认 v2`、`4/9 已采用`）；需要处理时并列 warn 徽标；右侧固定一条本集级摘要（如 `● 素材已准备 · 快照 14:32`）；
- **Studio 制作头**：左（返回 + 项目名 / 集名）· 中（保存态：`已保存 · 14:32`）· 右（撤销/重做 · 任务徽标 · 远端预算 `¥0.42` · 更多）。

### 3.1 状态语言（全局统一）

| 状态 | 徽标样式 |
|---|---|
| 草稿 | neutral 灰 |
| 待确认 / 需处理 / 已过期 | warn 琥珀 + 对应图标 |
| 已确认 / 已完成 / 校验通过 | ok 绿 + 勾 |
| 生成中 / 进行中 / 排队 | info 蓝（配进度条） |
| 失败 / 缺失 / 媒体离线 | danger 红 |
| 当前使用 / 当前镜 | accent 紫描边或 `当前图 · vN` |

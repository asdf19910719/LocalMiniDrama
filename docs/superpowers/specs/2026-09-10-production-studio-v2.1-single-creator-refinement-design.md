# Production Studio V2.1 单人创作者收敛改造设计

日期：2026-09-10  
状态：待用户审阅  
范围：统一可交互原型、原型状态模型、原型测试、交互与 UI 规格、逐页决策记录；不改 `src/`、真实 API、数据库或 Provider。

## 1. 目标与边界

本轮将 V2.1 从“把制作系统所有能力展示给用户”的原型，收敛为“一个人完成一集成片”的工作台。用户默认只需回答四个问题：剧本是否可用、本集需要哪些设定、分镜下一步做什么、怎样导出成片。任务、版本、快照、上下文、引用和恢复仍保留为技术能力，但只在需要行动时露出。

以下能力保持不变：项目级素材主数据、素材候选与当前使用项、外部 AI 任务包及 JSON 回流、可恢复异步任务、精确素材快照、图片/视频/合片/超分管线。以下内容不进入本轮：真实业务实现、数据迁移、Provider 调用、团队协作、复杂批量运营、硬删除。

## 2. 信息架构

项目内导航调整为：`概览 / 剧集 / 项目素材`。删除用户可见的“项目设置”页；原 route 可以暂存为兼容路由，但应重定向到概览或对应具体入口，不保留空壳页面。

单集阶段调整为：`剧本 / 设定 / 分镜 / 成片`。页面标题使用“本集设定”，导航只显示“设定”。阶段导航居于 Studio 页头中间，是当前位置与跳转控件，不占右侧 Inspector。

全局设置仍承载工作区、目录、Provider、备份和高级数据工具；它不承载项目资料、项目画面风格、单集默认时长或项目输出偏好。

## 3. 项目概览

### 3.1 项目资料

概览 Hero 展示封面、项目名称、题材、画幅、集数和最近编辑时间。点击“编辑项目”打开窄 Drawer，只编辑名称、封面、题材、画幅和项目简介。项目资料中不再显示或维护默认单集时长、输出编码、输出分辨率或项目级输出偏好。

项目本地路径不在 Hero 中编辑；它属于项目操作或全局数据工具。画幅保留在项目资料，因为画幅会影响后续图片和视频生成。

### 3.2 项目画面风格

概览保留“当前画面风格”卡片，显示缩略图、名称、一句话描述和最近应用时间。点击卡片或“更换风格”打开大型中央选择 Modal，而不是窄 Drawer。

Modal 固定提供“预设风格 / 我的风格 / 自定义风格”三个页签，当前风格置顶。选择前能查看简短描述和视觉预览；自定义风格在同一 Modal 的第二步填写名称、描述、参考图和约束。确认应用创建新的项目风格版本，只影响之后的新生成或用户明确刷新，不改写现有素材、分镜或成片。

项目概览不再展示生产对象概览。人物、场景、道具及其问题统一由“项目素材”承担。

## 4. 剧集页与剧集创建

### 4.1 列表与次级菜单

剧集页默认按集号展示紧凑列表，保留搜索和排序。首发不把顶部统计卡做成可点击多维筛选；若剧集规模增大，只增加一个轻量筛选：`全部 / 需要处理 / 制作中 / 已完成`。阶段筛选、来源筛选和统计卡联动不进入默认界面。

每行菜单保留：重命名、调整集序、查看导入来源（存在时）和删除剧集。删除的用户文案是“删除”，技术实现可进入回收站并提供撤销，不向用户展示“归档”入口。删除前必须显示会受影响的素材、分镜、媒体和本地空间。

“设置目标时长”删除。`复制为草稿` 降为 P1，不出现在当前默认原型；未来如恢复，只复制剧本和场次结构，不复制媒体候选、任务、已确认状态或外部协作记录。

### 4.2 统一新建入口

剧集页首要 CTA 是“新建剧集”，创建空白草稿后直接进入剧本页。创建时只需要集号与可选标题，不要求预计时长。

剧集页次级菜单为“导入 / 协作”，包含：导入制作包、外部 AI 制作、小说/长文本拆集、从已有视频开始剪辑。它们保留为不同的数据协议或工作流，而不是普通剧本输入方式。

“我有剧本”“让 AI 帮我写”“空白创建”不再作为彼此竞争的创建来源。空白剧本页提供三个开始方式：粘贴/导入剧本、AI 生成草稿、直接写作。三者都写入同一份可编辑剧本草稿。

草稿阶段即应解析并展示场次结构，用户可修改场次、角色、地点、动作和对白；“确认剧本”表示批准这个版本供下游使用，而不是首次把文本拆为场次。估算时长在剧本或分镜结构出现后计算展示，不要求用户在创建时预填。

## 5. 外部 AI 制作

外部 AI 是重要但非强制的协作能力，不再占用项目设置页，也不建立独立一级 Tab。其唯一实现路径放在剧集页的“导入 / 协作 → 外部 AI 制作”；项目概览只可提供同一向导的快捷入口，或在存在待回流任务时展示一张紧凑任务卡。

完整流程使用独立 Page 向导，不使用 Drawer 或中央 Modal：

1. 选择目标：新建下一集或填充空白剧集；非空剧集永不可写入。
2. 自动编译上下文：项目资料、当前画面风格、已确认的连续性、必要人物/场景/道具和上一集摘要。
3. 补充本次要求：用户只编辑“给外部 AI 的补充说明”，不维护一套永久的平行创作上下文。
4. 预览与创建任务包：显示目标、包内容、冻结版本和安全边界；创建后提供下载任务包与复制任务说明。
5. 等待外部结果：任务在剧集行和任务中心持久显示，可离页，提供重新下载、复制说明、选择结果和取消。
6. 导入结果 JSON：校验 schema、`package_id`、`assets_digest`、项目、目标剧集和上下文版本。
7. 预览五步导入：剧本场次、素材映射、分镜与时段、写入摘要。
8. 原子写入草稿并打开剧本页；不自动确认剧本、不自动发起图片/视频/音频任务。

“编辑创作上下文”和“复制创作上下文”不再是项目内的永久并列功能。任务创建后才可复制任务说明或下载上下文；上下文的用户可编辑部分只有本次任务的补充说明。

## 6. 剧本页

剧本页保留“场次导航—正文编辑—当前上下文”的三栏，但四阶段导航移动到页面顶部中央。右侧不常驻版本历史；默认用于当前场次资料、确认检查和下游影响。

AI 能力保留，但按状态渐进出现：空白剧本突出“AI 生成剧本”，已有草稿放入“AI 辅助”，选中文本后提供改写、扩写和缩写。所有 AI 输出都是候选，比较后才写入草稿。

版本比较仅在“已有已确认剧本且当前草稿有修改”时出现，使用大型 Modal 或独立对比视图。初次确认按钮为“确认剧本”，已有已确认版本后的编辑使用“确认修改”；内部仍创建 revision。历史版本改为次级“历史版本”入口，点击打开 Drawer，不常驻占据右栏。

## 7. 项目素材与本集设定

### 7.1 项目素材

项目素材卡片默认只显示当前图、名称、类型、一句话描述、状态缩略图和真正需要处理的异常。默认不显示“新候选数量”“用于几集/几个分镜”“资料版本号”或“默认缺少侧视图”。侧视图仅在某个明确工作流或生成任务需要时提示。

使用位置、候选数、来源、历史和删除影响保留在详情 Drawer 或删除确认中。用户可见操作为删除，不提供归档；若资产已有引用，则删除流程解释影响并通过可恢复删除、替换或解除引用保护数据。

### 7.2 本集设定

“本集素材”重命名为“本集设定”。页面只投影当前剧本实际引用的人物、场景和道具，不罗列所有项目素材；底层只保存“本集采用了项目对象的哪个状态和媒体版本”，不复制项目对象资料。

页面使用 `角色 / 场景 / 道具` 三个 Tab 和与项目素材一致的卡片网格。删除大面积的“已准备、必须处理、可选更新、剩余策略、只处理差异和阻塞、自动继承说明”等管理型 UI。必要缺失仅以卡片轻徽标或紧凑提示条出现。

素材卡点击打开 560–720px 右侧 Drawer。Drawer 默认只回答：对象是什么、当前选择哪个状态、当前使用哪张图、能否生成/上传、当前剧集使用哪个版本。结构为：对象摘要、状态切换、当前形象与候选、简短资料、生成/上传、使用于本集。角色的音色仅在角色详情中按需出现。

Drawer 不默认展示 hash、revision、完整 Prompt、Provider 参数、全量任务日志、跨项目使用统计、归档和技术来源。这些进入“技术详情”。点击生成时使用中央 Modal，避免 Drawer 套 Drawer；Modal 的高级参数默认折叠。

## 8. 非阻塞的分镜前检查

“进入分镜前检查”不再是阻止页面跳转的 Gate。用户从“本集设定”点击“进入分镜”时，系统立即跳转到分镜页，同时在后台执行检查和素材快照保存。

状态如下：

| 状态 | 页面跳转 | 分镜可做的事 | 媒体生成 |
|---|---|---|---|
| 检查中 | 立即允许 | 查看/编辑分镜结构 | 暂不提交，显示“正在准备素材” |
| 已准备 | 允许 | 全部 | 可提交 |
| 有待处理项 | 允许 | 查看/编辑分镜结构、查看引用 | 受影响镜头的生图/生视频要求先处理对应素材 |
| 快照保存失败 | 允许 | 查看/编辑分镜结构 | 禁止创建需要快照的媒体任务，提供重试 |
| 剧本未确认 | 允许 | 查看/编辑草稿结构 | 禁止正式媒体生成，提示返回确认剧本 |

本集设定页不再有大面积检查面板，只保留紧凑提示与主按钮：`进入分镜`、`正在检查…`、`有 2 项可稍后处理` 或 `本集设定已准备好`。分镜页顶部用同一条紧凑状态条展示待处理项和“去处理”快捷入口。

技术约束不变：任何会产生媒体或费用的任务，都必须绑定有效的剧本确认版本和本集素材快照；允许进入和编辑分镜不等于允许绕过生成前校验。

## 9. 容器和交互准则

| 场景 | 容器 |
|---|---|
| 项目资料编辑、素材详情、版本历史、任务详情 | Drawer |
| 风格库选择、素材生成配置、版本对比、删除确认 | 中央 Modal |
| 外部 AI 协作、制作包导入 | 独立 Page 向导 |
| 剧本正文、场次标题、项目名称的快速修改 | Inline Edit |
| 低风险行级操作 | Context Menu |

默认界面只呈现当前主任务和少量异常；技术信息、低频操作和批量能力按需展开。任一失败状态保留当前草稿、已有候选和已确认版本，并提供唯一明确恢复动作。

## 10. 原型验收

- 项目内没有“项目设置”一级导航；项目资料和画面风格均可从概览完成。
- 新建剧集直接进入空白剧本；剧本输入、AI 起草和手写共用草稿。
- 制作包与外部 AI 的入口与普通剧本输入分离，外部 JSON 能回流为草稿。
- 创建剧集和剧集菜单均不要求或展示目标时长；默认菜单没有归档。
- 项目素材与本集设定默认卡片不展示候选数量、使用集数或可选侧视图缺失。
- 本集设定仅展示本集引用对象，并能在 Drawer 选择状态和图像版本。
- 用户在素材不完整、快照失败或剧本未确认时仍能进入分镜页；受影响的媒体生成动作准确禁用并指向修复入口。
- 原型测试同时覆盖导航可达性、生成前校验、外部 AI 回流、删除保护和既有可恢复状态。

## 11. 迁移与风险控制

这是一层原型投影和文档变更，不删除既有领域状态。原有 `project-bible`、目标时长、归档和阻塞 Gate 模型可暂时保留为内部兼容状态，但不得继续出现在新的默认 UI。通过原型测试后再单独评估真实产品的数据模型、路由和 API 迁移。

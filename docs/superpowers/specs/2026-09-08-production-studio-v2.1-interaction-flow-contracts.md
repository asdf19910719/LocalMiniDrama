# Production Studio V2.1 关键交互流程合同

日期：2026-09-08
状态：P0 权威附件，实施计划前置输入

## 1. 文档职责

本文补齐架构母稿和页面 UI 规格中不能只用功能摘要表达的十类完整交互。每个流程必须明确入口、前置、操作、即时反馈、失败/恢复和成功落点。实施计划不得重新决定本文件已经固定的产品行为。

通用状态机：

```text
idle → editing/selecting → validating → confirming → executing
                                  ├→ validation_blocked → editing/selecting
                                  ├→ failed             → retry/recover/cancel
                                  └→ succeeded          → explicit success destination
```

这里的 `validation_blocked` 只是当前交互分支，不是阶段内容状态；持久化层仍记录 blocker/Gate 评估并保持原内容状态。取消不得产生当前步骤的新增业务写入；已经在前置步骤由用户显式提交的项目壳、任务或其他事实继续保留。事务型操作失败必须零部分写入；远端任务失败保留输入快照与 attempt。

## 2. 六类项目/剧集来源

统一入口是 Project Hub“新建项目”和项目详情“新建/导入剧集”。两者复用同一来源能力、`EpisodeTargetSelector` 和导入引擎，但交互上下文不同：新建项目页先选择来源，只有点击上下文主动作后才原子创建项目并进入第 1 集流程；剧集入口直接绑定当前项目。所有来源必须在读取内容或创建任务前显式绑定“创建下一个可用集号”或“填充指定空白剧集”，非空剧集不进入可选目标，任何流程不得默认落到 E01。

用户首屏只展示“我有剧本、让 AI 帮我写、我有制作包”三个入口。“空白创建、小说/长文本、已有视频”进入“更多开始方式”；“外部 AI 协作”是制作包向导内的次动作。六类能力和协议没有删除或合并。来源卡只选中，不隐式创建项目；提交后每种来源必须进入自己的向导，不能共同跳到一个成功占位状态。

| 来源 | 前置与向导 | 执行反馈 | 失败与恢复 | 成功落点 |
|---|---|---|---|---|
| 空白手工 | 先选安全目标，再填写标题、集号、目标时长；不要求 AI 配置 | 创建摘要，远端费用 0 | 集号冲突停留表单；取消不写入当前剧集草稿，已经用户提交的项目继续保留 | Script Stage 空白编辑器 |
| 想法/剧本 AI | 先选首个目标；输入想法/剧本文本、生成集数、模型、费用确认 | 生成前预览编号和标题；逐集显示结果 | 配置缺失阻断；部分生成失败保留成功集并只重试失败集 | 剧集列表显示 draft，首集进入 Script Review |
| 小说/长文本分章 | 文本/文件、分章规则、集号起点 | 预览章节、标题、空段和冲突 | 解析失败保留原文；提交冲突整体拒绝 | 剧集列表，用户选择一集进入 Script Stage |
| 外部 AI 协作 | 项目存在；可选空白目标集 | 进入第 3 节任务包流程 | 会话/文件错误保留 package task | 外部结果五步导入后进入来源抽屉或 Script Stage |
| 直接 V2.1 JSON | `local-mini-drama.episode-package@2.1`；新建或空白集 | 五步预览，明确零媒体任务 | Schema/业务/非空冲突阻断；修复文件或换目标 | 导入报告页，再进入剧本/设定/分镜 |
| 从已有视频开始剪辑 | 先选安全目标；本地文件或媒体库条目；许可确认 | 显示探测信息、媒体大小和复制/引用策略 | 文件离线、Hash 变化可重定位或复制进项目；解码失败保留媒体记录草稿 | Cut Stage 来源媒体区；不伪造 Script/Asset/Shot 批准 |

新建项目提交前取消不得写入项目；提交后如果来源步骤取消，空项目保留并标“未创建剧集”，用户可继续创建第 1 集、进入项目或从项目菜单可恢复删除。新项目上下文只允许创建第 1 集，不显示既有项目的填充空白集、非空目标或任意集号选项。

## 3. 外部 AI 协作闭环

| 状态 | 入口/前置 | 操作与反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| context_ready | 新建/导入剧集→外部 AI；项目已保存 | 生成可复制 Markdown，显示纳入的剧集摘要和资产计数 | 上下文生成失败可重试；不创建 package | 复制上下文或继续生成任务 |
| package_ready | 已选新建/空白目标；上下文已确认 | 冻结目标、上下文版本、素材版本、结果 Schema、`package_id/assets_digest`；下载 ZIP 或单文件任务 JSON | 下载失败复用同一 package，不重新生成 id | 状态变为 `waiting_external` |
| waiting_external | 已有 package task | 剧集中心和任务中心同时显示目标、包名、创建时间、重新下载、复制说明、选择结果和取消任务 | 页面关闭或应用重启后恢复同一 attempt；可取消但保留审计 | 选文件进入校验 |
| validating_result | 选择外部结果 JSON | 校验 `schema/version/package_id/assets_digest/project/episode/context_revision` 和引用 | 资产快照变化时允许按冻结快照导入、重新匹配当前素材或放弃重建任务；引用丢失阻断；不得自动三方合并 | 进入统一五步导入 |
| importing | 五步决策完成且目标仍为空 | 提交前展示新建/复用数量和零远端费用 | `TARGET_NOT_BLANK` 回到目标步；事务失败保留文件、预览和决策 | 导入报告与只读来源抽屉 |

同一个结果重复提交必须由 `source_sha256 + package_id + target` 幂等识别；已成功导入时只打开原导入记录，不重复创建剧集或资产。

### 3.1 剧集中心导航与 Gate

| 用户动作 | 决策规则 | 成功落点 | 阻断与恢复 |
|---|---|---|---|
| 点击阶段格 | 使用该剧集的 Gate 投影，不复用其他剧集状态 | 可进入/已完成/需要更新进入准确阶段和版本 | 未解锁留在剧集页并显示前置条件；有阻塞进入对应阶段并定位阻塞 |
| 点击继续 | 硬阻塞优先，其次恢复 locator，再处理空白或已完成 | 恢复 `projectId + episodeId + sceneId/shotId + inspector + candidate/timelineTime` | locator 对象失效时回到正确阶段并说明，不能静默打开其他对象 |
| 创建或导入 | 先经过 `EpisodeTargetSelector` | 创建下一个可用集号或填充指定空白集 | 提交事务内重检目标；非空返回 `TARGET_NOT_BLANK` |
| 查看已归档 | 状态筛选进入归档集合 | 可恢复原集号、历史和来源 | 不允许日常物理删除 |

剧集页搜索输入停止 280ms 后按集号、标题和最近位置更新；默认集号升序，“最近工作”必须读取真实更新时间。状态筛选是第一层，阶段筛选是承接项目概览深链的第二层；项目空状态与筛选空结果不得复用。

### 3.2 项目设置进入外部 AI 协作

| 状态 | 入口/前置 | 操作与反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| settings_ready | 项目详情→项目设置 | 按项目资料与画面风格、生产对象、外部 AI 顺序展示；Header 无全页保存 | 局部统计失败只重试该区域；不清空已加载内容 | 留在项目设置 |
| profile_editing | 点击“编辑项目资料” | 编辑名称、封面、画幅、题材、默认时长和输出偏好；本地位置只读 | Dirty 离开需确认；Saving 锁控件；失败保稿；离线只读；重开同步恢复保存能力 | 更新项目资料，协作上下文标为需要更新 |
| look_selecting | 点击“更换画面风格” | 搜索/选择预设或自定义基础风格，预览引用与需要更新范围后创建新版本 | 取消零写入；失败保留选择；不自动重新生成历史媒体 | 返回项目设置并显示新当前版本 |
| context_editing | 点击“编辑创作上下文” | 只编辑故事基础、不可改变设定和跨集备注；显式保存/取消 | 离开有草稿需确认；保存失败保留全部输入；重开恢复 Dirty 与保存能力 | 更新当前上下文摘要 |
| context_copying | 点击“复制创作上下文” | 在抽屉预览包含来源，可复制或下载 Markdown；无需先选目标集 | 可选字段缺失只警告；复制失败保留预览并允许重试或下载 | 留在项目设置 |
| episode_selecting | 点击“创建外部 AI 制作任务” | 进入剧集创建/导入中心，选择新集或允许的空白目标集 | 取消不创建 package；项目和已保存设置保留 | context_preview |
| context_preview | 已选目标集 | 展示目标、包含来源、缺失项和项目/素材版本，再创建任务包 | 生成失败保留目标与预览；可重试或打开任务中心 | package_ready |

项目设置中的项目资料、故事基础设定和连续性备注变化只使后续外部 AI 上下文需要刷新，不触发既有图片/视频整体 stale。只有 Project Look 或明确生产状态作为有效输入进入任务快照后，才按实际引用传播失效。人物、场景、道具卡必须使用稳定 `focusId` 进入项目素材对应筛选；不得在项目设置内重复维护媒体候选、版本或生成任务。

### 3.3 剧本编辑、AI 候选与确认闭环

| 状态/动作 | 前置与即时反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|
| 编辑与自动保存 | 场次选择、结构化场景头和正文共同属于当前草稿；用户只看到未保存→保存中→已保存时间 | 保存失败或离线保留浏览器副本；仅在副本有差异时显示恢复入口 | 留在当前场次，已保存不等于已确认 |
| 409 冲突 | 展示本机恢复内容与服务端内容，禁止最后写入覆盖 | 可复制本机内容或由其创建新草稿；任一历史版本不变 | 新草稿继续编辑 |
| AI 续写/改写 | 选择方式、范围、模型和预计消耗；无文本选区时禁用选段改写 | 失败保留输入快照；部分成功允许应用成功场次并单独重试失败项 | 候选差异；应用后才进入未保存草稿 |
| 版本比较/恢复 | 按场次和段落展示新增、删除、修改；隐藏内部 revision id | 历史版本只读，恢复只能复制为新草稿 | 新草稿或返回当前编辑器 |
| 预计素材变化 | 保存后后台轻量解析新增、属性变化、删除候选与人工锁定 | 解析失败不影响草稿保存；可稍后重试 | 确认检查中逐项采用/忽略 |
| 检查并确认 | 草稿非空且已保存；显示场次、字数、预计时长、素材和下游影响 | 空白、保存中、保存失败、离线和冲突均阻断；确认失败保留已保存草稿 | 新 approved Script Revision；下游标记需评估，CTA 转到本集素材 |

确认新版本只创建版本与失效事实，不自动删除、覆盖或重新生成任何图片、视频和音频。后续阶段允许浏览旧快照，但不能把未确认草稿作为收费生成输入。

## 4. AI 配置基础与高级

| 区域/状态 | 入口与前置 | 操作与反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| Provider 列表 | 设置→AI 配置 | 显示已配置/缺失/认证过期、默认用途和最近测试 | 读取失败保留上次缓存并标时间；生成前仍需服务端复检 | 打开 Provider 详情 |

| 连接测试 | 基础配置已保存 | 明确“仅鉴权/列模型/健康检查，不生成媒体、不计生成任务” | 区分网络、认证、限流、余额和协议错误 | 写最近测试时间与结果 |

| 导出配置 | 高级→导出 | 默认脱敏；包含密钥需单独危险确认且本地加密 | 写文件失败可换目录重试 | 文件路径和 hash |
| 批量换 Key | 高级→凭据维护 | 先列受影响 Provider/项目引用，不改项目快照 | 任一保存失败整体回滚 | 连接测试队列，不自动生成 |
| 并发与队列 | 高级→调度 | 按 Provider 设置并发、lane 和本地显存限制 | 非法值内联阻断；降低并发不取消运行任务 | 新任务使用新策略 |
| 模型映射/Prompt 覆盖 | 高级映射 | 业务用途→模型；覆盖显示 diff、版本和作用域 | 变更令相关编译 stale，不改人工 prompt | 映射 revision 详情 |

## 5. ChatGPT 网页生成会话

ChatGPT 网页与 API、ComfyUI 同为 Product Core 一级可选生图通道，并可显式保存为全局或项目默认。新任务按“本次选择→项目默认→全局默认→安装默认”解析并冻结真实通道；已创建任务不随设置变化漂移。保存或提交前的环境检查只读取浏览器/Profile、桥接、登录和结果捕获能力，不发 prompt、不创建任务、不产生费用。环境不可用时保留用户默认值，提供修复动作以及“仅本次用 API/ComfyUI”；任何回退都不得静默写回默认值。

人物、场景、道具和分镜图片使用同一规则：生成成功只追加候选，用户点击候选后才更新当前使用项。ChatGPT 网页任务在独立任务页按项目/剧集/类型/通道定位；默认只显示创作者状态、耗时区间与一个主要动作，session、attempt、fingerprint、runtime owner 和原始 Provider 状态收进技术详情。

| 状态 | 入口/前置 | 用户反馈与动作 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| preflight | 图片生成抽屉选择 ChatGPT 网页 | 检查浏览器、扩展、登录、目标绑定、引用包 | 未登录进入 `waiting_external`，提供“打开登录页/重新检查” | 创建不可变 task 输入 |
| submitted | 已创建 session/attempt | 显示浏览器会话、已发送 prompt hash 和等待状态 | 用户关闭浏览器后保持 attempt；可“重新打开会话” | generating |
| generating | 外部页面处理中 | 页面可离开；任务中心持续显示 | 查询失败先标 unknown，不重复发送 prompt | result_detected |
| result_detected | 检测到一个或多个结果 | 预览来源 tab、结果 hash、尺寸与目标对象 | 重复回填按 result hash 去重；错误目标阻止采用 | 导入为候选 |
| rebind_required | 目标对象已删除/stale 或用户选错 | 显示原目标和允许的新目标；重绑写审计事件 | 已批准对象不可被覆盖；取消保留未绑定结果 | 新目标候选列表 |
| expired | 登录/会话失效 | 显示“重新登录后恢复原 attempt”，不把它当生成失败 | 恢复仍使用原 prompt/reference hash；明确新提交才产生新 attempt | 回到 submitted/generating |

## 6. 项目归档协议边界

| 场景 | 前置/识别 | 反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| 导出当前归档 | 项目数据完整性预检 | 显示包含对象、媒体策略、预计大小和版本 | 空间不足或文件占用时换目录重试 | 当前协议 ZIP + manifest/hash |
| 初始选择 | 尚未选文件 | 只显示当前协议、不会覆盖和“选择项目归档” | 取消返回项目列表，零写入 | validating |
| 校验中 | 已选择 ZIP | 逐项检查版本、结构、Hash、媒体、名称和含临时解压的峰值空间；提交禁用 | 可更换归档；读取失败保留错误报告 | ready / ready-with-warnings / unsupported |
| 可导入 | 根 manifest 与版本受支持 | 预览项目名、剧集、资产、媒体、任务历史；确认最终名称、目录和媒体策略 | 名称或空间阻断时停留确认页 | importing |
| 缺失媒体 | 数据可导入但部分媒体不可用 | 显示警告、缺失清单和“仍然导入为新项目”；不伪装为全绿 | 保留引用和 Hash，导入后重定位 | importing |
| 导入中 | 用户确认且二次预检通过 | 创建持久化任务，按字节和步骤显示进度；允许离页并从任务中心查看 | 中断后恢复原任务，不重复提交 | success / partial-success / rolled-back |
| 完整回滚 | 任一步骤提交失败 | 报告失败步骤、原因、临时文件清理和报告位置 | 数据库与媒体零残留；释放资源后安全重试 | 返回 importing |
| 成功/部分成功 | 事务提交完成 | 主动作只显示“打开项目”；报告和媒体重定位为次操作 | 历史任务只恢复记录，绝不自动运行或调用 Provider | Project Hub 新项目 |
| 历史/未知 ZIP | 版本不是当前协议或无 manifest | 显示检测版本、支持版本与 `ARCHIVE_VERSION_UNSUPPORTED` | 不尝试猜测、不部分解压、不调用单集 JSON 导入；只能重新选择 | 返回选择文件 |
| Phase 6 升级提示 | 仅扫描当前 SQLite，不扫描用户任意目录 | 明示“磁盘历史 ZIP 不在迁移范围” | 用户可退出并在旧开发版本中先导入 | 继续迁移预检 |

不建设旧 ZIP 兼容器。该决定服从“项目未正式上线、不保留旧协议”的已确认范围。

## 7. 本地个人资产库双向操作

| 方向/状态 | 前置 | 操作与反馈 | 失败/恢复 | 成功落点 |

## 8. 声音唯一所有权

所有权保存到 Episode Audio Plan，逐 Shot/Timed Segment 可覆盖。一个时间范围内同一语义声部只能有一个 owner。

| 声部 | 允许 owner | 前置与行为 | 冲突/恢复 | 成功反馈 |
|---|---|---|---|---|
| 对白 | `h3_native/post_tts/source_media/none` | H3 原声、后期 TTS 或已有视频原声三选一 | 切到 post_tts 时若 H3 不能分离语音，必须静音整条 H3 音频或重生成静音视频 | 时间线只显示一个主对白片段 |
| 旁白 | `h3_native/post_tts/source_media/none` | 默认 post_tts；逐段可覆盖 | 与同文本的 H3/source_media 重叠时阻断 Delivery | 显示 owner 与来源 revision |
| 环境声 | `h3_native/source_media/library/generated/none` | 可继承原视频环境或后期替换 | 不可分离的原声切换时提示将同时影响对白/音效 | 独立或合并声轨来源可追溯 |
| 音效 | `h3_native/source_media/library/generated/none` | 按事件和时段绑定 | 相同事件同区间多 owner 时警告并要求保留一个 | 事件与 Shot/Segment 对齐 |
| 音乐 | `episode_track/per_segment/source_media/none` | 遵守 BGM 策略 | source_media 音乐不可分离时，替换需静音原声或重新生成 | PostRevision 保存混音决定 |

所有权切换创建新的 Audio/Post revision，不覆写旧版本。Video Gate 可使用 H3 原声预览；Delivery Gate 必须确认所有对白/旁白重叠冲突为零。

| 确认锚点 | 来源可读且目标 Shot 明确 | 显示将影响的后续 Shot | 用户确认后才建立依赖 | continuity anchor revision |
| 断开依赖 | 下游 Shot 引用了锚点 | 显示哪些 prompt/candidate 将 stale | 断开不删除 artifact；可重新绑定 | 下游 Shot 新 revision |
| 重拍完成 | Provider 返回媒体 | 新结果进入候选组，不覆盖原候选 | 迟到/旧输入结果标 stale | 候选比较与采用 |

## 10. 任务能力与队列

| 状态/能力 | 可见动作 | 约束 | 失败/恢复 | 成功反馈 |
|---|---|---|---|---|
| queued | cancel；可选 pause/reorder | `canReorder` 仅同一 scheduler lane 且均未提交 Provider | 冲突刷新 queue revision；不静默重排 | 队列位置和预计开始更新 |
| running | cancel；Provider 支持时 pause | pause 必须由后端持久化，不靠前端倒计时 | Provider 不支持暂停则不显示 | paused 或 cancelled |
| waiting_external | open/resume/cancel | 指向登录、外部网页、文件回填或人工确认 | 关闭页面不丢 attempt | 恢复原 attempt |
| succeeded | open result；可选 retry-as-new | 不显示 resume/skip | 结果离线进入重定位 | 打开候选/artifact |
| failed | retry/cancel；流水线可选 skip | retry 复用输入与幂等键；新候选需显式操作 | 状态 unknown 时先对账 | 新 attempt 或 skipped |
| unknown | refresh/reconcile/cancel-local | 不自动判失败、不自动重提 | 对账后回真实状态；无法确认时保留 raw status | 状态与证据更新 |

任务中心按后端返回的 `canPause/canResume/canSkip/canCancel/canReorder` 渲染。跨 Provider、跨 scheduler lane 或已经提交远端的任务不能拖拽重排。

## 11. 首次升级、删除与物理清理

| 流程 | 入口/前置 | 操作与反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| 首次升级 | V2.1 启动且 DB 版本旧 | 任务冻结、空间/锁/备份预检，显示对象计数 | 查看报告、重试、打开备份目录、退出 | 迁移摘要→进入 V2.1 |
| 软删除项目/剧集 | 项目操作/剧集次级菜单 | 影响清单、运行任务、交付和媒体计数 | 有不可取消任务时阻断；取消操作零写入 | 回收站/归档筛选 |
| 恢复 | 回收站 | 显示名称/集号冲突和原路径 | 冲突需改名/改集号；媒体离线可先恢复对象 | 对象详情并显示待修复项 |
| 候选/资产归档 | 历史或候选详情 | 显示引用位置 | adopted/approved/Timeline 引用时禁止物理删除 | 归档筛选，可撤销 |
| 物理清理 | 设置→高级数据工具→物理清理 | dry-run 列表、预计回收空间、保留期、绝对目标根 | 路径越界、引用非零或任务活动时阻断 | 清理报告，不删除审计/revision |
| 迁移备份清理 | 设置→高级数据工具→迁移与恢复记录 | 首次 V2.1 备份默认永久保留，显示恢复价值 | 必须二次确认并验证不影响当前库 | 清理报告 |

## 12. 计划前验收

- 每个流程的入口在页面规格中有唯一位置。
- 每个失败状态至少有一个恢复或安全退出动作。
- `waiting_external`、blocker、内容状态和任务状态不会互相覆盖。
- 任何远端费用、覆盖写入、物理删除和迁移恢复都有明确确认。
- 原型只需演示高风险分支；完整业务闭环由 E2E 矩阵验证。

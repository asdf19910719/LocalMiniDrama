# Production Studio V2.1 关键交互流程合同

日期：2026-09-08
状态：P0 权威附件，实施计划前置输入

## 1. 文档职责

本文补齐架构母稿和页面 UI 规格中不能只用功能摘要表达的十类完整交互。每个流程必须明确入口、前置、操作、即时反馈、失败/恢复和成功落点。实施计划不得重新决定本文件已经固定的产品行为。

通用状态机：

```text
idle → editing/selecting → validating → confirming → executing
                                  ├→ validation_blocked → editing/selecting
                                  ├→ failed             → retry/recover/cancel
                                  └→ succeeded          → explicit success destination
```

这里的 `validation_blocked` 只是当前交互分支，不是阶段内容状态；持久化层仍记录 blocker/Gate 评估并保持原内容状态。取消不得产生当前步骤的新增业务写入；已经在前置步骤由用户显式提交的项目壳、任务或其他事实继续保留。事务型操作失败必须零部分写入；远端任务失败保留输入快照与 attempt。

## 2. 六类项目/剧集来源

统一入口是 Project Hub“新建项目”和项目详情“新建/导入剧集”。两者打开同一个来源选择器；项目入口会先创建项目壳，剧集入口直接绑定当前项目。

| 来源 | 前置与向导 | 执行反馈 | 失败与恢复 | 成功落点 |
|---|---|---|---|---|
| 空白手工 | 标题、集号、目标时长；不要求 AI 配置 | 创建摘要，远端费用 0 | 集号冲突停留表单；取消不写入当前剧集草稿，已显式创建的项目壳保留 | Script Stage 空白编辑器 |
| 想法/剧本 AI | 想法/剧本文本、生成集数、模型、费用确认 | 显示将创建的草稿数和任务 | 配置缺失阻断；部分生成失败可逐集重试，不重复成功集 | 剧集列表显示 draft，首集进入 Script Review |
| 小说/长文本分章 | 文本/文件、分章规则、集号起点 | 预览章节、标题、空段和冲突 | 解析失败保留原文；提交冲突整体拒绝 | 剧集列表，用户选择一集进入 Script Stage |
| 外部 AI 协作 | 项目存在；可选空白目标集 | 进入第 3 节任务包流程 | 会话/文件错误保留 package task | 外部结果五步导入后进入来源抽屉或 Script Stage |
| 直接 V2.1 JSON | `local-mini-drama.episode-package@2.1`；新建或空白集 | 五步预览，明确零媒体任务 | Schema/业务/非空冲突阻断；修复文件或换目标 | 导入报告页，再进入剧本/设定/分镜 |
| 已有视频 | 本地文件或媒体库条目；许可确认 | 显示探测信息、媒体大小和复制/引用策略 | 文件离线可重定位；解码失败保留媒体记录草稿 | Cut Stage 来源媒体区；不伪造 Script/Asset/Shot 批准 |

项目壳创建后如果后续来源步骤取消，空项目保留并标“未创建剧集”，用户可删除或改选来源；不得静默删除可能已经填写的项目设定。

## 3. 外部 AI 协作闭环

| 状态 | 入口/前置 | 操作与反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| context_ready | 新建/导入剧集→外部 AI；项目已保存 | 生成可复制 Markdown，显示纳入的剧集摘要和资产计数 | 上下文生成失败可重试；不创建 package | 复制上下文或继续生成任务 |
| package_ready | 剧情已在外部会话确认；选择新建/空白目标 | 生成 `package_id/assets_digest`；下载 ZIP 或单文件任务 JSON | 下载失败复用同一 package，不重新生成 id | 状态变为 `waiting_external` |
| waiting_external | 已有 package task | 显示等待说明、重新下载、复制 Schema、选择结果文件 | 可放弃 attempt，但保留任务审计 | 选文件进入校验 |
| validating_result | 选择外部结果 JSON | 校验 `schema/version/package_id/assets_digest` 和引用 | 资产摘要变化显示 diff；引用丢失阻断；不得自动三方合并 | 进入统一五步导入 |
| importing | 五步决策完成且目标仍为空 | 提交前展示新建/复用数量和零远端费用 | `TARGET_NOT_BLANK` 回到目标步；事务失败保留文件、预览和决策 | 导入报告与只读来源抽屉 |

同一个结果重复提交必须由 `source_sha256 + package_id + target` 幂等识别；已成功导入时只打开原导入记录，不重复创建剧集或资产。

### 3.1 项目设定进入外部 AI 协作

| 状态 | 入口/前置 | 操作与反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| settings_ready | 项目详情→项目设定 | 三块式显示创作上下文、Project Look、人物/场景/道具摘要 | 局部统计失败只重试该区域；不清空已加载内容 | 留在项目设定 |
| context_editing | 点击“编辑创作上下文” | 编辑项目简介、题材、故事基础、不可改变设定和跨集备注；显式保存/取消 | 离开有草稿需确认；保存失败保留全部输入 | 更新当前上下文摘要 |
| episode_selecting | 点击“生成外部 AI 上下文” | 进入剧集创建/导入中心，选择新集或允许的空白目标集 | 取消不创建 package；项目壳和已保存设定保留 | context_preview |
| context_preview | 已选目标集 | 展示包含来源、缺失项、人物/场景/道具计数和目标集；可复制或下载 Markdown | 可选字段缺失只警告；生成/复制失败保留预览并允许重试或手工复制 | context_ready 或 package_ready |

项目设定中的项目简介、故事基础设定和连续性备注变化只使后续外部 AI 上下文需要刷新，不触发既有图片/视频整体 stale。只有 Project Look 或明确生产状态作为有效输入进入任务快照后，才按实际引用传播失效。人物、场景、道具卡必须使用稳定 `focusId` 进入项目资产对应筛选；不得在项目设定内重复维护媒体候选、版本或生成任务。

## 4. AI 配置基础与高级

| 区域/状态 | 入口与前置 | 操作与反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| Provider 列表 | 设置→AI 配置 | 显示已配置/缺失/认证过期、默认用途和最近测试 | 读取失败保留上次缓存并标时间；生成前仍需服务端复检 | 打开 Provider 详情 |
| 基础配置 | Provider 详情“基础” | endpoint、模型、非明文 Key 引用、启用状态；保存前本地校验 | 409 保留本地表单并提供刷新比较 | 返回列表并更新 capability |
| 连接测试 | 基础配置已保存 | 明确“仅鉴权/列模型/健康检查，不生成媒体、不计生成任务” | 区分网络、认证、限流、余额和协议错误 | 写最近测试时间与结果 |
| 导入配置 | 高级→导入 | 预览新增/覆盖/跳过；密钥字段默认不导入 | Schema 错误零写入；冲突由用户逐项决定 | 配置列表与导入报告 |
| 导出配置 | 高级→导出 | 默认脱敏；包含密钥需单独危险确认且本地加密 | 写文件失败可换目录重试 | 文件路径和 hash |
| 批量换 Key | 高级→凭据维护 | 先列受影响 Provider/项目引用，不改项目快照 | 任一保存失败整体回滚 | 连接测试队列，不自动生成 |
| 并发与队列 | 高级→调度 | 按 Provider 设置并发、lane 和本地显存限制 | 非法值内联阻断；降低并发不取消运行任务 | 新任务使用新策略 |
| 模型映射/Prompt 覆盖 | 高级映射 | 业务用途→模型；覆盖显示 diff、版本和作用域 | 变更令相关编译 stale，不改人工 prompt | 映射 revision 详情 |

## 5. ChatGPT 网页生成会话

| 状态 | 入口/前置 | 用户反馈与动作 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| preflight | 图片生成抽屉选择 ChatGPT 网页 | 检查浏览器、扩展、登录、目标绑定、引用包 | 未登录进入 `waiting_external`，提供“打开登录页/重新检查” | 创建不可变 task 输入 |
| submitted | 已创建 session/attempt | 显示浏览器会话、已发送 prompt hash 和等待状态 | 用户关闭浏览器后保持 attempt；可“重新打开会话” | generating |
| generating | 外部页面处理中 | 页面可离开；任务中心持续显示 | 查询失败先标 unknown，不重复发送 prompt | result_detected |
| result_detected | 检测到一个或多个结果 | 预览来源 tab、结果 hash、尺寸与目标对象 | 重复回填按 result hash 去重；错误目标阻止采用 | 导入为候选 |
| rebind_required | 目标对象已删除/stale 或用户选错 | 显示原目标和允许的新目标；重绑写审计事件 | 已批准对象不可被覆盖；取消保留未绑定结果 | 新目标候选列表 |
| expired | 登录/会话失效 | 显示“重新登录后恢复原 attempt”，不把它当生成失败 | 恢复仍使用原 prompt/reference hash；明确新提交才产生新 attempt | 回到 submitted/generating |

## 6. 项目归档协议边界

| 场景 | 前置/识别 | 反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| 导出当前归档 | 项目数据完整性预检 | 显示包含对象、媒体策略、预计大小和版本 | 空间不足或文件占用时换目录重试 | 当前协议 ZIP + manifest/hash |
| 导入当前归档 | 根 manifest 与版本受支持 | 预览项目名、剧集、资产、媒体缺失和冲突 | 失败零项目壳；可重选文件 | Project Hub 新项目 |
| 历史/未知 ZIP | 版本不是当前协议或无 manifest | 明确 `ARCHIVE_VERSION_UNSUPPORTED` | 不尝试猜测、不部分解压、不调用单集 JSON 导入 | 返回选择文件 |
| Phase 6 升级提示 | 仅扫描当前 SQLite，不扫描用户任意目录 | 明示“磁盘历史 ZIP 不在迁移范围” | 用户可退出并在旧开发版本中先导入 | 继续迁移预检 |

不建设旧 ZIP 兼容器。该决定服从“项目未正式上线、不保留旧协议”的已确认范围。

### 7.1 项目资产日常流程

| 场景 | 前置 | 操作与反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| 检索项目资产 | 项目资产索引可读 | 统计入口施加精确筛选；搜索、状态/使用/来源/媒体/剧集筛选及四种排序可组合，结果数和条件写入 URL | 筛选空显示清除条件；读取失败保留条件并重试 | 原列表位置 |
| 新增资产 | 当前项目可写 | 两步选择人物/场景/道具并填写类型最低字段；可仅建草稿、创建并上传或进入生成参数确认，默认不调用 AI | 取消零写入；名称冲突提示打开已有项、改名或取消，禁止静默合并 | 资产草稿详情 |
| 上传媒体 | 已选择目标资产 | 本地预检后保存为候选，不覆盖当前使用媒体 | 重复 hash 选择复用/辅助参考/取消；失败保留表单 | 版本与候选 |
| 生成候选 | 目标版本、Look、模式、参考和 Provider 能力可检查 | 展示输入、模型、数量、画幅、费用后创建统一任务 | 失败保留输入快照；认证失效恢复原 attempt | 候选组 |
| 人物状态生图 | 已选人物及人物状态 | 在现有 `SINGLE` 单图和 `TURNAROUND` 三/四视图间选择；模式按状态保存，生成/上传只增加该状态候选 | 失败保留模式、Prompt、身份锚点和参考图快照；不影响其他人物状态或音色 | 人物形象候选区；不自动改选 current |
| 比较与使用 | 至少一个生成或上传候选 | 点击候选卡即更新 current pointer；旧 current 留在候选历史；不再另设临时选择、采用和对象批准 | 409 保留候选列表并刷新 current；已确认剧集快照不被改写 | 资产详情；剧集设定阶段提示是否刷新快照 |
| 场景/道具状态与视图切换 | 对象至少有一个剧情状态和视图参考 | 先选择剧情状态，再选择视图参考；候选和 current 只属于该组合。场景视图允许用户按需新增和命名 | 缺少目标组合时保留当前页面并提示新增状态或视图；不得回退成无语义多图列表 | 目标状态/视图的候选区 |
| 场景生成模式 | 已选场景剧情状态与视图参考 | 从单图、四宫格、独立俯视图、全景图中选择；生成成功只进入候选。四宫格可拆为主、反、俯视和补充视图候选 | 任务失败保留模式、Prompt 与参考图快照并提供重试；拆分失败保留四宫格原图 | 版本与候选；不自动改选 current |
| 场景资料与参考图 | 已打开场景概览 | 资料表单保存地点、时间、环境、状态和氛围；参考图可来自上传、资产库或当前候选，并标注布局/构图/材质/光线用途 | 保存失败保留输入；解除参考只移除关系，不删除源文件或替换 current | 场景概览原位置 |
| 进入分镜 | 本集必需 Look 已确认，人物状态、场景和道具有可用 current；所选音频策略要求人物音色时，该音色也有可用 current | 点击后自动预检，只保存实际引用的精确版本/hash episode asset snapshot 并通过 Asset Gate；不再弹出额外确认 | 必需项按对象列出并精确跳转；非必需音色只警告；事务失败不写部分快照 | 当前剧集分镜阶段 |
| 批量资产操作 | 用户进入按需选择模式 | 只允许生成缺失候选、设置未来默认模式、添加/移除标签和归档未使用项；预览已选、可执行、跳过、阻塞、Provider、模型、任务数、费用与并发 | 部分任务失败可只重试失败项；不得批量改选 current、批准或物理删除 | 全局任务中心与原筛选结果 |
| 归档 | 对象可读 | 展示全部使用位置；归档可恢复 | 引用中的批准版本仍保留可读；物理删除被阻断 | 已归档筛选 |
| 库版本更新 | 项目固定引用的库资产出现新版本 | 只提示并显示 diff | 不自动漂移；用户可忽略或派生新项目草稿 | revision diff |

人物状态和人物音色都归人物对象，人物形象与音色分别维护候选/current；项目资产页不建立平级声音标签。人物音色缺失采用条件 Gate，只有所选音频策略明确依赖该音色时才阻断。人物本体与人物状态保留现有单图/三四视图两种生图模式，不能因音色合并而隐藏形象生成。场景资产不得与叙事场次混用。场景和道具均按“对象 → 剧情状态 → 视图参考 → 候选”组织，剧情变化与空间/构图角度分层。生成模式是候选任务参数，不是视图层级：旧版单图/四宫格继续保留，独立俯视图/全景图作为 V2.1 新增场景预设。分镜图片与逐镜正式视频候选归 Storyboard，整集审核、环境声、音效、音乐、声音 owner 和混音归 Cut。项目资产页不得承载这些镜头媒体、时间线或完整任务队列。

### 7.2 分镜生成视频与短片复核

| 状态 | 入口/前置 | 操作与反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| 从当前剧本重新生成分镜 | 当前剧集有已确认 Script revision | 显示来源 revision、结构模型、预计费用/耗时；生成后展示新增/变化/拟删除/不变逐镜 diff | 人工锁定冲突逐项处理；取消不写入；既有媒体历史不删除 | 用户确认后创建新 Shot revision |
| 导入分镜文件 | Storyboard；选择 Excel/CSV/shot-package@2.1 JSON | 选择文件 → 解析/字段映射 → 结构预览 → 资产匹配 → 版本差异 → 确认写入；完整单集包转剧集页 | Schema/字段/时长/资产匹配失败保留预览并返回对应步骤；禁止直接覆盖 | 创建新 Shot revision；待确认资产精确列出 |
| 编译与预检 | Storyboard；Shot Package 已保存 | 展示业务 Prompt、编译结果、Reference Manifest、Provider 能力、计划/请求时长和所有降级 | 能力不支持时提供拆分分镜或换模型；人工 Prompt 只标 stale 不覆盖 | 可提交的不可变输入快照 |
| 生成/编辑 H3 草稿 | H3 Recipe；Shot、引用和声音事件已保存 | 独立动作生成可编辑草稿，显示来源 revision/fingerprint、生成时间和结构/槽位/声音语义/风格校验 | 来源变化标 stale、校验失败标 invalid；保留人工文本，可编辑或重新生成；两者均阻断正式任务 | 校验通过的 H3 草稿 |
| 确认正式任务 | 预检及 H3 校验通过 | 显示任务数、并发、分辨率、输出计划/请求时长、预计排队/处理/总耗时、统计样本、预计费用/资源；用户明确确认后提交 | 取消零任务；认证失效恢复原 attempt；重复命令幂等；预计耗时明确为非承诺值 | 任务中心并留在当前分镜 |
| 任务运行/完成 | Provider 已接受任务或返回可读媒体 | 运行中显示已运行与预计剩余；完成记录提交/开始/完成时间及实际排队/处理/总耗时，新结果追加到唯一 VideoCandidate 组 | 迟到/旧输入结果标 stale；失败保留快照，可原参数重试或换模型 | 分镜视频候选区与任务中心 |
| 比较与使用 | 至少一个候选 | 点击候选只预览；点击“使用这个候选”才写 adopted pointer 和事件，旧候选保留 | 409 刷新 current 并保留预览选择 | 当前分镜；可继续下一镜或进入短片审核 |
| 批量生成 | 多选镜头 | 预览命中/跳过/阻塞、任务数、并发和费用；部分成功保留 | 按失败原因分组重试，不回滚成功镜头 | 镜头轨与任务中心 |
| 短片镜头审核 | 至少有 Shot Package；可在候选未齐时软进入 | 连续播放、逐镜复核、A/B、技术质量、稳定帧和 Video Gate | 缺失/失败可返回分镜，或从审核页打开同一生成服务补充候选/局部重拍 | 时间线或具体问题镜头 |
| 短片改选候选 | 镜头已有其他候选 | 先更新 adopted；若 Timeline 已引用旧 candidate，询问替换或仅改默认候选 | 取消不改变任何 pointer/revision | 替换时派生 Timeline revision；否则 Timeline 保持不变 |

`进入短片审核` 只是页面导航。候选生成成功不等于采用，采用不等于 Video Gate 已批准；只有 Picture Lock 前的 Video Gate 才强制要求每个必需镜头有 adopted 候选或有效豁免。

## 8. 声音唯一所有权

所有权保存到 Episode Audio Plan，逐 Shot/Timed Segment 可覆盖。一个时间范围内同一语义声部只能有一个 owner。

| 声部 | 允许 owner | 前置与行为 | 冲突/恢复 | 成功反馈 |
|---|---|---|---|---|
| 对白 | `h3_native/post_tts/source_media/none` | H3 原声、后期 TTS 或已有视频原声三选一 | 切到 post_tts 时若 H3 不能分离语音，必须静音整条 H3 音频或重生成静音视频 | 时间线只显示一个主对白片段 |
| 旁白 | `h3_native/post_tts/source_media/none` | 默认 post_tts；逐段可覆盖 | 与同文本的 H3/source_media 重叠时阻断 Delivery | 显示 owner 与来源 revision |
| 环境声 | `h3_native/source_media/library/generated/none` | 可继承原视频环境或后期替换 | 不可分离的原声切换时提示将同时影响对白/音效 | 独立或合并声轨来源可追溯 |
| 音效 | `h3_native/source_media/library/generated/none` | 按事件和时段绑定 | 相同事件同区间多 owner 时警告并要求保留一个 | 事件与 Shot/Segment 对齐 |
| 音乐 | `episode_track/per_segment/source_media/none` | 遵守 BGM 策略 | source_media 音乐不可分离时，替换需静音原声或重新生成 | PostRevision 保存混音决定 |

所有权切换创建新的 Audio/Post revision，不覆写旧版本。Video Gate 可使用 H3 原声预览；Delivery Gate 必须确认所有对白/旁白重叠冲突为零。

| 状态 | 入口/前置 | 操作与反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|
| 选择重拍区间 | Cut→镜头审核→局部重拍；已有 adopted 候选 | 时间轴框选区间，显示保持区/修改区与预计请求 | Provider 不支持 V2V/mask 时提供换模型或返回分镜整镜重生 | 重拍任务确认 |
| 选择连续性来源 | 上一镜有 adopted artifact | 可选原始稳定帧、超分稳定帧或用户上传线稿；显示来源 hash/时间点 | 派生文件离线可回到原始帧；线稿缺许可阻断 | reference artifact 草稿 |
| 确认锚点 | 来源可读且目标 Shot 明确 | 显示将影响的后续 Shot | 用户确认后才建立依赖 | continuity anchor revision |

## 10. 任务能力与队列

| 状态/能力 | 可见动作 | 约束 | 失败/恢复 | 成功反馈 |
|---|---|---|---|---|
| queued | cancel；可选 pause/reorder | `canReorder` 仅同一 scheduler lane 且均未提交 Provider | 冲突刷新 queue revision；不静默重排 | 队列位置和预计开始更新 |
| running | cancel；Provider 支持时 pause | pause 必须由后端持久化，不靠前端倒计时 | Provider 不支持暂停则不显示 | paused 或 cancelled |
| waiting_external | open/resume/cancel | 指向登录、外部网页、文件回填或人工确认 | 关闭页面不丢 attempt | 恢复原 attempt |
| succeeded | open result；可选 retry-as-new | 不显示 resume/skip | 结果离线进入重定位 | 打开候选/artifact |
| failed | retry/cancel；流水线可选 skip | retry 复用输入与幂等键；新候选需显式操作 | 状态 unknown 时先对账 | 新 attempt 或 skipped |
| unknown | refresh/reconcile/cancel-local | 不自动判失败、不自动重提 | 对账后回真实状态；无法确认时保留 raw status | 状态与证据更新 |

任务中心按后端返回的 `canPause/canResume/canSkip/canCancel/canReorder` 渲染。跨 Provider、跨 scheduler lane 或已经提交远端的任务不能拖拽重排。

| 流程 | 入口/前置 | 操作与反馈 | 失败/恢复 | 成功落点 |
|---|---|---|---|---|

## 12. 计划前验收

- 每个流程的入口在页面规格中有唯一位置。
- 每个失败状态至少有一个恢复或安全退出动作。
- `waiting_external`、blocker、内容状态和任务状态不会互相覆盖。
- 任何远端费用、覆盖写入、物理删除和迁移恢复都有明确确认。
- 原型只需演示高风险分支；完整业务闭环由 E2E 矩阵验证。

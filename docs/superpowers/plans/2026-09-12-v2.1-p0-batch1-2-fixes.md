### Task 4: 剧本 409 冲突对比解决流（P0-14）

**Files:**
- Modify: `frontweb/src/views/productionStudio/studio/ScriptStage.vue`（saveDraft 409 分支；新增冲突 Modal：双栏 diff 复用 `buildInlineDiff`；三动作）
- Test: `frontweb/test/` 追加断言（409 时必须出现 conflictModal 与「载入最新版本」；不得默认覆盖）

- [ ] Step 1: 失败测试：断言 `saveConflict` 为 true 时存在 `conflictModalOpen`、`loadServerVersion`、`overwriteServerVersion` 方法与「另一窗口已保存」文案，且 retrySave 不再直接覆盖保存
- [ ] Step 2: 确认失败
- [ ] Step 3: 实现——

```js
// data 增加：conflictModalOpen: false, conflictServerText: '', conflictServerRevision: null
// saveDraft catch 409 分支改为：
this.saveConflict = true
try {
  const server = await v21.getScript(this.episodeId)
  this.conflictServerText = server?.draft?.content || ''
  this.conflictServerRevision = server?.draft?.revision ?? null
} catch { /* 取不到服务端内容时仅提供覆盖确认 */ }
this.setSave('保存冲突：另一窗口已保存新版本，请比较后选择', true)
this.conflictModalOpen = true
// retrySave 删除（被三动作取代）
async loadServerVersion() {           // 放弃本机，载入服务端最新
  this.draftText = this.conflictServerText
  this.dirty = false
  this.saveConflict = false
  this.conflictModalOpen = false
  this.model = await v21.getScript(this.episodeId)
  this.setSave('已载入最新版本')
},
async overwriteServerVersion() {      // 明确确认后覆盖
  await this.saveDraft(this.draftText, this.model?.draft?.revision)
  if (!this.saveConflict) this.conflictModalOpen = false
},
```

Modal（`.modal` 560px，scrim 不可点关闭）：标题「版本冲突」；双栏 `<div class="row">` 各半宽 pre.mono 滚动区（本机修改 / 服务端最新 vN），复用既有 `buildInlineDiff` 高亮可选；底部三按钮：`ghost 载入最新版本（放弃本机修改）` danger `覆盖服务端版本` `保留现状（稍后处理）`。
- [ ] Step 4: 测试通过 + 手动验证（双窗口改稿触发 409）
- [ ] Step 5: Commit `fix: 剧本 409 冲突改对比解决流，杜绝静默覆盖（P0-14）`

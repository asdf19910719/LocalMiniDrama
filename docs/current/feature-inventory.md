# 当前功能清单

> 本清单按仓库真实路由、界面调用、服务实现、数据表和测试交叉判断。
> `COMPLETE` 表示产品代码闭环，不表示第三方模型无需密钥或一定可用。状态定义见 [product-model.md](./product-model.md#7-功能成熟度)。

## 1. 应用壳与导航

| 功能 | 状态 | 当前实现与边界 |
|---|---|---|
| Vue 单页应用壳 | `COMPLETE` | Vue 3、Vite、Element Plus、Pinia；路由承载所有主要页面 |
| 项目列表 → 项目详情 → 制作台导航 | `COMPLETE` | 主生产路径清楚，制作台按剧集上下文工作 |
| 线性七阶段导航 | `COMPLETE` | 脚本、角色、道具、场景、分镜脚本、分镜图像、分镜视频 |
| 画布制作台入口 | `COMPLETE` | 项目详情和制作台可进入 Vue Flow 画布 |
| AI 配置独立页与弹窗 | `LEGACY` | 两个入口承载近似内容；主使用路径偏向弹窗，独立页形成重复表面 |
| 主题切换 | `COMPLETE` | 项目列表和制作页有入口 |
| 自由创作导航 | `LEGACY` | 路由存在，但主要导航按钮已注释隐藏；页面关键图像流程另判为 `BROKEN` |

## 16. 清单结论

- 主生产链路已经达到“可用产品”而非原型：项目、资产、分镜、生成、选片和合成均有真实持久化与测试。
- `PARTIAL` 项多数不是缺少按钮，而是恢复、数据一致性、安全边界或供应商抽象尚未闭环。
- `BROKEN` 项应从产品承诺中移除，或在重新定义 API 契约后修复，尤其是自由创作图像、媒体上传/搜索、角色提取占位和 OpenClaw 适配。
- 后续新增能力前，应先收敛任务模型、供应商适配层和关系数据来源，否则功能库存会继续增长但可靠性下降。

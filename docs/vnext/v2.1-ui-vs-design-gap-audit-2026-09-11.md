# V2.1 UI 实现 vs 设计/原型文档 逐页逐弹窗遗漏审计

- 日期：2026-09-11
- 对比基线：
  - 交互与 UI 规格：`docs/research/localminidrama-product-baseline/production-studio-v2.1-interaction-ui-spec.md`（2026-09-11 版）

  - 逐页评审决策记录：`docs/superpowers/specs/2026-09-08-production-studio-v2.1-page-review-decision-log.md`（用于排除"故意裁剪"，避免误报）

  - 高保真设计稿：`docs/design/v2.1-ui/`（35 张）

- 方法：按页面/容器分组，逐项对比"规格条文 + 原型渲染与事件处理 + 原型状态机"与"实现模板/逻辑/API 接线"；关键 P0/P1 结论经主线程二次抽查验证（renameEpisode 双重包装、moveSegment 缺封装、uploadShotImage 误挂分镜端点、/api/v1/tasks 强制 resource_id、createWaiver 零调用均已实测证实）。

## 总体结论

实现骨架（路由、Rail、五区分镜、单屏成片、三 Tab 引用投影、自动保存/乐观锁、候选-采用、导出）与设计稿对齐良好；但**原型/规格定义的状态机、确认流、恢复路径与管理型功能存在系统性缺失**，另有 **9 处交互实际损坏（点击报错/静默失效/数据写坏）**。

| 级别 | 数量 | 说明 |
|---|---|---|
| P0（核心缺失/功能损坏） | 13 | 见 §1 |
| P1（功能/入口缺失可绕行，含失效 bug） | ~110 | 见 §2 分组 |
| P2（状态/文案/微交互） | ~150 | 见 §2 分组内压缩列出 |
| 已按决策裁剪核对项 | 30+ | 见 §3，均确认不属于遗漏 |

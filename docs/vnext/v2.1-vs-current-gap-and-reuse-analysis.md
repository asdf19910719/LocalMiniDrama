# 当前版本与 V2.1 下个大版本·产品功能差距与复用分析

日期：2026-09-10
对照对象：当前产品（frontweb + backend-node，下称 V1）与 Production Studio V2.1 统一原型（下称 V2.1）。
用途：V2.1 开发排期的范围依据——哪些是新开发、哪些是改造、哪些直接复用。

## 1. 信息架构差异（最大的结构性变化）

| 维度 | V1 现状 | V2.1 目标 | 差距类型 |
|---|---|---|---|
| 制作入口 | `FilmCreate.vue` 单页长流程（故事→剧本→管线→资源→分镜→合成，11000+ 行） | 四阶段独立路由：剧本→设定→分镜→短片，每阶段独立工作台 | **重构**：页面壳与路由新写；阶段内能力大多复用 |
| 项目中心 | `DramaDetail.vue`（分集+资源库 Tab） | 概览/剧集/项目素材三页 + 项目操作菜单 | **重构**：概览与剧集中心为新页面 |
| 阶段实体 | 无场次实体；分镜行内 `segment_title` 分幕 | 场次（StoryScene）—分镜—时段三层 | **新开发**：场次表 + 时段表 |
| 导航与术语 | 长页锚点导航；术语混杂 | 阶段导航组件 + 个人创作者语言 | **改造** |

## 2. 逐功能域对比

### 2.1 剧本阶段
- V1：剧本生成/编辑在长页内；确认与版本语义弱（script_content 字段）。
- V2.1：场次列表 + 编辑器两栏、版本历史（已确认版本/草稿/恢复副本）、AI 候选先比较后应用、素材提取差异、确认影响说明。
- **需开发**：剧本版本/确认状态机（新表或 episodes 扩展）、场次级 diff、AI 候选暂存。
- **可复用**：AI 文本生成链路（chat completion 封装）、提示词模板。

### 2.2 设定阶段（原"本集素材"）
- V1：资源管理区 + 资源库弹窗 + 人物状态变体（episode_characters）+ 四视图/四宫格生图。
- V2.1：继承摘要 + 差异/缺失/阻塞清单 + 页内决策抽屉 + 快照事务（进入分镜前固化版本）。
- **需开发**：设定快照事务（snapshot 表）、继承摘要视图、条件音色解析。
- **可复用**：characters/scenes/props 表、人物状态变体、生图多通道（API/ChatGPT 网页/ComfyUI）、资产级生图模式、 libraries 三表。

### 2.3 分镜阶段（V2.1 已按 STORYBOARD-021 重设计）
- V1 已有（**直接复用**）：
  - 分镜 CRUD/AI 拆分镜（`generateStoryboard` + async_tasks）
  - 素材绑定与 `reference-slots`（@图片N 槽位解析，分镜图/H3/视频三处共用）
  - 分镜图生成（`/images` 多 provider + 历史图条）与首尾帧（`frame_prompts` + 尾帧衔接 tail_frame_link）
  - H3 全链路：草稿编译（h3PromptDraftService/h3SkillAgent/技能包）、结构校验、语义审核、门禁、TE-Speed 工作流切换
  - 视频候选组（director_candidate_groups/candidates、选用/锚点、质量检查）
  - 全能提示词（universal_segment_text + NDJSON 流式）
- **需开发/改造**：
  1. 独立分镜页路由 + 五区前端工作台（替换长页分镜区）
  2. 时段（segment）实体化：V1 是行内字段/全能文本，V2.1 需要 `storyboard_segments` 表（时码/画面/对白/资产引用）与拆分/合并/重排 API
  3. 场次实体与分镜归属、场次筛选
  4. 上一镜/下一镜、镜头时间线（纯前端）
  5. 素材预览抽屉与引用管理抽屉（数据已有，UI 新）
  6. 图片提示词字段已有（image_prompt）✓，补"自动拼装/手工覆盖"两态
- V1 需迁移决策：全能模式 vs 时段模型合并（迁移矩阵 B-02 已定：不建两类分镜实体）

### 2.4 短片阶段（V2.1 已按 CUT-002 重设计）
- V1 已有（**复用**）：整集合成（video_merges + videoMergeService）、合成保留 H3/原声 + TTS/BGM 混音、超分（video_upscale_jobs）、SRT 导出。
- **需开发**：
  1. 独立短片页（大播放器 + 成片设置 + 镜头时间线）
  2. 成片版本化（成片 vN 表：来源镜头候选快照 + 合成设置 + 产物路径）
  3. 合成任务化（进度/取消/失败重试走统一任务模型）
  4. 完成度门禁 API（x/y 已完成、基于旧图未确认镜头统计——数据已在 storyboards 状态字段）
- V2.1 移除项（不需要开发）：多轨时间线、声音归属矩阵、字幕编辑器、七步后期链 UI、Picture Lock 语义。

## 3. 开发范围建议（按依赖排序）

1. **地基**：四阶段路由与工作台壳、场次实体、时段表、术语统一（数据迁移脚本）。
2. **分镜页**（最高价值）：五区前端 + 时段编辑 API + 素材预览/引用管理抽屉；复用既有生成/H3/候选后端。
3. **短片页**：成片版本表 + 合成任务化 + 前端单屏；复用 video_merges 混音。
4. **项目中心**：概览/剧集中心（含 Gate→顺序解锁语言、外部 AI 任务卡）；设定快照事务。
5. **全局页**：任务中心、自由创作改造、AI 配置三页；资产库音色扩展。
6. **后置（P2）**：高级画布、高级数据工具、多轨精剪（若有需求挂画布）。

## 4. 复用清单速查（开发时先查这里）

后端直接复用：storyboards/episodes/dramas 表体系、reference-slots、frame_prompts、H3 三服务 + 技能包 + 草稿表、director 候选三表、video_generations、video_merges、video_upscale_jobs、images/image_generations、ai_service_configs/ai_model_map、stylePresets、外部 AI 协作全套、async_tasks、*_libraries。
前端直接复用：风格选择器、VideoGenerationPanel 的 H3 区与候选逻辑（改造进新分镜页）、画布底座、AI 配置检测逻辑。
前端新写：四阶段壳、分镜五区、短片单屏、项目中心三页、任务中心、资产库向导、设置三页。

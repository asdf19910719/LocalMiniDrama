- 候选卡仅显示 url + provider·时间，**无 prompt/模型/尺寸/模式**（`ProjectAssetsView.vue` 候选渲染；`assetQueryService.js:301-307` 映射丢弃 size/model/negative_prompt）。
- 生成记录的提示词为**单行 320px 截断**，无展开/复制，且 SELECT 只取 provider/created_at/prompt/status（`assetQueryService.js:237-245`）；DB 实有 model/size/width/height/negative_prompt 列（`db/migrate.js:372-398`）但 v21 查询不取、mock 生成 INSERT 也不写入——**前端与查询层双缺失**。
- 规格要求的"高级"标签页（完整 Prompt/负向词/风格继承/参考图/provenance/fingerprint）整体缺失。

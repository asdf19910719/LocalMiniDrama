## 5. Remaining Risks

1. 配置了本地 Provider（18080/8188）但服务未启动时，相关生成按钮会失败——错误已可见，但用户需自行启动服务或切换通道。
2. mock 视频任务耗时较长（ffmpeg），期间镜头轨显示"处理中"，用户可能误以为卡死。
3. 3013 端口残留旧 Vite 实例：若用户访问 3013 会看到旧版页面，建议关闭旧进程。
4. 约 40 条 P3/边缘项登记于 SDD 台账与 bug-report，均为低概率或轻微体验项。

## 6. Recommended Release Decision

**建议发布给真实用户使用（本地单人场景）。** 核心创作链已端到端验证，发现的所有 P1 及以上问题均已修复并通过 UI 复测与自动化回归（后端 1156 / 前端 366 / 原型 174 全绿）。外部 AI 依赖（真实 Provider）不可用时产品按"无 Key 可运行"合同以 mock 通道完成全流程。

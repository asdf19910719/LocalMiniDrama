# 风格业务整理

本目录单独归档 LocalMiniDrama 的画面风格业务现状，以及对 RunningHub AI 漫剧工作台风格流程的调研结果。

- [当前项目风格业务说明](./当前项目风格业务说明.md)：说明风格选项、保存结构、提示词合并优先级、图片与视频生成链路，以及“电影感”的实际处理。
- [RunningHub风格业务调研](./RunningHub风格业务调研.md)：说明登录态实时风格数量、公开构建中的结构化提示词、选择与覆盖流程、提示词编译逻辑、验证边界和可借鉴方案。
- [RunningHub真实风格提示词与模型映射](./RunningHub真实风格提示词与模型映射.md)：登录态接口导出的 169 个风格、提示词、结构化关键词及图片模型映射；同目录另有完整 JSON 数据。
- [LocalMiniDrama风格目录v1](./LocalMiniDrama风格目录v1.json)：当前程序实际加载的 169 个规范化 StyleSpec，包含稳定 `style_id`、中英文展示、中文原始提示词、可直接用于模型的英文提示词、能力建议、RunningHub 模型键和本地预览路径。
- [RunningHub真实生成案例分析](./RunningHub真实生成案例分析.md)：分析“凌晨两点的客房服务”和“房客”两个真实案例，记录角色、场景与道具的逐字提示词编译规则、全局风格继承、模型选择优先级、`TURNAROUND` 三视图、场景 `NORMAL / PANORAMA / TOP_DOWN` 模式、360° 全景与俯视空间图固定模板、分镜剧本处理流程，以及 Seedance 2.0 镜头视频的模型映射、真实 `promptSnapshot.finalPrompt`、参考图编号与真人模式失败规则。
- [RunningHub与当前项目风格模块全链路分析](./RunningHub与当前项目风格模块全链路分析.md)：以本次真实页面/API 取证和源码为依据，系统梳理项目—剧集—资产—分镜—镜头视频的 UI、交互、状态机和提示词编译链路，对比当前项目的图片/视频风格实现，给出 StyleSpec、统一编译器、参考图注册、模型能力预检、快照审计和分阶段落地建议。

实现说明：系统现已采用后端唯一风格目录。RunningHub 登录页面因浏览器会话隔离只成功核验并裁取了画风库截图中可见的 12 张真实预览；其余 157 张为脚本生成且在清单中明确标记为 `fallback` 的本地占位图。运行时全部使用本地文件，不热链 RunningHub，也不把占位图冒充真实预览。

调研与实现时间：2026-09-06 至 2026-09-08。
